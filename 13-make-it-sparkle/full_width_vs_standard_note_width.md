# Controlling "Standard" vs "Full" width layout for notes

> [← Help Index](../00-index.md) · Category: [Make it Sparkle](./index.md) · [Source ↗](https://www.amplenote.com/help/full_width_vs_standard_note_width)

## Difference between "Standard" and "Full" width

Standard width constrains note content to a maximum of 700 pixels, while Full width uses the entire screen width.

**Standard Width advantages:**
- Research shows the human eye reads text fastest at moderate widths
- Easier for eyes to locate where lines continue
- Provides space for background images and colors
- Creates a more aesthetically pleasing, readable appearance
- Favored by design-focused apps like Craft, Notion, and Bear

**Full Width advantages:**
- Displays more information per line
- Particularly useful for tables and data-dense content
- Takes advantage of wider screen resolutions

Accounts created October 2024 onwards default to Standard Width.

## Setting Account-wide preference for note width

Access **Account Settings > Appearance** to set your default note width preference. When displays exceed 1,000 pixels width, Standard Width restricts content to 700 pixels.

## Setting note-specific width

Override account defaults for individual notes:

1. Open the note
2. Click the triple-dot menu (upper right)
3. Select "More options" > "Edit page style"
4. Choose your preferred width in Appearance Settings

This note-specific setting supersedes your account-wide default.

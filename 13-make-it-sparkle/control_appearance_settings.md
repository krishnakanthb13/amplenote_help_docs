# Appearance Control: Configuring "Theme" and "Light/Dark" Preferences

> [← Help Index](../00-index.md) · Category: [Make it Sparkle](./index.md) · [Source ↗](https://www.amplenote.com/help/control_appearance_settings)

## Overview

Amplenote offers customization options to control how the application appears to users. These settings are accessed through **Settings → Appearance** in the web app.

## Mode

Users can select how light and dark themes are displayed:

- **Light**: Forces the light version of the chosen theme
- **Dark**: Forces the dark version of the chosen theme
- **Match system**: Automatically syncs with the device's operating system settings

![Appearance Mode setting with Light, Dark, and Match system options](https://images.amplenote.com/85c115a4-2fd1-11ed-9462-327ebed86db8/3d101a3a-1ba1-406c-83f1-31cdb2c69493.png)

## Task Completion Effects

This setting controls the celebration animation when tasks are marked complete. The options include:

**Minimal**: Completed tasks shrink out of view in approximately half a second with minimal fanfare.

**Normal**: Yellow and red tasks trigger star animations (under one second). Important tasks receive extra animated affirmation. Note that gray-bordered tasks (common checklists) show no effects.

**Dazzle**: Full celebration effects lasting up to two seconds. The cursor remains functional throughout animations.

Users must click "Update settings" after changing the Task Completion Effect level.

![Task Completion Effects setting options](https://images.amplenote.com/85c115a4-2fd1-11ed-9462-327ebed86db8/0aa55039-be8a-4797-b1ac-f95fbc6a3454.png)

## Themes

The primary appearance customization feature allows users to select different themes. Detailed theme information is available in the [dedicated themes help article](https://www.amplenote.com/help/appearance_theme_coloring).

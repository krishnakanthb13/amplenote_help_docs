# Handwriting and drawing (native iPad and Excalidraw)

> [← Help Index](../00-index.md) · Category: [Make it Sparkle](./index.md) · [Source ↗](https://www.amplenote.com/help/handwriting_drawing_in_notes)

## Drawing on iPad

Amplenote provides built-in drawing capabilities for iPad users. The feature supports "the standard set that Apple provides" as drawing tools.

To edit a previous drawing, tap the image and then tap the Amplenote drawing icon to continue making modifications.

## Drawing using Excalidraw

After installing the Excalidraw plugin, users can access drawing by using the curly bracket menu and typing "excalidraw" followed by Enter. The interface loads within seconds and supports:

- Shapes, arrows, lines, and free drawing
- Text insertion
- Undo/redo functionality
- Eraser tool for modifications
- Advanced properties (background color, border style, etc.) accessible via the selection tool

### Keyboard Shortcuts

**Tools:** Hand (H), Selection (V/1), Rectangle (R/2), Diamond (D/3), Ellipse (O/4), Arrow (A/5), Line (L/6), Draw (P/7), Text (T/8), Insert image (9), Eraser (E/0), Frame tool (F), Laser pointer (K)

**Actions include:** Zoom (Cmd +/-/0), Zen mode (Option Z), Snap to objects (Option S), Grid toggle (Cmd '), View mode (Option R), Theme toggle (Option Shift D)

**Editor actions:** Standard operations like Cut (Cmd X), Copy (Cmd C), Paste (Cmd V), Select all (Cmd A), Duplicate (Cmd D), Group/Ungroup (Cmd G/Shift G), Undo/Redo (Cmd Z/Shift Z)

For additional tutorials, the official Excalidraw YouTube channel is referenced.

# Inspire yourself with beautiful note background styles

> [← Help Index](../00-index.md) · Category: [Make it Sparkle](./index.md) · [Source ↗](https://www.amplenote.com/help/styling_note_page_appearance_background_image_and_color)

## Controlling note width

Amplenote allows you to adjust note width settings. Read the guide on "Controlling 'Standard' vs 'Full' width layout for notes" to learn how you can establish width preferences account-wide or per individual note. The default "Standard Width" setting provides additional spacing that complements background customization choices.

An example shows how a note appears with Standard Width applied on a viewport approximately 1100 pixels wide.

![Here is how this note looks with Standard Width applied (and no other background settings) on a viewport approximately 1100 pixels wide](https://images.amplenote.com/a21ec6be-80e8-11ef-8493-ceeb1c0a5b1e/03afe85e-288b-403e-9ae7-1a74053b7a57.png)

## Choosing a background image

Pro-level subscribers receive approximately 10 default note backgrounds available through the "Edit page style" menu's "Select an image" option.

Unlimited and Founder subscribers gain access to 20-30 default backgrounds and can **upload custom images** for note backgrounds.

![Default note background options in Edit page style](https://images.amplenote.com/a21ec6be-80e8-11ef-8493-ceeb1c0a5b1e/f4431d99-0f93-4c37-be57-31acefe70793.png)

The article demonstrates how a note appears with a selected default background, and separately shows the effect when "Full-width image" is enabled.

![Here is this note after choosing one of the default backgrounds without choosing 'Full-width image'](https://images.amplenote.com/a21ec6be-80e8-11ef-8493-ceeb1c0a5b1e/affce90a-fe55-4dd3-887d-202be5428b3e.png)

![And here it is when 'Full-width image' is enabled](https://images.amplenote.com/a21ec6be-80e8-11ef-8493-ceeb1c0a5b1e/9dcbd1e9-6fe5-4390-bf4c-2c10d4dc2613.png)

## Combining background image with background color

You can enhance your note by pairing a background image with a background color selected under the "Background" label in "Edit Page Style." The example illustrates selecting a turquoise blue color to coordinate with a wave-themed background image.

![Choosing a background color to match with our background image within 'Edit Page Style'](https://images.amplenote.com/a21ec6be-80e8-11ef-8493-ceeb1c0a5b1e/7e657003-c308-4aa2-9bb1-acef23102486.png)

When you publish notes with customized backgrounds, both the image and color settings combine to create a visually appealing introduction for readers. The published version demonstrates this combined effect.

![Note with turquoise blue background color and wave background image](https://images.amplenote.com/a21ec6be-80e8-11ef-8493-ceeb1c0a5b1e/91763836-9817-4aaa-8294-6158935c90bc.png)

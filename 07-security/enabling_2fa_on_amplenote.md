# Enabling Two-Factor Authentication (2FA)

> [← Help Index](../00-index.md) · Category: [Security](./index.md) · [Source ↗](https://www.amplenote.com/help/enabling_2fa_on_amplenote)

To activate this security feature on your Amplenote account, begin by clicking your account icon and clicking "Account Settings." This is strongly recommended, unless you're logging in through a third-party provider through which you already have 2FA activated.

## Steps

1. Access your account settings via the account icon.
2. Locate the "Account & Password" section.
3. Find and click the link to enable two-step verification.
4. Scan the provided verification code using an authentication app.
5. The app will generate a six-digit code required for all future login attempts.

## Key Details

Most every authentication app you could download in the app stores will support scanning a code like this to generate a six-digit code.

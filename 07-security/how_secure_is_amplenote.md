# How secure is Amplenote?

> [← Help Index](../00-index.md) · Category: [Security](./index.md) · [Source ↗](https://www.amplenote.com/help/how_secure_is_amplenote)

Amplenote distinguishes itself through security-first design principles. The platform states: "We are the only app we know of (aside from possibly Standard Notes) to have launched with end-to-end encryption available."

The company emphasizes transparency as a core security strategy: "we are one of the only note taking apps that will explicitly discuss the technical details of our security design." They compare this approach to open-source security utilities, arguing that public scrutiny enables design improvements.

## User Engagement

Amplenote invites feedback on security improvements, stating that "Actionable opportunities to improve security get an express ticket to the top of our development queue." Users can contact the team at hello@amplenote.com with security enhancement suggestions.

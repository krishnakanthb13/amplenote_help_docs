# Our "note decryption" policy

> [← Help Index](../00-index.md) · Category: [Security](./index.md) · [Source ↗](https://www.amplenote.com/help/security_note_content_policy)

## Note content policy

Amplenote commits to never attempting to decrypt user note content, supported by technical safeguards including Vault Notes—which enable local encryption without the company retaining decryption keys.

## The role of "policy" within an overarching security strategy

Amplenote acknowledges that policy alone cannot guarantee absolute security. However, the company recognizes users prefer vendors with security-focused policies, noting that such policies carry legal weight in proceedings, creating strong incentives for compliance.

The material emphasizes that technical protections supplement policy. The company outlines that even open-source applications demand user trust regarding binary code authenticity, potential government-mandated backdoors, and developer intentions—factors users cannot independently verify.

Amplenote positions transparency about implementation details and explicit policies as tools enabling users to evaluate trustworthiness independently, recognizing that some degree of trust in any software provider is unavoidable.

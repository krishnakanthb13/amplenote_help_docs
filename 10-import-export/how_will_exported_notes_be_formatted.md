## Exporting your notes

Amplenote prioritizes user data portability. The company explicitly states that "robust exporting is the first core value" they identify, emphasizing transparent switching costs if users decide to leave the platform.

## How do I export my notes?

**Access Requirements:**

- Desktop version only (mobile export not currently available)
- Navigate to www.amplenote.com and log in

**Export Steps:**

1. Click the Account Icon in the upper left corner
2. Select Account settings
3. Navigate to the Import & Export tab
4. Click the Start Export button
5. Verify account credentials when prompted
6. Wait for processing (duration depends on note and image volume)
7. Receive ZIP file via registered email address, or download directly from Export history section after refresh

The Export history section allows users to access or revisit older exports.

## How will my exported notes be formatted?

**Format Details:**

"Each note will be exported in markdown format with the note name becoming the file name."

**Content Structure:**

- Notes use markdown format for broad compatibility
- Uploaded images are included in the ZIP file
- Note metadata packaged into a YAML Front Matter section
- YAML Front Matter maintains links between notes

**Example:** A note with metadata and content becomes a markdown file with YAML Front Matter header, preserving all note relationships and information for seamless migration to other platforms or editors.

# Public User Profiles

> [← Help Index](../00-index.md) · Category: [Goals, Forums & Social](./index.md) · [Source ↗](https://www.amplenote.com/help/public_user_profiles)

Public user profiles enable Amplenote users to showcase their accomplishments and organizational approaches. The platform's [public profile gallery](https://amplenote.com/user_profiles) serves as inspiration for effective goal management.

## Profile Benefits & Uses

### Find Collaborators
Collaborative goals are often most satisfying. The profile gallery helps identify users interested in partnership, enabling shared project work.

### Get Compensated for Building Plugins
Developers who publish plugins can add a supporter link to their profile. After Amplenote review, this "developer support" link appears prominently on plugin pages, allowing users to support development efforts. Note: Amplenote suspends accounts using URLs with dark patterns, phishing, or user-unfriendly behavior.

### Earn Votes for Supporter Voting Board
Entering a testimonial that Amplenote can use for promotion grants an additional vote on the [Supporter Voting board](https://www.amplenote.com/suggested_features).

### Collect Recognition
[Amplenote Badges](https://www.amplenote.com/help/profile_badges) allow users to display proof of achievements, adding visual interest and telling a story about interests and engagement.

### Read What Others Are Writing
Many Amplenote users are prolific writers. Browsing profiles reveals subjects that engage ambitious thinkers.

### Learn How Others Work
Profiles showcase diverse productivity styles. Users mention tactics and contact preferences for discussing methodologies.

### Get an Audience with Amplenote Employees
Amplenote staff review public profiles weekly, helping ensure the product meets user needs.

## Creating a Profile

Click your account icon (upper-left corner), then select "Public profile" to create your profile and describe your use case.

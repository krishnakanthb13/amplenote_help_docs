# Markdown for forum posts & goal updates

> [← Help Index](../00-index.md) · Category: [Goals, Forums & Social](./index.md) · [Source ↗](https://www.amplenote.com/help/social_markdown_guide)

## Interpreting plain text as markdown

Amplenote's community features support markdown formatting for plain text input. Key formatting options include:

- **Images**: Use `![Image alt text](https://image.com/image.png)` syntax
- **Bold text**: Wrap text in double asterisks, e.g., `**bold text**`
- **Block quotes**: Prefix lines with `>` character

For comprehensive formatting guidance, consult the "[Markdown Guide basic syntax reference](https://www.markdownguide.org/basic-syntax/)."

## Inserting richer text via public tokens

Forum posts and goal announcements support an additional feature: public note tokens. This capability enables users to embed "any type of content that can be inserted within a published note for Unlimited+ subscribers," providing enhanced formatting and multimedia options beyond standard markdown.

---

**Note:** These formatting tools apply across Amplenote's Social message forums, accountability goal groups, and direct messaging systems.

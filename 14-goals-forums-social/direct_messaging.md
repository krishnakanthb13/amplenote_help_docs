# Direct messaging users via Amplenote Social

> [← Help Index](../00-index.md) · Category: [Goals, Forums & Social](./index.md) · [Source ↗](https://www.amplenote.com/help/direct_messaging)

Direct Messages function as a "light inbox" enabling Amplenote community members to communicate for collaboration and goal-sharing purposes.

## Messaging a member

Two primary methods exist for contacting members:

1. Send messages to recently active users via the sidebar on the Social homepage
2. Visit a user's profile and click the messaging link

The profile page includes a dedicated button to initiate direct communication with that user.

![Message a user from their profile page](https://images.amplenote.com/c7430cd8-c879-11ef-b7c5-b56772301abd/fb368215-314a-4dc4-9a27-3a35973862ca.png)

## Controlling whether you can receive messages

Message receipt requires an established user profile. Once created, users can customize their profile settings to:

- Control whether they accept direct messages
- Determine if incoming Direct Messages trigger email notifications

These preferences appear at the bottom of the profile editing interface.

# Rescheduling en masse

> [← Help Index](../00-index.md) · Category: [Calendars & Scheduling](./index.md) · [Source ↗](https://www.amplenote.com/help/reschedule_calendar_events_when_task_runs_long)

## Overview

Amplenote provides solutions for users whose calendar schedules are disrupted when events extend beyond their allocated time. As the help documentation puts it: "Anyone who uses a calendar as their agenda for the day will regularly encounter situations where their intended itinerary is disrupted."

## Option #1: Use the pop-up prompt to reschedule

When you extend an event by dragging it until it overlaps with the next scheduled item, a popup appears offering conflict resolution options. The system automatically calculates suggested time adjustments based on how far subsequent events need to shift to prevent overlapping. The further you drag an event down the daily schedule, the greater the time adjustment options presented.

## Option #2: Hold shift and select multiple tasks

An alternative method allows batch selection of multiple events. Users can hold the shift key while selecting tasks, then drag the entire group to a new time slot. This approach works better when:

- You only want to reschedule some events (not all remaining tasks)
- You need precise control over when the moved events should start

This method provides more granular control compared to the automatic conflict resolution popup.

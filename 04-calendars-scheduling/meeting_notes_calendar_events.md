# Meeting notes for calendar events

> [← Help Index](../00-index.md) · Category: [Calendars & Scheduling](./index.md) · [Source ↗](https://www.amplenote.com/help/meeting_notes_calendar_events)

## Overview

Amplenote provides functionality for capturing meeting notes and follow-up action items connected to calendar events. The platform supports two different approaches depending on whether your calendar event was created in Amplenote or an external calendar application.

## Meeting notes for an Amplenote-scheduled calendar event

### Creating linked notes

To connect calendar events with meeting notes, use the double bracket syntax to create notes directly within calendar event text. This example demonstrates combining this syntax with date calculations to rapidly generate a linked note containing follow-up tasks.

![Using double bracket syntax with date calculations to create a linked meeting note with follow-up tasks](https://images.amplenote.com/ac71eeb6-e8cf-11eb-ac70-42c8adfdc167/91465a48-857c-40ec-95c3-49fef62d5f4a.gif)

### Organizing tasks in domains

For visibility across your calendar, add tags matching your task domains (such as `todo/project-name`) to notes created from events. The task commands menu allows you to schedule when work on follow-up items begins. Once you select a start time, the task appears on your Amplenote calendar at that designated time, respecting your configured task domains.

![Scheduling follow-up tasks via the task commands menu so they appear on the calendar](https://images.amplenote.com/ac71eeb6-e8cf-11eb-ac70-42c8adfdc167/a410c91f-5f4b-42c9-9e4d-fe9786629add.gif)

## Meeting notes for a Google Calendar or Outlook external event

### Creating notes from external events

When events originate in external calendar applications, a dedicated button in the task details panel enables note creation. After creation, the note becomes visible within the task details view as a clickable link directing to the note's contents.

![A button in the task details panel for creating notes from external calendar events](https://images.amplenote.com/ac71eeb6-e8cf-11eb-ac70-42c8adfdc167/69089cf6-5e34-4e3a-b7f2-bf9913343db0.png)

### Handling multiple notes

If multiple notes share the same name as the event, the platform displays a complete list of those notes for easy access and organization.

![Created notes appear in Task Details as clickable links](https://images.amplenote.com/ac71eeb6-e8cf-11eb-ac70-42c8adfdc167/12d07b31-2de3-4ac2-8add-23175ad0da16.gif)

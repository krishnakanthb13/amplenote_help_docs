## Tasks Mode Overview, and how to show visible due/starting time

Amplenote's **Task View** (also called the "Unified Task List" or "Tasks pane") enables users to browse all tasks and to-do items across notes in a centralized location. Tasks typically originate within individual notes, but the Task View provides comprehensive management capabilities.

Access Task View through the leftmost navigation pane or by entering Quick Open and typing "Tasks."

Tasks display in paginated groups of 100 for optimal performance.

## Task View Primer

The Task View displays every task created across all notes. When first accessed without a configured Default Shortcut, you see all tasks from all notes. This unified view becomes manageable through grouping, sorting, and filtering options.

### Group Tasks By

#### Agenda View — Grouping Tasks by Scheduled Date

The most frequently used grouping option is "Scheduled Date," which represents the task's start time on the calendar (equivalent to "Due" in apps like Todoist). This creates an agenda-style view similar to Google Calendar's agenda format.

When you select "Scheduled Date" as the grouping option, tasks reorganize into date-based clusters, with the inline task data adjusting accordingly. This feature works on both desktop and mobile platforms.

![Changing Task View grouping from 'None' to 'Scheduled date' — notice the per-task inline data changes](https://images.amplenote.com/6da70c7a-fc35-11ea-a1e0-160c44ce3352/f0fd0741-d896-4565-ae56-ea236e1f21d0.gif)

#### Other Grouping Options

Additional grouping choices include:

- By source note
- By the creator of the source note

![Other task grouping options](https://images.amplenote.com/6da70c7a-fc35-11ea-a1e0-160c44ce3352/3f04d796-84df-4407-9da1-e4ac64d29f45.png)

#### Seeing When a Task is Scheduled Without Expanding It

To view task scheduling information without expanding task details, select "Scheduled Date" as the "Group by" option. This displays tasks in an agenda-style format similar to Google Calendar. Alternative sorting options for scheduled dates are expected to become available later in 2024.

#### Group by Note: Sort Notes By

When grouping tasks by their source note, the "Sort notes by" selector becomes active. As of 2024, notes and their tasks can be sorted using various criteria (specific options shown in the interface).

![The 'Sort notes by' selector becomes active when 'Group tasks by' is set to Notes](https://images.amplenote.com/6da70c7a-fc35-11ea-a1e0-160c44ce3352/4d2d05e7-6885-4033-adc1-e59bd8716e2a.png)

### Sort Tasks By

After selecting a grouping method, you control how tasks sort within each group through the "Sort tasks by" option. For example, when grouping by "Scheduled start date," unscheduled tasks cluster together — sorting options help prioritize these tasks. Available sorting criteria control task precedence within groups.

![Choosing 'Sort tasks by' controls precedence of tasks shown within their group](https://images.amplenote.com/6da70c7a-fc35-11ea-a1e0-160c44ce3352/1aab683f-18cd-42d5-8295-430e9d0d6dd8.png)

## Filter Tasks: By Tag, Note, Inline Tag, and More

### Filter by Tag or Shortcut

You can filter tasks by navigating their tag hierarchy, enabling creation of new Shortcuts for customized task views.

![Filtering tasks by tag or shortcut](https://images.amplenote.com/6da70c7a-fc35-11ea-a1e0-160c44ce3352/4f360363-2b48-47f5-bca2-01a87adf77c5.gif)

### Filter by Note Reference (Inline Tag)

A dedicated help page covers filtering by note reference functionality.

### Default Task Filters: Due This Week, High Value

Two built-in shortcuts provide default task filtering:

- **"Due This Week"** — displays tasks scheduled for the current week
- **"High Value"** — shows tasks with a Task Score above 10

![Default task filters: Due This Week and High Value](https://images.amplenote.com/6da70c7a-fc35-11ea-a1e0-160c44ce3352/68f96e1a-374c-423f-ac1c-a676561ec9b1.png)

## Using Task View

### Which Note Did This Task Come From?

The most common question when using Task View concerns the source note. Access this information by expanding the "Task Details" section, which reveals the originating note. A hotkey also opens Task Details quickly.

![Find which note a task came from by clicking its Task Details via the expand/contract icon](https://images.amplenote.com/6da70c7a-fc35-11ea-a1e0-160c44ce3352/468c9d0f-800d-4994-811d-f76efe1e5eb6.gif)

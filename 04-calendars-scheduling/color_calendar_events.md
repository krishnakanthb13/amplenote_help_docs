# Color external and internal calendar events and tasks

> [← Help Index](../00-index.md) · Category: [Calendars & Scheduling](./index.md) · [Source ↗](https://www.amplenote.com/help/color_calendar_events)

## 2 ways to add colors to your Calendar

Amplenote provides two methods to customize calendar entry colors: adjusting external calendar colors (Google, Apple, Outlook) or customizing tag colors within Amplenote.

![Two ways to add colors to your calendar](https://images.amplenote.com/ef8c307c-f9ca-11ed-9bd0-aa1e76b1d5f5/cd239e51-bde5-4c42-a51b-a71f6c4ca1ed.png)

## Task coloring from Amplenote tags

Calendar tasks inherit colors based on tags assigned to their source notes:

- **No tags**: Tasks receive a default color
- **Single tag**: Tasks display that tag's color
- **Multiple tags**: The first tag determines the color

![A task with no tags receives a default color](https://images.amplenote.com/ef8c307c-f9ca-11ed-9bd0-aa1e76b1d5f5/5b8d9be5-b6f0-4c02-bc74-e9120adde766.png)

![A task with a single tag displays that tag's color](https://images.amplenote.com/ef8c307c-f9ca-11ed-9bd0-aa1e76b1d5f5/4e6b6788-eb65-4e15-bc3a-52b2b587b438.png)

![With multiple tags, the first tag determines the color](https://images.amplenote.com/ef8c307c-f9ca-11ed-9bd0-aa1e76b1d5f5/3d88f645-5460-4435-b492-87272aece0b3.png)

To change which tag determines a task's color:

1. Use Task Details in the Calendar Sidebar and click the desired tag name
2. While editing a note, select a tag and press `Select as note's calendar color`

![Changing which tag determines a task's color](https://images.amplenote.com/ef8c307c-f9ca-11ed-9bd0-aa1e76b1d5f5/5287af97-d390-401e-8261-c9e00b8cb65c.png)

![Selecting a tag as the note's calendar color](https://images.amplenote.com/ef8c307c-f9ca-11ed-9bd0-aa1e76b1d5f5/bd630785-d558-41a7-826e-8e8a3f85cb9a.png)

## Event coloring from external calendars

When connecting external calendars, Amplenote requests color information from your calendar provider. These colors display automatically for imported events.

If you change colors on your external calendar, they update in Amplenote when you next access the calendar view.

![Events imported from external providers retain their background color](https://images.amplenote.com/ef8c307c-f9ca-11ed-9bd0-aa1e76b1d5f5/34327fa1-c9de-4d0f-a310-b3d1fc57a32c.png)

### Customize external event colors

Visit Task Calendar Settings and click the arrow next to an external calendar to manually select colors for those events instead of using defaults.

![Uncheck the box to pick a new color for your external calendar events](https://images.amplenote.com/096292f8-26c0-11ee-971d-96476340c194/660c6411-3346-4f1e-b543-4a5364be8adb.png)

## Why customize calendar colors?

"Customizing calendar colors offers a very quick way to distinguish between different kinds of commitments." Visual differentiation helps users rapidly identify task types without reading descriptions.

![Color-coded calendar entries help distinguish different kinds of commitments](https://images.amplenote.com/ef8c307c-f9ca-11ed-9bd0-aa1e76b1d5f5/3ac25114-6cc2-4c4f-a007-c7dfe3462d40.png)

## Inspiration: color categories

Common organizational approaches include:

- Events and time-sensitive appointments
- Work versus personal tasks
- Daily habits and weekly chores
- Project due dates
- One-off reminders
- Bill payment reminders

## Multiple tags strategy

When notes have multiple tags, evaluate which tag provides the most useful calendar overview. Consider whether color differentiation helps distinguish task domains (research versus marketing days) or collaboration status (shared team notes).

![Choosing which of a note's multiple tags to use for calendar color](https://images.amplenote.com/ef8c307c-f9ca-11ed-9bd0-aa1e76b1d5f5/19fa4c67-4e78-45b1-808f-0412606b7a4a.png)

## Gray tasks troubleshooting

Gray tasks typically indicate they're outside your current Task Calendar Domain. Solutions include:

1. Add a domain-matching tag (e.g., `todo`) to the note
2. Use `!move` to relocate tasks to tagged notes
3. Adjust Task Domain settings to include the note

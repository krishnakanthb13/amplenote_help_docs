# Getting a task reminder through your calendar

> [← Help Index](../00-index.md) · Category: [Calendars & Scheduling](./index.md) · [Source ↗](https://www.amplenote.com/help/task_calendar_reminder)

## Task Reminders

There are a couple different ways that you can get notifications when your tasks come due. This help page will outline your options for making sure you don't let important events slip through the cracks.

## Setting the Reminder Time

Whenever you create a task in Amplenote, you can choose when it happens and when you want to be notified about it.

*Screenshot: Shows a reminder configured to send to "hollla" at 8am on October 6, one hour before an event occurring at 9am.*

These notifications will be sent on desktop and mobile, if you have downloaded the mobile app and enabled notifications.

## Push Notification Reminders

If you're using the app on iOS or Android, you should be able to enable push notifications as the first option in Settings.

*Screenshot: iOS Settings page displaying the first option labeled "Task Reminders".*

## Calendar Reminders

By connecting your calendar, you can receive notifications about your Amplenote tasks through the mechanisms you have set up in Google Calendar, Apple Calendar or Outlook.

If you're using the Amplenote Calendar, read about the Calendar Task Domains Default reminder option.

## Diagnosing Mobile Reminder Notifications

iOS and Android offer a lot of options to control how/if notifications are received. If you're not receiving expected notifications on your mobile device, here are some steps to determine what might be going wrong.

1. **Ensure that "Task reminders" is enabled in settings.** See the screenshot in the previous section.

2. **Ensure that notifications are enabled for Amplenote.** On iOS, this amounts to opening "Settings," dragging down so that the search field is shown, and then searching for "Notifications." After clicking on Notifications, click on "Amplenote" and ensure that your settings look similar to the recommended settings.

   *Screenshot: Notification Settings configuration that permits notifications in iOS.*

3. **Ensure that "Focus" mode's "Do Not Disturb" is not enabled for Amplenote.** Again within your Settings page, you can click the "Focus" option to check whether "Do Not Disturb" is activated. If so, you typically will not receive push notifications from any apps, including Amplenote. If you want to receive reminders from Amplenote in spite of "Do Not Disturb" mode being activated, you can add Amplenote as an app.

   *Screenshot: Settings interface showing Focus menu with "Do Not Disturb" option marked "On".*

   *Screenshot: Focus settings screen with option to add Amplenote as an "Enabled App" to receive notifications.*

4. **Confirm that the expected notification shows within "Settings."** If all of your OS settings look correct, the last place to check to understand the cause of your missing notification is the "View scheduled notifications" within Amplenote settings.

   *Screenshot: Within the Amplenote app, Settings contains a button to display scheduled notifications.*

   If you have an upcoming task with "Reminder" checked, and the note that task exists within has downloaded, then you should see the task listed within this button. If the list of notifications is missing a task that you've confirmed has a Start Time set and a "Reminder" checked, feel free to contact the support team for assistance in diagnosing the issue.

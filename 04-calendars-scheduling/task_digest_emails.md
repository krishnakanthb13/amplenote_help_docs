# Task Digest emails

> [← Help Index](../00-index.md) · Category: [Calendars & Scheduling](./index.md) · [Source ↗](https://www.amplenote.com/help/task_digest_emails)

## Overview

Amplenote's Task Digest emails provide periodic summaries containing three key elements: your biggest accomplishments (ranked by Victory Value), tasks ready to begin, and upcoming deadline reminders.

## Enabling the Feature

To activate Task Digest emails, navigate to your Account Settings and locate the "Email Preferences" section. There you'll find frequency options ranging from daily to weekly delivery schedules.

![Enabling Task Digest emails in the Email Preferences settings](https://images.amplenote.com/f7045590-e730-11f0-b9bf-3d47a13df648/760ceb52-3bb3-4e42-8801-4c10a928b735.png)

## Controlling Send Frequency

Each Task Digest email includes buttons allowing you to adjust the maximum sending frequency without requiring login. According to the documentation, "Task Digest emails will not be sent if there is no new activity since the previous update that was sent."

![Within each Task Digest are buttons to change send frequency](https://images.amplenote.com/f7045590-e730-11f0-b9bf-3d47a13df648/e3183950-f280-4ecd-85ca-a0c8ab8efdaa.png)

## Email Content Structure

**Outstanding Work Section:** This portion highlights your most impressive completed tasks since the last email, with achievements ranked by Victory Value. The documentation notes that actively rating your completed tasks helps improve accuracy in both current digests and long-term task reviews.

![Most impressive achievements since your last Task Digest email](https://images.amplenote.com/f7045590-e730-11f0-b9bf-3d47a13df648/a99172f9-aefc-4ee7-ba87-d196c9f26e21.png)

**Ready to Start Section:** Displays tasks scheduled to begin today or within the next few days, helping direct your immediate focus and energy allocation.

![Reminding you which tasks have been scheduled to start soon](https://images.amplenote.com/f7045590-e730-11f0-b9bf-3d47a13df648/74dec008-efb6-4c27-91bf-e458f1fa5359.png)

**Upcoming Deadlines Section:** Features tasks with deadline markers (created using commands like `/deadline`). This section ensures critical time-sensitive tasks remain visible even when they lack calendar scheduling.

![Reminder of the critical tasks to complete soon](https://images.amplenote.com/f7045590-e730-11f0-b9bf-3d47a13df648/9f13eb80-b78f-4d07-8354-0d21d8121dcd.png)

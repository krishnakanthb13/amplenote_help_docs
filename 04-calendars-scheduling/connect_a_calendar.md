# Connect Google, Outlook or Apple Calendars with two-way sync

> [← Help Index](../00-index.md) · Category: [Calendars & Scheduling](./index.md) · [Source ↗](https://www.amplenote.com/help/connect_a_calendar)

## Overview

Amplenote enables integration with Google, Outlook, and Apple calendars. Users with Pro subscriptions or higher can activate bidirectional syncing, allowing scheduled tasks to automatically appear on designated external calendars.

## Key Features

The platform offers three primary advantages:

- **Multiple calendar connections**: Link several external calendars to Work or Personal Task Domains separately
- **Flexible sync options**: Each calendar can operate in import-only mode or bidirectional mode where new Amplenote tasks publish to external calendars
- **Color preservation**: Custom event colors from external calendars display identically in Amplenote

All functionality supports fixed recurrence, flexible recurrence, and one-time events.

## Setup Instructions

### Connecting an External Calendar

Access Amplenote settings, navigate to the "Task Calendar" option in the left menu, then authenticate with Google, Microsoft, or Apple to connect your desired calendar.

### Configuring Sync Direction

After connecting an account, select either:

- **"Show events only"** for one-way import of external calendar events
- **"Show events and publish tasks"** for two-way synchronization

### Setting Task Timing

Use the "Start At" field to designate when events display on your calendar. The "Duration" field determines event length. Changes propagate to external calendars automatically.

### Creating Tasks with External Calendar Integration

Once two-way sync is enabled, tasks created within notes tagged as part of your Task Domain automatically appear on connected Google, Outlook, or Apple calendars. Updates to start times or durations reflect across platforms within seconds.

The Calendar Pane includes an "Add a Task" box for creating tasks directly on external calendars.

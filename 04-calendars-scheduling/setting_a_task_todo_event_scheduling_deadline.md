# Scheduling a deadline for a task

> [← Help Index](../00-index.md) · Category: [Calendars & Scheduling](./index.md) · [Source ↗](https://www.amplenote.com/help/setting_a_task_todo_event_scheduling_deadline)

## Overview

**Task Deadlines** (`/deadline`) offer a way to specify if there is a specific date/time that a task needs to be completed by.

They work alongside "Start Time" (`/start`) to schedule task completion. Setting a task deadline functions similarly to setting a due date or start time — a deadline task receives elevated priority via Task Score on its scheduled date and appears at the top of your task list.

Tasks with missed deadlines are highlighted on your calendar, ensuring you remain aware of upcoming or overdue deadlines.

![Tasks with deadlines are highlighted on the calendar](https://images.amplenote.com/bc83c6fe-21f0-11f0-876d-d5a65ff71df8/34640847-965b-4235-93d5-d68ff9de9854.png)

Think of a task deadline as "the drop-dead time by which this task _really_ needs to be completed." This approach keeps you cognizant of deadline status regardless of completion.

## Distinctions between "Start Date" ("Due Date") and "Deadline"

### Recurring Tasks

When a task is recurring, its deadline remains fixed. While each instance of a recurring task has a distinct start time, all instances share the same deadline. For example, a recurring task to spend 3 hours every other morning on video production would have one fixed deadline for when the entire project completes.

### Priority After Scheduled Time

A deadline continues receiving elevated priority (shown in red via Task Score) after its scheduled time. Conversely, a task with a Start Time receives a one-time Task Score boost on its due date; if incomplete, it returns to normal priority the next day.

### Filtering Options

Tasks with deadlines can be separately filtered. The Tasks Pane allows filtering for tasks at or past their deadline and grouping tasks by deadline date. Tasks at their deadline are visually demarcated with special borders and box-shadows.

![Border and box-shadow demarcate tasks at their deadline](https://images.amplenote.com/bc83c6fe-21f0-11f0-876d-d5a65ff71df8/ca00b9a1-c530-4dd5-8e77-8bdb02c33b97.png)

## Setting a deadline

**Via slash command:** Invoke `/deadline` to specify completion timing.

**Via hover menu:** Click the "Start At" icon appearing when hovering or focusing a task, then select "Add Deadline."

**Via task details:** Once set, adjust deadlines through the slash menu or by opening task details.

# Scheduling "events" vs scheduling "tasks"

> [← Help Index](../00-index.md) · Category: [Calendars & Scheduling](./index.md) · [Source ↗](https://www.amplenote.com/help/calendar_events_vs_tasks)

## Overview

Amplenote distinguishes between "tasks" and "events" based on specific behavioral characteristics:

| Aspect | Task | Event |
|--------|------|-------|
| **Appearance** | Checkbox-style item | Calendar-style item |
| **Visibility** | Shows in calendar | Shows in calendar |
| **Repeat** | Can be set to repeat | Can be set to repeat |
| **External calendar sync** | Synced with 3rd party calendars | Synced with 3rd party calendars |
| **Completion behavior** | Removed from note when completed; crossed out on calendar | Left in note when completed; crossed out on calendar |

![Appearance of a task](https://images.amplenote.com/850fe864-711b-11ef-9ba3-eeba9115991d/3203460d-e812-4f23-9489-2bb555ec19c8.png)

![Appearance of an event](https://images.amplenote.com/850fe864-711b-11ef-9ba3-eeba9115991d/0e886c55-f5b3-4f9b-8f8c-0744e0e31a5a.png)

### Key Differences

The critical distinction is that "a **task** will show up in the Tasks Pane and Calendar Pane task list, whereas a scheduled **event** will only show up in the note that it was created within."

When marked complete, tasks are removed from notes by default (though this can be changed). Events remain in notes but are crossed out; they're eventually removed only if the containing note is auto-archived after 30 days of inactivity.

## Creating an Event

An event is a bullet list item with a scheduled start (due) time. There are several methods to create one:

### Type the event's start time in natural language

Enter the event time in a task and select "Set start time for event" when prompted by the system.

![Using the natural language menu to schedule an event](https://images.amplenote.com/850fe864-711b-11ef-9ba3-eeba9115991d/1e8c7411-b1cf-47d3-b2b4-f2bf54103d7a.gif)

### Use bullet commands menu

Enter "!" after a space to open the bullet commands menu, then choose "start" to specify the event's beginning time.

![Using the list commands menu to schedule an event](https://images.amplenote.com/850fe864-711b-11ef-9ba3-eeba9115991d/0ca104d2-d78f-4f23-bc05-abeff53b7940.gif)

### Convert from an existing task

Transform a task into a bullet item using keyboard shortcuts: "Cmd-Enter" on macOS or "Ctrl-Enter" on Windows. Start times are preserved during conversion.

### Click a scheduled task in calendar

Select a task on the calendar to access an option toggling between "task" and "event" formats.

![Clicking a scheduled task allows it to be transformed into an event](https://images.amplenote.com/850fe864-711b-11ef-9ba3-eeba9115991d/726abe01-2332-4783-94e2-4327cb82ea5a.png)

### Calendar mode creation

When in Calendar Mode, use the text field in the bottom right corner to switch between task and event types using the available toggle.

![Switching between task and event types in Calendar Mode using the bottom-right text field toggle](https://images.amplenote.com/850fe864-711b-11ef-9ba3-eeba9115991d/6dd2c980-32b7-45ce-b6d2-13d198f1e877.png)

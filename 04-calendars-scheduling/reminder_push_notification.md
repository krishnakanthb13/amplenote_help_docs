# Task push notifications

> [← Help Index](../00-index.md) · Category: [Calendars & Scheduling](./index.md) · [Source ↗](https://www.amplenote.com/help/reminder_push_notification)

## Task reminders

Amplenote offers multiple notification methods to alert you when tasks become due, ensuring important deadlines don't slip through unnoticed.

## Setting the reminder time

When creating a task in Amplenote, you can specify both the task timing and notification preferences. The interface allows you to set a reminder time separate from the task's due time. For example, you might receive a reminder at 8am for an event scheduled at 9am.

These notifications deploy to both desktop and mobile devices (if the mobile app is installed with notifications enabled).

## Push notification reminders

iOS and Android users can enable push notifications through the app's Settings menu, where "Task Reminders" appears as the first available option.

## Calendar reminders

By integrating your calendar, you can receive task notifications through your existing notification systems in Google Calendar, Apple Calendar, or Outlook. The Amplenote Calendar also offers a default reminder feature within its task domain settings.

## Diagnosing mobile reminder notifications

If notifications aren't arriving, follow these troubleshooting steps:

1. **Enable "Task reminders"** in the app's settings menu
2. **Allow notifications system-wide** for Amplenote through iOS/Android Settings, ensuring alerts are permitted and notification badges are visible
3. **Check "Do Not Disturb"** settings; disable it for Amplenote or add Amplenote as an enabled app exception
4. **Review scheduled notifications** within Amplenote settings to confirm the task appears with both a start time and reminder checkbox enabled

Contact support if a task with these settings doesn't appear in the scheduled notifications list.

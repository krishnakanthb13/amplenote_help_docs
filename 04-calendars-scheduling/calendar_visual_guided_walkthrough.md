# Calendar: Detailed Visual Guide

> [← Help Index](../00-index.md) · Category: [Calendars & Scheduling](./index.md) · [Source ↗](https://www.amplenote.com/help/calendar_visual_guided_walkthrough)

## First Time Using The Amplenote Calendar?

The Calendar Mode only displays tasks belonging to a Task Domain. To get started, visit the [Calendar Task Domains](./using_calendar_task_domains.md) help section to set one up.

## Overview: Amplenote Calendar on Desktop

Amplenote's calendar represents the fourth step of the Idea Execution Funnel. It enables drag-and-drop scheduling of important tasks. The desktop interface contains several key sections:

![Overview of the Amplenote Calendar on desktop](https://images.amplenote.com/c5a402ac-90e1-11eb-bbea-1e34e7aa6740/9b5ac91b-b3a2-4b7c-bd70-2f23312eb83e.jpg)

### Selected Task Domain

Multiple Task Domains can remain active simultaneously. The chosen domain determines which tasks appear. Task Domains are configured in Account Settings → Task Domains, where you define the default tags and notes that control task visibility.

![Upper-left of the screenshot, where your Task Domain is selected](https://images.amplenote.com/c5a402ac-90e1-11eb-bbea-1e34e7aa6740/740cbb57-dfda-4058-ba87-341fa3584199.png)

### Date Selector

Allows you to change which date you're viewing.

![Click the date selector to change the date being viewed](https://images.amplenote.com/c5a402ac-90e1-11eb-bbea-1e34e7aa6740/073f1749-4aee-48ba-9ddb-0d5beef5e03d.png)

### Domain Options / Sync Indicator

The sync icon displays green only when all tasks have been parsed from selected tags and notes, and recent synchronization with external calendars has occurred. Three configuration options control task display:

- **Default setting (all toggles disabled)**: Only tasks from the current Task Domain appear
- **"Show all scheduled tasks" enabled**: The calendar displays all tasks with start dates across all your notes
- **"Include tasks from notes created by others" enabled**: Also shows scheduled tasks from collaborative notes

Manual syncing is available via the "Sync" button, though automatic syncing occurs whenever tasks update.

![Click the sync icon to see synchronization status from external calendars and display available Task Domain options](https://images.amplenote.com/c5a402ac-90e1-11eb-bbea-1e34e7aa6740/a01bd058-28fc-4185-b081-c5bdd7bb449b.png)

### Date View Selector

Choose between per-day, per-week, or per-month calendar views.

![Choosing the date view in the Amplenote calendar, upper middle of the calendar](https://images.amplenote.com/c5a402ac-90e1-11eb-bbea-1e34e7aa6740/bef10aef-0e5a-4de5-ae77-e2c79299c36a.png)

### Active Note Selector

Filter which notes' tasks display by toggling note checkboxes. Notes appear in this list if they contain tags within your Task Domain or were explicitly added to it. However, notes are excluded if they're archived or contain no tasks.

**Tip**: Hold shift while clicking a note's checkbox to focus exclusively on that note's tasks.

![Clicking the Active Note Selector offers a list of notes associated with the Task Domain](https://images.amplenote.com/c5a402ac-90e1-11eb-bbea-1e34e7aa6740/dc8921bc-4c27-4394-93f8-05dd0312bb11.png)

### Active Tag Selector

For broad Task Domains, hold shift while clicking a tag's checkbox to focus on tasks from a specific project.

![Limiting the tasks shown in the calendar sidebar using the Active Tag Selector](https://images.amplenote.com/c5a402ac-90e1-11eb-bbea-1e34e7aa6740/150adecd-f47f-4926-8840-b2dfa5fc323e.png)

### Overdue Task Indicator

Tasks scheduled but not marked complete by their deadline are "Overdue." Click the overdue indicator in the upper-right corner to highlight these tasks with light red coloring.

A task qualifies as overdue if: it was dragged to the calendar but not completed by deadline, OR it has a Start Time and duration that has elapsed.

![Overdue tasks can be highlighted with the 'Highlight overdue tasks' icon](https://images.amplenote.com/c5a402ac-90e1-11eb-bbea-1e34e7aa6740/b8f018fd-fefc-4892-808f-7291a1250cc2.png)

### Calendar Sidebar Sort

Choose how tasks are ordered: by Task Score, most recent, or randomly ("whatever" 😜).

![Three options to order the tasks shown in the Calendar Sidebar](https://images.amplenote.com/c5a402ac-90e1-11eb-bbea-1e34e7aa6740/e95f92a7-594e-4a63-9144-70638f5405d0.png)

### Calendar Sidebar Task List

This section contains draggable tasks from enabled notes and tags. Drag tasks onto the calendar to set their start time; they'll sync as private events to connected calendars and trigger reminder notifications.

![List of tasks that exist within the enabled notes and tags from the Task Domain](https://images.amplenote.com/c5a402ac-90e1-11eb-bbea-1e34e7aa6740/08977df3-5218-4a93-a2f0-810479cb7cd2.png)

![Dragging a task from the sidebar to the calendar, scheduling its Start Time](https://images.amplenote.com/c5a402ac-90e1-11eb-bbea-1e34e7aa6740/7fa0f639-4aba-4b4b-84df-93a14526b289.gif)

#### Unscheduling a Task by Dragging to Sidebar

Reverse the scheduling process by dragging a scheduled task back to the right sidebar. Alternatively, click the task to open Task Details and remove its Start Time.

![Drag a scheduled task onto the right sidebar to remove its Start Time](https://images.amplenote.com/c5a402ac-90e1-11eb-bbea-1e34e7aa6740/624f3490-4e0f-49b0-806d-f724ac9591da.gif)

### Resizing Calendar Sidebar

Hover over the left sidebar edge for more than half a second to reveal the resize control, allowing you to adjust width based on your monitor.

![Entering sidebar resize upon hover](https://images.amplenote.com/c5a402ac-90e1-11eb-bbea-1e34e7aa6740/07c2849c-e57f-4013-a237-39679829b657.png)

### Add a Task Menu

Located in the lower-right corner, this menu creates new tasks with optional exact or "fuzzy time" scheduling (Morning, Afternoon, Evening). Fuzzy times automatically find available calendar blocks.

![Using the 'Add a Task' menu to add a task to the default note for the Task Domain](https://images.amplenote.com/c5a402ac-90e1-11eb-bbea-1e34e7aa6740/75a6f89c-342a-4511-b5e3-6c8e16e52b9c.png)

### Setting a Default Note for New Calendar Tasks

Each Task Domain can designate a default note for new tasks created via the Add a Task Menu. Click the icon next to a note in the Active Note Selector to set it as default. If unset, tasks default to the most recently changed or viewed note.

![Clicking the icon next to a note changes the default note to be used](https://images.amplenote.com/c5a402ac-90e1-11eb-bbea-1e34e7aa6740/fad5b14a-92a8-4efa-be3e-ce8a8484f24d.gif)

### Calendar Body

Three interactive views for scheduling tasks:

#### Daily Calendar

Enables checking off tasks directly without opening them, though clicking tasks allows editing or unscheduling.

![With the daily calendar view selected](https://images.amplenote.com/c5a402ac-90e1-11eb-bbea-1e34e7aa6740/a140b0bb-99e7-416c-adac-cbccd7837f12.png)

#### Weekly Calendar

Displays external events in dark gray and Amplenote tasks in lighter gray. Click any event for details or to mark complete.

![A weekly collection of external events in dark gray, with Amplenote tasks in lighter gray](https://images.amplenote.com/c5a402ac-90e1-11eb-bbea-1e34e7aa6740/53e458d8-ca39-495d-b9cf-b4d7ee2783a9.png)

#### Monthly Calendar

Shows external events in dark gray and Amplenote tasks in lighter gray. Click tasks to view full details in the Calendar Sidebar and mark them complete.

![A monthly collection of external events in dark gray, and Amplenote tasks in lighter gray](https://images.amplenote.com/c5a402ac-90e1-11eb-bbea-1e34e7aa6740/a81d16ca-4f42-48e8-9337-9caf0550a06e.png)

## Overview: Amplenote Calendar on Mobile Devices

The mobile calendar provides equivalent functionality to desktop, but task scheduling differs due to space constraints.

![Viewing a month of tasks on the Amplenote mobile calendar](https://images.amplenote.com/c5a402ac-90e1-11eb-bbea-1e34e7aa6740/01315fe8-2dcd-4f91-847b-cbac91dd2d8d.png)

### Scheduling a Task from the Current Task Domain

1. Tap the calendar-plus icon (upper right; color varies by theme)
2. Tap the icon next to the task you want to schedule
3. Choose your preferred date and time

Tasks then appear on the calendar at your selected time.

![Tap the schedule-task icon in the upper right](https://images.amplenote.com/c5a402ac-90e1-11eb-bbea-1e34e7aa6740/2776efba-5036-47aa-bb80-30e75793e553.png)

![Tap on the calendar immediately to the right of the task you want to schedule](https://images.amplenote.com/c5a402ac-90e1-11eb-bbea-1e34e7aa6740/df9bc7b8-1704-49cb-b949-303bd54b1ff3.png)

![Choose the date and time that you want to start the task](https://images.amplenote.com/c5a402ac-90e1-11eb-bbea-1e34e7aa6740/3ae8763b-9365-4812-9499-09cef54acc9a.png)

## Changing the First Day of the Week

**Desktop**: Navigate to the Appearance Settings page (`https://www.amplenote.com/account/appearance`) and select your preferred day from the dropdown.

![Desktop Appearance Settings page dropdown for the first day of the week](https://images.amplenote.com/c5a402ac-90e1-11eb-bbea-1e34e7aa6740/1cd442af-1358-4fdf-940f-f572f9e750a3.png)

**Mobile**: Go to Settings, scroll to the "Appearance" section, and select your choice.

![Mobile Settings page with the Appearance section](https://images.amplenote.com/c5a402ac-90e1-11eb-bbea-1e34e7aa6740/ff413f37-746a-4eff-b4ec-b262b8db1805.png)

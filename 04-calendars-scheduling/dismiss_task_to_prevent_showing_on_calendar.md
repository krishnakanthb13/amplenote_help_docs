# Dismiss tasks: Prevent completed tasks from showing on calendar

> [← Help Index](../00-index.md) · Category: [Calendars & Scheduling](./index.md) · [Source ↗](https://www.amplenote.com/help/dismiss_task_to_prevent_showing_on_calendar)

## Overview

Amplenote offers three methods to mark tasks as complete. Beyond standard "Completed" or "Crossed out" options, users can dismiss tasks to "remove the completed task from their calendar(s)."

## How to mark a task as "Dismissed"

### Via hotkey

Position your cursor within the task text and use:

- **macOS**: Ctrl-Option-Space (Ctrl-Alt-Space or `⌃⌥␣`)
- **PC (Linux and Windows)**: Ctrl-Shift-d (`^D`)

### Via task action

When cursor is within task text, use `!dismiss` (or `!di` for auto-suggestion) to dismiss a task.

### Via calendar

Select "Dismiss task" from the options menu.

![Dismissing a task from the calendar options menu](https://images.amplenote.com/efbc7268-ac17-11ef-ac7d-17af97ee6322/100fdd91-5d1d-427c-9bf9-981e0369cb31.jpg)

## Effect of Dismissing a Task

When a task is dismissed:

- The task is removed from all calendars
- The task appears in the "Completed task" section with lighter formatting than standard completed tasks
- Half of the Task Score associated with the task contributes to your daily "Completed Task Score"

# Setting an event (task) reminder time

> [← Help Index](../00-index.md) · Category: [Calendars & Scheduling](./index.md) · [Source ↗](https://www.amplenote.com/help/set_reminder_time)

## Task reminders

Amplenote offers multiple ways to receive notifications when tasks become due, helping you stay on top of important events.

## Setting the reminder time

When creating a task in Amplenote, you can specify both when the task occurs and when you want notification.

The interface allows you to set a reminder time before your task's start time. For example, you might receive a notification at 8am for a task scheduled at 9am. These notifications deliver to both desktop and mobile devices (if the mobile app is installed with notifications enabled).

## Push notification reminders

iOS and Android users can enable push notifications through the app's Settings page. The first option in Settings is "Task Reminders," which controls push notification delivery.

## Calendar reminders

You can connect your calendar to receive Amplenote task notifications through Google Calendar, Apple Calendar, or Outlook's existing notification systems. When using Amplenote Calendar, you can set a default reminder within the Calendar Task Domains settings.

## Diagnosing mobile reminder notifications

If you're not receiving expected mobile notifications, follow these troubleshooting steps:

1. **Enable "Task reminders" in Amplenote settings** — Verify this option is activated within the app.

2. **Enable Amplenote notifications at the OS level** — On iOS, access Settings > Notifications > Amplenote and ensure notifications are permitted with appropriate alert settings enabled.

3. **Check Focus / Do Not Disturb settings** — Within Settings > Focus, verify that "Do Not Disturb" isn't blocking Amplenote. You can add Amplenote as an enabled app to receive notifications despite Do Not Disturb being active.

4. **Review scheduled notifications in Amplenote** — Open Amplenote Settings and select "View scheduled notifications." If a task has a Start Time and Reminder enabled, it should appear in this list. Contact support if an expected notification is missing.

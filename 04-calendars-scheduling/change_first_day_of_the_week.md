# How do I change the first day of the week in the Calendar?

> [← Help Index](../00-index.md) · Category: [Calendars & Scheduling](./index.md) · [Source ↗](https://www.amplenote.com/help/change_first_day_of_the_week)

## Changing the first day of the week

You can choose which day of the week the Amplenote Calendar starts on.

**Desktop**: Navigate to the Appearance Settings page (`https://www.amplenote.com/account/appearance`) and use the dropdown to select your desired starting day of the week.

**Mobile**: Go to Settings, scroll to the "Appearance" section, and select your preferred first day.

> Note: The "First Day of Week" setting applies globally across all Task Domains (it is not domain-specific).

---

This setting is part of the broader Amplenote Calendar. The full visual walkthrough of the calendar (desktop and mobile) is reproduced below for reference, since the source page is part of the Calendar visual guide.

## Overview: Amplenote Calendar on Desktop

Amplenote's calendar represents the fourth step of the Idea Execution Funnel, providing drag-and-drop functionality to schedule your most important tasks.

> The Calendar Mode only displays tasks that are part of a Task Domain. If you haven't established a Task Domain yet, visit the [Calendar Task Domains](./using_calendar_task_domains.md) page to learn how to set one up.

### Selected Task Domain

Multiple Task Domains can be active simultaneously, with one selected at a time. Task Domains are managed under Account Settings → Task Domains, where you can rename them, define their scope, and enable/disable them. This is where you establish the default tags and notes that determine which tasks appear in the calendar sidebar.

### Date Selector

Click the date selector to change which date you're viewing.

### Domain options / Sync indicator

The sync indicator appears green only when all known tasks from the selected Task Domain's tags and notes have been parsed and recent syncs to connected external calendars are complete. You can manually trigger a sync using the "Sync" button, though automatic syncing occurs whenever you update a task. This menu provides three configuration options for task display:

- **Default (all toggles disabled)**: Only tasks from the current Task Domain display on the calendar
- **"Show all scheduled tasks" enabled**: The calendar shows all tasks with a start date across all your notes
- **"Include tasks from notes created by others" enabled**: The calendar also displays tasks with start dates from notes created by other users

### Date View Selector

Select which calendar format to display: daily, weekly, or monthly view.

### Active Note Selector

This selector lets you hide tasks from irrelevant notes. Shift+click a note's checkbox to focus on only that note's tasks while disabling all others.

### Active Tag Selector

For broad Task Domains, filter to specific projects by tag. Hold shift while clicking a tag's checkbox to focus on only that project's tasks.

### Overdue Task Indicator

Tasks scheduled on the calendar but not marked "Done" by their deadline become overdue. Click the "Overdue tasks" icon in the upper-right corner to highlight them with light red.

### Calendar Sidebar Sort

Choose how tasks sort: by Task Score, most recent, or randomly ("whatever" 😜).

### Calendar Sidebar Task List

Shows items from enabled notes and tags within your Task Domain. Drag tasks from the list onto the calendar to set their start time. Once synced to external calendars as private events, you'll receive reminder notifications based on your calendar settings.

### Add a Task Menu

Located in the lower-right corner, this menu creates new tasks. You can set tasks to start at exact times or "fuzzy times" like "Morning," "Afternoon," or "Evening."

## Overview: Amplenote Calendar on Mobile Devices

The mobile calendar offers the same functionality as desktop. To schedule a task:

1. Tap the calendar-plus icon in the upper right
2. Tap the icon next to the task you want to schedule
3. Choose a time for it

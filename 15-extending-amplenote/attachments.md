# Note Attachments: images, videos, audio, PDFs, Word, Excel, Powerpoint

> [← Help Index](../00-index.md) · Category: [Extending Amplenote](./index.md) · [Source ↗](https://www.amplenote.com/help/attachments)

## What types of attachments are supported in Amplenote?

The platform supports various file types with size limits varying by account tier as of February 2023:

**Personal Plan Limits:**

- Images (jpg, jpeg, png, bmp, gif, webp): 5MB
- Videos (mov, mp4, mpg, webm): 5MB
- Audio (aac, mid, m4a, mpeg, mp4, ogg, wav, flac): 5MB
- Excel files (xlsx, xls): 3MB
- Word documents (docx, doc): 3MB
- PowerPoint (pptx, ppt): 5MB
- PDF: 5MB
- JSON: 5MB

**Pro+ Plan Limits:**

- Images: 16MB
- Videos: 200MB
- Audio: 100MB
- Excel: 10MB
- Word: 10MB
- PowerPoint: 30MB
- PDF: 30MB
- JSON: 10MB

## How do I add an attachment to a note?

**On Web:**
Use the attachment icon in the toolbar to select files. The "Attach PDF" button appears when your cursor is positioned in compatible note sections, supporting PDF, Excel, Word, and PowerPoint files. For images and videos, use the adjacent toolbar button. Alternatively, drag and drop files directly into the note editor.

**On Mobile:**
Use the dedicated toolbar button for images and videos, or utilize the Share Sheet to share files from other applications.

## How can I open the Manage Files view?

Access the file management interface by:

1. Clicking note options (triple dot in upper right)
2. Selecting "View all details"
3. Clicking the "Manage Files" link

Alternatively, append `/files` to your note's URL in your browser.

## How do I permanently delete an image/video file?

Referenced files (actively used in notes or Rich Footnotes) appear in the "Referenced" section. Unreferenced files appear separately. To delete permanently:

1. Remove the image from note content
2. Open Manage Files view
3. Select the file from "Unreferenced" and click "Delete"

## How do I restore a deleted file?

To recover accidentally deleted files:

1. Open File View
2. Right-click the image to recover
3. Copy the image
4. Paste it back into the note

Currently, only image files support restoration this way.

# Published Plugins Directory

> [← Help Index](../00-index.md) · Category: [Extending Amplenote](./index.md) · [Source ↗](https://www.amplenote.com/help/published_plugins_directory)

## Overview

The Published Plugin Directory is a curated list of notes that function as Amplenote plugins. Since Amplenote doesn't individually review community-created plugins, users vote and comment to help others identify valuable options.

## Key Questions & Answers

**What are the potential dangers?**
See the related help page on "What are the potential dangers of installing Amplenote plugins?"

**Reporting malicious plugins:**
Use the "Report listing" link available when viewing any plugin in the Published Plugin Directory.

**Publishing your own plugin:**
After publishing a note matching plugin specifications, expand the token and select the option to publish to the Amplenote Plugin Directory. Your listing will be indexed within hours using metadata from your plugin.

![When publishing a note that is a plugin, you can expand the note token to show an option for sharing the plugin](https://images.amplenote.com/dda36f2a-ceae-11ed-898c-76979436bcb1/602df0ce-35ca-4425-8f7b-fb87362951ef.png)

**Preview images:**
Thumbnails display at 300px height (typically 482px wide). Images in the "Instructions" field are detected automatically in order encountered. You can also upload a custom image when logged in—this takes precedence over instruction images.

![A 482x300 sized thumbnail as seen in the Plugin Gallery](https://images.amplenote.com/dda36f2a-ceae-11ed-898c-76979436bcb1/583e04db-9acd-4cad-863f-6f67f64cc74a.png)

**Metadata fields used:**

- `name`, `description`, `instructions` (synced every couple hours)
- `icon` field (uses Google Material Icon set with underscores separating words)

![Metadata in a plugin that will be used to populate the details of a published Amplenote plugin](https://images.amplenote.com/dda36f2a-ceae-11ed-898c-76979436bcb1/b1c0160f-4758-40d3-bf8f-79b83ed7410c.png)

![A plugin icon from the Google Material Icon set](https://images.amplenote.com/dda36f2a-ceae-11ed-898c-76979436bcb1/0c8f17e4-c418-49b8-ad03-0aee86cb5728.png)

**Plugin restrictions:**
Plugins utilizing user data inconsistently with descriptions are removed. Malicious authorship may result in account bans.

**Version consistency:**
Installed plugins may differ from voted-upon versions.

**Voting eligibility:**
Logged-in users can vote up plugins or remove votes. Downvoting is unavailable.

## How do I create a new note?

Multiple methods exist for creating notes in Amplenote.

### Create a note using the "New note" button

After logging in, users can click the "New note" button in the top right corner. This switches from Jots mode to Notes mode and opens a blank note for editing. Using `Ctrl-Click` or `Cmd-Click` opens the note in Peek Viewer instead.

### Create a note with the note hotkey

- macOS: `Cmd-Alt-N` or `Cmd-Option-N`
- PC: `Ctrl-Option-N`

### Create a note using double brackets `[[`

Double brackets enable note creation and linking. Details appear in a dedicated help article: "Using Double Brackets [[ for Note Creation/Linking".

### Create new notes from text selection

Two methods exist:

1. Create a note titled after selected text
2. Move selected text to a new note

Both are covered in "Note linking guide (at @ and double-bracket [[ notation)".

### Create a note from a link

Users can create links to `https://www.amplenote.com/notes/new` with optional parameters:

- `name` parameter: Sets the note title (e.g., `?name=My%20Named%20Note`)
- `tags` parameter: Applies tags (e.g., `?tags=tag-a`)
- `source` parameter: Copies content from another note using its UUID

Parameters can be combined, such as:

```
https://www.amplenote.com/notes/new?name=Daily%20Plan&tag=todo
```

### Create a note through the mobile quick todo bar

The mobile app includes a note creation button on the right side of the Quick Task menu.

## What other note settings are there?

Click the triple-dot icon on the right side of the note header to access individual note settings. Additional options appear under "More options."

Most settings can be activated for multiple notes simultaneously. See "Multi-note selections and bulk actions".

### Duplicate Note

Creates a new note with identical content. Users specify a new title during duplication. Non-secure notes can share with original note recipients. Related: "Using note templates to quickly create notes with structure".

### Download Note

Downloads a markdown (.md) file of the note to a device. Markdown files open in plain text editors and note applications.

### Lock Note

Locking a note achieves two things:

1. Makes the note read-only for all collaborating users
2. Hides open tasks from Tasks & Calendar Views

Only note owners can lock/unlock. The owner is:

- The person who created the applied shared tag (if any)
- The person who originally created the note (otherwise)

### Archive Note

Archiving hides notes from the list without deletion. Notes remain searchable and can be un-archived anytime. Use the sidebar filter or "Archived Notes query" to view archived notes.

### Delete Note

Removes notes from the account. Shared notes remain in other users' accounts unless the share is removed first. Amplenote retains deleted notes for 30 days before permanent deletion. See "Tag moving, renaming, deleting and merging" for bulk deletion.

### Restore a deleted note

Use the "Deleted Notes filter" or the dedicated button at the bottom of the tag sidebar. Click `Restore` within a note to prevent permanent deletion.

> [← Help Index](../00-index.md) · Category: [Notes & Writing](./index.md) · [Source ↗](https://www.amplenote.com/help/word_count)

## Getting word count and character count in a note

Amplenote provides multiple methods for viewing word and character counts.

### For notes without tasks

Access word count, character count, and estimated reading time by clicking the upper-right note options menu. This information appears at the bottom of the menu.

### For notes with tasks or detailed summaries

Select "View all details" from the Note Options menu, or use the keyboard shortcut **Ctrl-Shift-O**. This opens a detailed panel displaying:

- Word count and character count for the note
- Character and word counts for Rich Footnotes
- Word and character counts for selected text

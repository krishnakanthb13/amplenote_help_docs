# How do I create a new note?

> [← Help Index](../00-index.md) · Category: [Notes & Writing](./index.md) · [Source ↗](https://www.amplenote.com/help/notes_and_writing_create_new)

The platform offers numerous methods for note creation.

## Create a note using the "New note" button

Users should log into Amplenote and click the "New note" button in the top right corner. After login, users arrive in Jots mode (daily auto-generated notes). Selecting "New note" switches to Notes mode and opens a blank note for editing.

**Special modifier:** Using `Ctrl-Click` or `Cmd-Click` opens the newly created note in Peek Viewer instead.

![The "New note" button in the top right corner](https://images.amplenote.com/c1d821d0-fad2-11ea-a5bc-f200a12bf340/d88588d3-4578-45f4-9155-ec9d57ceb45a.png)

- Moving selected text to a new note

## Create a note from a link

Users can link to `https://www.amplenote.com/notes/new` with optional parameters:

- `name` parameter: Designate the note title (e.g., `?name=My%20Named%20Note`)
- `tags` parameter: Apply tags (e.g., `?tags=tag-a`)
- `source` parameter: Copy content from another note using its UUID

Parameters can combine. Example: `https://www.amplenote.com/notes/new?name=Daily%20Plan&tag=todo`

## What other note settings are there?

Users click the triple-dot icon on the note header's right side to access individual note settings. Additional "More options" include less-frequently used features.

Most options apply to multi-note selections.

## Duplicate Note

This creates a new note with identical content. Users assign a new title during duplication. Non-secure notes can maintain sharing settings from the original. Related: note templates article.

![Duplicating a note to create a copy with identical content](https://images.amplenote.com/c1d821d0-fad2-11ea-a5bc-f200a12bf340/837811f1-4e68-48b1-bd68-05d1d5e28526.png)

## Download Note

Users can export notes as markdown (.md) files to their device for viewing in text editors or other note applications.

## Lock Note

Locking accomplishes two things:

1. Makes the note read-only for all collaborators
2. Hides open tasks from Tasks & Calendar Views

**Permissions:** Only the note owner can lock/unlock. Owner is defined as: the person who created the shared tag applied to the note, or the note's original creator otherwise.

## Archive Note

Archiving hides notes from the list without deletion. Notes remain searchable and exist indefinitely until un-archived.

**To un-archive:**

- Search for and open the note
- Access note settings menu
- Select "Un-archive note"

View all archived notes using the left sidebar filter or Archived Notes query.

## Delete Note

Deletion removes notes from the account. Shared notes remain in collaborators' accounts unless the share is removed first.

Amplenote retains deleted notes for 30 days for restoration. After 30 days, deletion becomes permanent.

![Deleting a note from the account](https://images.amplenote.com/0bbee202-0327-11e9-b258-7a639e48bef6/912e0b8c-31a6-41ee-b438-36315dda9170)

## Restore a deleted note

Access the Deleted Notes filter or dedicated button at the tag sidebar bottom. Within a deleted note, select `Restore` to prevent permanent deletion.

![Restoring a deleted note before permanent deletion](https://images.amplenote.com/c1d821d0-fad2-11ea-a5bc-f200a12bf340/a486f476-8794-45d9-8f10-1a935e713d65.gif)

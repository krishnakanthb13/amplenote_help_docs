# Note content formatting and page layout options

> [← Help Index](../00-index.md) · Category: [Notes & Writing](./index.md) · [Source ↗](https://www.amplenote.com/help/formatting_layout_options)

## How do I access formatting options?

Amplenote offers three methods for formatting notes:

1. **Via the toolbar** at the top of the note window in Notes Mode
2. **Via the contextual toolbar** that appears when selecting text (works in both Jots and Notes Mode)
3. **Using keyboard shortcuts and markdown syntax**

💡 Hover over toolbar icons to view associated keyboard shortcuts.

**Supported languages:** JavaScript, C, C++, C#, CSS, HTML, Python, Ruby, Rust, XML

**Rainbow text styling options:**

- `rainbow` – Different color per line
- `rainbow2` – Alternative color scheme
- `rainbow3` – Color changes per character, no background
- `rainbow4` – Alternative to rainbow3
- `rainbow5` – Dynamic text color changes
- `plain` – Black text on gray background

## Using the Formatting Toolbar

The contextual toolbar provides standard text formatting plus two exclusive options:

- **Extracting text to a note** – Creates a new note from selected text
- **Extracting text to a Rich Footnote** – Converts selection into a Rich Footnote

![Contextual toolbar buttons for extracting text to a note or a Rich Footnote](https://images.amplenote.com/c1d821d0-fad2-11ea-a5bc-f200a12bf340/d489af97-2ce1-492d-bfc1-2d350692a16c.png)

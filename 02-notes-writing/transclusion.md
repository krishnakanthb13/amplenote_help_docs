## Transcluding note content (show a block outside the note)

"Transclusion" is the name that third-generation note apps use to describe the pattern whereby you embed a block from one note into another. This approach proves especially useful when a block defines a topic that should appear across multiple notes or tasks.

### Transcluded content via Rich Footnote live preview

Note content can be embedded through Rich Footnotes as a live preview. Content from a note (or a section in a note) can now be viewed from within the note that links to it. This feature enables quick content preview without navigating to other pages.

### How to transclude (link to a specific note section)

**Steps to link to another note's section:**

Use the Note linking syntax, start typing the target note name, then press `#` to see available sections in that note.

**Linking within the current note:**

Follow the same process but omit the note title entry. This approach proves useful to "include context around a task."

**Result:**

You receive a Rich Footnote with automatically updated contents whenever the source note changes.

# What other note settings are there?

> [← Help Index](../00-index.md) · Category: [Notes & Writing](./index.md) · [Source ↗](https://www.amplenote.com/help/notes_and_writing_other_settings)

## How do I create a new note?

Multiple creation methods are available:

**New note button method**: Click the "New note" button in the top right corner after logging in. Using `Ctrl-Click` or `Cmd-Click` opens the note in Peek Viewer instead.

![The "New note" button in the top right corner](https://images.amplenote.com/c1d821d0-fad2-11ea-a5bc-f200a12bf340/d88588d3-4578-45f4-9155-ec9d57ceb45a.png)

**Keyboard shortcuts**:

- macOS: `Cmd-Alt-N` or `Cmd-Option-N`
- PC: `Ctrl-Option-N`

**Double brackets**: Use `[[` syntax for note creation and linking (covered in separate documentation).

**Text selection**: Create notes titled after selected text or move selected text to a new note.

**From a link**: Create parameterized links using `https://www.amplenote.com/notes/new` with optional parameters:

- `name` parameter sets the note title
- `tags` parameter applies tags
- `source` parameter copies content from another note using its UUID

**From templates**: Dedicated help page available for template-based creation.

**Mobile quick todo bar**: Use the button on the right side of the Quick Task menu.

![The note creation button on the mobile quick todo bar](https://images.amplenote.com/c1d821d0-fad2-11ea-a5bc-f200a12bf340/bdb6454e-6c8e-462e-ad3f-31047d6cd805.jpg)

**Tag auto-tagging**: Control automatic tag assignment for newly linked notes.

## What other note settings are there?

Access individual note settings by clicking the triple-dot icon in the note header. Additional options appear under "More options."

![Accessing individual note settings from the triple-dot icon](https://images.amplenote.com/c1d821d0-fad2-11ea-a5bc-f200a12bf340/3f420ac4-4c22-4e84-a45a-ff047027269c.png)

![The "More options" menu of less-frequently used note settings](https://images.amplenote.com/c1d821d0-fad2-11ea-a5bc-f200a12bf340/d6e82069-3b4b-4932-89b7-f9149bc49309.png)

Most settings work on multi-note selections (see bulk actions documentation).

### Key Note Settings

**Publish notes**: "Publishing notes deserves a separate help page" with detailed guidance.

**Collaboration/Sharing**: Share notes with individuals, groups, or the web through dedicated collaboration documentation.

**Vault Notes**: Special note type with separate documentation.

**Revision history**: Restore previous note versions using dedicated help article.

**Duplicate Note**: Creates a new note with identical content; optionally share with same collaborators as original.

![Duplicating a note to create a copy with identical content](https://images.amplenote.com/c1d821d0-fad2-11ea-a5bc-f200a12bf340/837811f1-4e68-48b1-bd68-05d1d5e28526.png)

**Download Note**: Export notes as markdown (.md) files for use in text editors or other apps.

**Lock Note**: Makes notes read-only for all collaborators and hides open tasks from Tasks & Calendar Views. Only note owners (creator or shared tag creator) can lock/unlock.

**Archive Note**: Hides notes from the list without deletion; they remain searchable. Un-archive by opening the note and selecting the option, or use the Archived Notes filter.

**Delete Note**: Removes notes from your account. Amplenote retains deleted notes for 30 days for restoration; after that, deletion becomes permanent. Shared notes remain in collaborators' accounts unless explicitly unshared before deletion.

![Deleting a note from the account](https://images.amplenote.com/0bbee202-0327-11e9-b258-7a639e48bef6/912e0b8c-31a6-41ee-b438-36315dda9170)

**Restore Deleted Note**: Use the Deleted Notes filter or dedicated sidebar button to view recently deleted notes; click "Restore" to prevent permanent deletion.

![Restoring a deleted note before permanent deletion](https://images.amplenote.com/c1d821d0-fad2-11ea-a5bc-f200a12bf340/a486f476-8794-45d9-8f10-1a935e713d65.gif)

**Mail-to-note**: Forward emails to Amplenote using dedicated documentation.

**Note Shortcuts**: Create pinned notes using the Note Shortcuts feature (documented separately).

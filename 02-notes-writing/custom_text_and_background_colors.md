# Applying custom foreground and background color to text and table cells

> [← Help Index](../00-index.md) · Category: [Notes & Writing](./index.md) · [Source ↗](https://www.amplenote.com/help/custom_text_and_background_colors)

## Overview

Amplenote allows users to customize text and background colors beyond the default dark yellow highlight. Users access these features through the formatting bar using `Ctrl-H` / `Cmd-H` keyboard shortcuts.

## Changing text foreground and background colors

The platform provides two primary customization options:

- **Foreground color:** Click the "A" icon to modify text letter color.
- **Background color:** Select the bucket icon to change cell or text background.

Both options open a color picker modal featuring pre-defined colors, gradients, and rainbow options.

## Table cell coloring

Table cells support background color customization. Users select the desired cell and click the bucket icon to apply color changes.

## Code block colors

The help documentation references a separate page covering "color options inside code blocks" for additional formatting details.

# Rich Footnotes and content previews

> [← Help Index](../00-index.md) · Category: [Notes & Writing](./index.md) · [Source ↗](https://www.amplenote.com/help/rich_footnotes_content_preview)

Rich Footnotes enable Amplenote users to add **context** to **text**, transforming ordinary words into what the platform calls "writing in 3d" — allowing users to capture more thoughts even when processing ideas from multiple directions.

## What goes in Rich Footnotes?

Rich Footnotes can embed plain text (and text in Amplenote tasks and calendar events) with various content types:

- 🖼️ Image
- 📽️ Mp4 video
- 🔡 Text
- 🖇️ Links
- 🤩 Youtube video
- 🐦 Tweet
- 📄 Google Sheet
- 👀 Preview of another note
- 🕺 A combination thereof
- 📫 Email addresses

Given their versatility, Rich Footnotes can often replace the need to create and jump between multiple notes.

## Use cases

- **Instructions for peers**: Open a note, type text, highlight it, click the link icon, and upload a picture. This consolidates instructions and images into a single sentence.
- **Vacation planning**: Embed property listings, images, maps, and travel time estimates within planning notes.
- **Work research**: Compare charts and data visualizations alongside text analysis.
- **Reminders to future self**: Link and embed technical documentation and setup preferences.
- **Bugs to work on later**: Link to external issue trackers directly within notes.
- **Email → todo list**: Convert emails into actionable task items using Rich Footnotes and Task Detail features.
- **Jokes**: Embed humorous content within text.

## Creating Rich Footnotes

**Simple method**: If you want to insert a **link** (which includes links to Youtube videos, tweets, etc), **image**, or **video** into text, just select and paste.

**Rich Footnote dialog**: For commentary or linking to existing notes, highlight text and use the keyboard shortcut (`Ctrl K` for Windows or `Cmd K` for Mac) or click the toolbar icons.

### Using the Rich Footnote dialog to search for existing notes to link to

When typing in the input field, a list of existing notes appears for selection. Pressing Enter creates a new linked note with the entered title.

The field accepts double bracket note creation syntax, including:

- `#` sign after note titles to link to specific sections.
- `path/to/New Note` syntax to declare tag hierarchies for newly created notes.

## Rich Footnote content previews

Content previews layer onto existing Rich Footnotes. Pasting URLs for tweets, Google Sheets, and videos into the Rich Footnotes dialog displays them — **no additional steps** necessary.

### An example embedding a public note from Amplenote

Content previews work on all published notes, appearing on amplenote.com/public links and embedded blog content.

### An example of embedding a tweet

Linking to tweets now displays embedded tweet content.

### An example of embedding a spreadsheet

Google Sheets can be embedded and made editable directly from the Amplenote client if permissions allow.

### An example of embedding a video

YouTube videos play within notes without leaving the current document. Links to specific timestamps work, with playback starting at the designated time.

## Extracting text selection to Rich Footnotes

Using the contextual toolbar, you can quickly create footnotes with existing note text. The footnote text field focuses automatically, allowing you to type visible display text.

## Converting rich footnote content to a note

Opening a rich footnote and pressing `Tab` enters edit mode, revealing an option to convert the footnote into a separate note. This creates a new note and replaces the previous Rich Footnote with a link to it.

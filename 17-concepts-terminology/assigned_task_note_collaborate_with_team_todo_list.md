# Assigned Tasks Note: Definition and Usage

> [← Help Index](../00-index.md) · Category: [Concepts & Terminology](./index.md) · [Source ↗](https://www.amplenote.com/help/assigned_task_note_collaborate_with_team_todo_list)

An "Assigned Tasks Note" is a shared note enabling teammates to assign tasks for your consideration. Typically named something like "Bill's Tasks from Liam," the **creator** (Bill) shares it with the **assigner** (Liam).

## Key Features

When tagged with `todo/collaborative` in your notebook, the note integrates with Amplenote's task management system. The creator sees assigned tasks in the Calendar pane, while the assigner doesn't see their own assignments there.

## Using an Assigned Tasks Note

The primary benefit involves leveraging existing Task Pane filters to distinguish between tasks you created versus those others identified for your consideration.

By default, the Tasks pane displays only tasks within notes you authored. However, an Assigned Tasks Note need not be one-to-one. You could create "Bill's Tasks from Project Eagle" and share it with all collaborators on that project, allowing easy filtering of incoming versus self-created tasks.

# Task Inbox Note: Definition and Recommendations

> [← Help Index](../00-index.md) · Category: [Concepts & Terminology](./index.md) · [Source ↗](https://www.amplenote.com/help/task_inbox_note_explained_with_recommendations)

## Overview

A Task Inbox Note is a dedicated note for collecting unorganized tasks and ideas awaiting organization into project-specific notes. According to the article, such notes typically contain "at least 20 tasks" that are "often found in a 'partially formed' state."

## Key Benefits

The article identifies several advantages to maintaining a Task Inbox Note:

- **Easy access**: Pin the note as a shortcut for quick navigation
- **Centralized location**: Eliminates confusion about where tasks were stored
- **Historical tracking**: View completed and dismissed tasks over time
- **Mood-based task selection**: Find recently-relevant tasks matching current energy levels
- **Customization options**: Apply inspiring backgrounds and aesthetic settings like Evergreen Notes

## Recommendations

**Set an Aesthetic**: Personalize your Task Inbox using note appearance settings with custom backgrounds and colors to inspire action.

![The author's Evergreen Task Inbox note uses a blue background color and a picture he took on vacation](https://images.amplenote.com/e0bdce5a-80d5-11ef-8707-62fb339586e5/eeea9f9f-6d0d-47a0-a15a-09880c70570b.png)

**Pin as Default Shortcut**: Use the pinning feature to keep your active task queue visible when switching between the Note Pane.

**Enable Email Forwarding**: Create a mail-to-note contact in your email app to forward important messages directly to your Task Inbox, including images and attachments.

![Setting up an email forwarding contact to your Task Inbox](https://images.amplenote.com/7dfc48a8-78f8-11ea-9709-4a9bae68938e/b09a70bd-a221-4e9d-91c2-e81cd5e7e973.png)

The article also notes that Daily Jots can function as an alternative Task Inbox, though dedicated notes offer greater customization possibilities.

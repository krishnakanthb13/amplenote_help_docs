# Spaced-repetition learning

> [← Help Index](../00-index.md) · Category: [Concepts & Terminology](./index.md) · [Source ↗](https://www.amplenote.com/help/spaced_repetition_learning_use_case)

## Overview

Spaced-repetition learning represents the gold standard approach many academics recommend for mastering new topics. The concept involves creating flashcards that are periodically revisited to solidify information in long-term memory.

## Using Spaced-Repetition in Amplenote

### 1. Set up a task that uses the "Repeat" setting "When task is complete"

Create a task where the body contains the question you wish to memorize. Configure the "Start at" time to reflect your desired review interval (days, hours, weeks, etc.). Upon completion, the system schedules a follow-up instance based on the "Hide until" interval.

**Helpful hotkey:** Cmd-. (macOS) or Ctrl-. (PC) opens/closes Task Details, allowing you to navigate fields with the Tab key.

![Setting up a spaced repetition question in Amplenote as a flexible recurring task](https://images.amplenote.com/a4765f30-c6f6-11eb-9720-7efd079009b0/7b41b37b-1588-4936-a88a-8e5c25dd3619.png)

### 2. Provide the answer to the question in a Rich Footnote

Place answers in a Rich Footnote so you encounter the question without immediately seeing the answer. The footnote can include images, text, and links for reference.

![The Rich Footnote where the answer resides can contain image, text and a link to jog your memory about this topic](https://images.amplenote.com/a4765f30-c6f6-11eb-9720-7efd079009b0/72b61b52-4ee6-43de-8844-8cb1c4717045.png)

### 3. Delete or move the task when done learning it

Since tasks repeat indefinitely, you cannot simply mark them complete. Instead, either:

- Delete the task directly by selecting and pressing Backspace/Delete
- Use "Delete task" from the Task Details menu
- Use the `!move` command to transfer finished tasks to a separate learning-complete note or tag

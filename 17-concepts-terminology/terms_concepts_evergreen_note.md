# Evergreen Notes: Definition and Recommendations

> [← Help Index](../00-index.md) · Category: [Concepts & Terminology](./index.md) · [Source ↗](https://www.amplenote.com/help/terms_concepts_evergreen_note)

## Overview

Evergreen Notes are regularly revisited notes—typically accessed at least weekly—that constitute roughly half of an average user's daily note visits.

## Common Examples

- Daily Inbox todo list
- Quarterly Plan note
- Movie recommendations list
- Grocery shopping list
- Favorite quotes collection
- Workout/exercise plan
- Business strategy document
- "Likes and dislikes" list
- Weekly Dashboard note
- Team member's Assigned Tasks note

These notes share a key characteristic: they receive 10+ visits annually and improve incrementally as new information arrives.

## Recommendations for Evergreen Notes

### Aesthetic Personalization

Investing time in customizing Evergreen Notes makes sense given their frequent access. Amplenote recommends using the Note appearance settings to create an inspiring mood through background colors and images.

### Tag with `#canonical`

Using a dedicated tag like `canonical` or `evergreen` helps identify notes for repeated reference and proves especially useful when exploring connections via Note Graph View.

### Dismiss Aggressively

For task-based Evergreen Notes, implement these strategies:

**Set a task limit** to maintain visibility on whether your list needs pruning. According to Amplenote's CEO, hitting a 60-task limit should prompt dismissing roughly two-thirds of least important tasks and snoozing one-third.

**Dismiss rather than hide** tasks you won't realistically work on. As the CEO states: "If it's truly an amazing, great idea, you'll return to it. Most of my best ideas occur to me at least 3x."

If you repeatedly avoid a task, either break it into smaller components or dismiss it entirely. Your future self will appreciate the clarity.

# Which devices are supported?

> [← Help Index](../00-index.md) · Category: [Devices & Syncing](./index.md) · [Source ↗](https://www.amplenote.com/help/devices_and_syncing_supported_devices)

## Platform & devices supported

Amplenote provides online and offline access across desktop platforms, iOS, and Android.

---

## Desktop

Windows, macOS, and Linux are supported through downloadable PWA apps with offline functionality or via web browser.

### Amplenote Web App

Access without downloading — simply "[log into the site](https://www.amplenote.com/login)." The web app offers complete functionality with internet access. For offline use, install the desktop PWA.

Supported browsers include the latest versions of Chrome, Firefox, and Safari on Windows, Linux, and macOS. Other browsers can be suggested on "[our voting boards](https://www.amplenote.com/help/feature_voting_roadmap_planning)."

![Amplenote web app](https://images.amplenote.com/744a092c-0490-11e9-8157-5261ad5891d7/aa3733e3-76dc-4ce8-a22c-046f5f5f7eb3)

### Amplenote PWA

For PWA installation instructions on Windows, Mac, or Linux, see "[Installing Amplenote and Storing Data](https://www.amplenote.com/help/installing_amplenote_macos_windows_linux_ios_android)."

Amplenote is available in the "[Apple App Store](https://apps.apple.com/us/app/amplenote/id1436769674)" and "[Google Play Store](https://play.google.com/store/apps/details?id=com.amplenote&hl=en)."

### Installing on an iPad

The native iPad app is available through the App Store, offering "[Handwriting and drawing on iPad](https://www.amplenote.com/help/handwriting_drawing_in_notes)" features.

### Amplenote mobile web

The mobile web version includes most native app functionality without downloading. However, it's the least-tested platform and prone to bugs — native apps are recommended for better reliability and offline access.

## How many devices can I use?

"All Amplenote plans have access to unlimited devices." Use Amplenote across web, iOS, and Android without restrictions.

### Installation instructions

A Pro, Unlimited, or Founder subscription (or trial) is required to access the native desktop app. Personal plan users can continue using the Amplenote PWA and mobile app at no cost. Native app development is resource-intensive, so access is currently limited.

To upgrade your subscription, visit the [Subscription selection page](https://www.amplenote.com/subscriptions/new).

**Installation steps:**

1. Visit the [Native Desktop Download page](https://www.amplenote.com/download)
2. Choose the application matching your system
3. Double-click the downloaded app to begin installation
4. Windows users will likely need Administrator permissions

### Features unique to the desktop clients

These features are available only on Linux, macOS, or Windows native clients:

- [Global task/event capture hotkey on desktop (plus global note open key)](https://www.amplenote.com/help/global_task_todo_capture_via_hotkey_on_desktop_plus_global_note_lookup_on_desktop)
- [Automatically save notes to local markdown files](https://www.amplenote.com/help/automatic_live_content_backup_to_local_directory_including_images)

**Keyboard shortcuts:**

- `Cmd-S` or `Ctrl-S`: Save current note as markdown locally
- `Cmd-P` or `Ctrl-P`: Save current note as PDF locally
- `Cmd-Shift-P` or `Ctrl-Shift-P`: Print current note
- `Cmd-,` or `Ctrl-,`: Open settings page

### Minimum system requirements

- 1GB RAM
- 300MB available hard drive space

### Recommended system requirements

- Modern CPU (Apple Silicon, Intel i5/i7/i9, AMD Ryzen, or Threadripper)
- 2GB RAM
- 1GB available hard drive space

### Additional Notes

The native desktop app is optional. Access Amplenote through any supported web browser: Google Chrome, Mozilla Firefox, Apple Safari, or Microsoft Edge.

**Browser compatibility note:** Brave Browser lacks full support due to their non-implementation of certain web APIs that Amplenote requires.

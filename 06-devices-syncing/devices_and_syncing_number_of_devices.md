# How many devices can I use?

> [← Help Index](../00-index.md) · Category: [Devices & Syncing](./index.md) · [Source ↗](https://www.amplenote.com/help/devices_and_syncing_number_of_devices)

## Platform & Devices Supported

Amplenote offers online or offline access across all desktop platforms, plus iOS and Android.

---

## Desktop

Windows, macOS, and Linux are supported as downloadable PWA apps with offline functionality, or through your preferred web browser.

### Amplenote Web App

No installation needed — simply log into the website. The browser-based version provides full functionality with internet access. To use Amplenote offline, install the desktop PWA version.

Supported browsers include the latest versions of Chrome, Firefox, and Safari on Windows, Linux, and macOS. Other browsers can be suggested on the voting boards.

### Amplenote PWA

For installation instructions on Windows, Mac, or Linux, visit the Installing Amplenote guide.

### iPad Installation

The native iPad app is available through the App Store and includes features like handwriting and drawing capabilities.

### Mobile Web

The mobile web version includes most native app functionality without requiring a download. However, native mobile apps are recommended for better testing and offline access.

# Widgets: iOS and Android agenda & lists

> [← Help Index](../00-index.md) · Category: [Devices & Syncing](./index.md) · [Source ↗](https://www.amplenote.com/help/mobile_ios_android_widgets_tasks_agenda_calendar)

Amplenote offers widgets that allow you to see your tasks and schedule on the lock screen or home page of your mobile device without opening the app.

## Widget Types

Amplenote provides three widget options:

- **Task List**: Displays tasks in a plain list with customizable sorting
- **Agenda View**: Shows tasks sorted by start time with day dividers for grouping
- **Quick Actions**: Enables common actions directly from your home screen

## Task List & Agenda View Widgets

### Features and Interactions

Both widgets display your to-do list with distinct presentations:

- **Task List** offers more visible tasks with flexible sorting options
- **Agenda View** groups tasks by day but displays fewer items simultaneously

Available interactions include:
- Tap a task to open it within its source note
- Tap the blue Plus sign to create a new task
- Tap the widget header to open the selected list in Tasks Mode

### Filtering, Sorting and Widget Settings

Long-press any widget to access its configuration options.

#### Task List Widget Options

| Option | Description |
|--------|-------------|
| List Type | Filter by: All tasks, Tag, Note filter, Shortcut, or Due today |
| Sort Order | Choose Task Score, Start Time, or Newest |
| Show Day Dividers | Creates horizontal dividers when sorting by Start Time |
| Show Task Duration | Displays task duration alongside start time |
| Notes Created by Others | Includes tasks from shared notes |

![Task List widget settings](https://images.amplenote.com/44841d32-cffb-11ed-8f5e-76979436bcb1/59344b68-b273-40c2-9262-e21b6e9aceef.jpg)

#### Agenda View Widget Options

| Option | Description |
|--------|-------------|
| List Type | Filter by: All tasks, Tag, Note filter, Shortcut, or Due today |
| Show Task Duration | Displays task duration alongside start time |
| Notes Created by Others | Includes tasks from shared notes |

![Agenda View widget settings](https://images.amplenote.com/44841d32-cffb-11ed-8f5e-76979436bcb1/26c30916-226f-4be7-b3a4-082bf0911cf3.jpg)

**Tip**: Transform a Task List widget into an Agenda-style widget by sorting by Start Time and enabling Day Dividers.

## Quick Actions Widget

This widget provides one-tap access to:
- Create a new empty note
- Start adding a new task
- Open Jots, Tasks, or Calendar mode
- Access Quick Open for searching notes and tasks

The Calendar icon displays a badge showing how many tasks have a start time for today, based on the widget's configured Task Domain.

![Quick Actions widget](https://images.amplenote.com/44841d32-cffb-11ed-8f5e-76979436bcb1/00d7d3c0-0d6f-45ef-8f1a-2ac487d15500.png)

## Adding Widgets to Your Home Screen

### Android

Widgets can be resized from 2x2 to 4x4 grid sizes:
- **Task List**: 2x2 to 4x4
- **Agenda View**: 3x3 to 4x4
- **Quick Actions**: Fixed 2x4 size

[Refer to Google's widget guide](https://support.google.com/android/answer/9450271?hl=en#zippy=%2Cadd-or-resize-a-widget) for installation instructions.

### iOS

The Task List widget offers three size options:
- 1x1
- 1x2
- 2x2

Other widgets have fixed dimensions:
- **Agenda View**: 2x2
- **Quick Actions**: 1x2

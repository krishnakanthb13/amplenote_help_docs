# How do I download mobile apps?

> [← Help Index](../00-index.md) · Category: [Devices & Syncing](./index.md) · [Source ↗](https://www.amplenote.com/help/devices_and_syncing_download_apps)

## Platform & devices supported

Amplenote provides online or offline access across all desktop platforms, plus iOS and Android.

## Desktop

Windows, macOS, and Linux users can access Amplenote as downloadable Progressive Web App (PWA) applications that function offline, or through any web browser.

### Amplenote Web App

The browser-based version requires no installation. Users simply "log into the site" to access full functionality with an internet connection. The platform supports the latest versions of Chrome, Firefox, and Safari on Windows, Linux, and macOS.

![Amplenote web app](https://images.amplenote.com/744a092c-0490-11e9-8157-5261ad5891d7/aa3733e3-76dc-4ce8-a22c-046f5f5f7eb3)

### Amplenote PWA

For offline capability on desktop systems, users should visit the installation guide for PWA setup instructions.

### Installing on an iPad

The native iPad application is available through the App Store and enables features like "handwriting and drawing on iPad."

### Amplenote mobile web

A mobile web version exists with most native app functionality, though it is "the least-used Amplenote platform" and may have bugs. Native apps are recommended for offline access and better stability.

![Amplenote mobile web](https://images.amplenote.com/744a092c-0490-11e9-8157-5261ad5891d7/e7ca470b-2f79-4c7c-a821-9c736ed5c0f3)

## How many devices can I use?

All Amplenote plans support unlimited device access across web, iOS, and Android platforms.

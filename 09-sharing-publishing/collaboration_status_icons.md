## Collaboration status indicators

Teams using shared tags frequently have multiple collaborators editing the same note simultaneously. Since Amplenote lacks real-time cursor visibility (as of November 2021), it helps to coordinate when two authors seek to concurrently modify a note.

The platform provides two status indicators that show active note engagement. These visual cues appear in the status bar and help teams manage simultaneous editing scenarios, which is particularly relevant for groups using shared tags for collaborative work.

![The two collaboration status indicators used to assess real-time activity in a note](https://images.amplenote.com/09708c7e-4cb9-11ec-aa44-9a8d989df9b3/e0282f62-e9c1-4357-af41-7eeb4568669e.gif)

## Behavior

- When a user loses window focus, the green background disappears.
- When a user moves to a different note, their icon is removed from the status bar.
- If a user leaves Amplenote while editing, their avatar persists in the status area until they return to close the app or navigate elsewhere.

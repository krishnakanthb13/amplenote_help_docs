# Publishing notes with background color and image

> [← Help Index](../00-index.md) · Category: [Sharing & Publishing](./index.md) · [Source ↗](https://www.amplenote.com/help/publishing_note_page_style_background_image)

## Overview

This feature is available to subscribers at the Unlimited and Founder levels. Amplenote allows publishers to customize the aesthetic of published notes using background colors and images.

![After setting 'Page Style' options on a note](https://images.amplenote.com/c607969a-6654-11ef-a232-b6c19b417745/83a25334-214c-4789-9fea-3e183b94cab3.png)

![A published note as it appears to viewers with applied styling](https://images.amplenote.com/c607969a-6654-11ef-a232-b6c19b417745/298002a6-bfc4-459f-8165-4c005ec0d897.png)

## Setting page style

To configure page styling, access the "Page Style" option through "More options" in the triple-dot note menu. From there, select "Edit Page Style" to choose colors and images.

![Page Style color and image selection interface](https://images.amplenote.com/c607969a-6654-11ef-a232-b6c19b417745/0eb640ec-9dbf-4006-968e-26c578e67ce8.png)

## Color selection

The selected color will alternate between "light" and "dark" versions based on the viewer's settings preferences.

## Image upload guidelines

For standard (non-full-width) images:

- The maximum recommended height-to-width ratio is 1:4.5 (or width-to-height of 1:0.2).
- Images exceeding this ratio may have their left/right edges cut off.
- Published notes display with 912-pixel-wide spacing (as of Q3 2024).

## Full-width image option

Enable the "Full-width image" toggle to extend images across the entire note width rather than constraining them to standard dimensions.

![Full-width image toggle option](https://images.amplenote.com/c607969a-6654-11ef-a232-b6c19b417745/98aee7a8-a549-4a72-94c6-75e051ef09d0.png)

## Editor experience

The selected background color and image apply both to published versions and the editing interface, creating a consistent visual presentation.

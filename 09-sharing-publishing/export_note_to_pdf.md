# Export a note to PDF

> [← Help Index](../00-index.md) · Category: [Sharing & Publishing](./index.md) · [Source ↗](https://www.amplenote.com/help/export_note_to_pdf)

There are three methods for exporting notes to PDF format.

## Option 1: Desktop App (recommended)

Downloading the native Windows/macOS/Linux client is the most handy and reliable way to export notes. Consult the official documentation on the native Amplenote Desktop app for specific hotkey instructions.

## Option 2: Omniexport plugin

A community-developed plugin called Omniexport provides another reliable export method, with accompanying video instructions available.

## Option 3: Print dialog

The browser's built-in print functionality enables PDF export.

- **Advantage:** Preserves color in code blocks and tables.
- **Drawback:** Open sidebars also print, so close them first.

**Instructions by platform/browser:**

- **macOS:** Press Cmd-P. **Windows/PC:** Press Ctrl-P.
- **Chrome / Brave / Edge:** Select "Save as PDF" from the printer options, then click "Save."
- **Safari:** Choose the "PDF" option at the bottom of the print dialog.
- **Firefox:** Select "Save to PDF" from the Printer dropdown, then click "Print."

# How do I prevent shared notes from being edited?

> [← Help Index](../00-index.md) · Category: [Sharing & Publishing](./index.md) · [Source ↗](https://www.amplenote.com/help/note_access_note_locking)

There are two paths by which you can prevent a shared note from being edited.

## View-only mode

The first path is to control the settings with which the note is shared. In the "Add a Collaborator" dialog, the collaborator permissions can be modified at any time. Changing the permissions to "View-only" means that the user who has the note shared can't make any changes.

![When a note is shared, the collaborator permissions can be modified at any time using the 'Add Collaborators' dialog](https://images.amplenote.com/aa2f6636-12f8-11eb-844d-ce170e0210a1/fde07ece-a3b2-4799-b23a-e4434e2c1dc0.png)

## Lock mode

The other option is to lock the note from being edited. This can also be useful even when a note isn't shared.

To lock a note, click the "Note Options" menu and select "More options." Then pick "Lock note." The appearance of your note will change, with a lock icon added and the note title grayed out.

![The appearance of this note when it is locked](https://images.amplenote.com/aa2f6636-12f8-11eb-844d-ce170e0210a1/1741699a-4af4-4c7b-bcfa-982d353a76d2.png)

To unlock a note, follow the basic sequence: Note Options → More Options → Unlock Note.

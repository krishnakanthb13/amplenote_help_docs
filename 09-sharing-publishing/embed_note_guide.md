# How do I embed notes in web pages?

> [← Help Index](../00-index.md) · Category: [Sharing & Publishing](./index.md) · [Source ↗](https://www.amplenote.com/help/embed_note_guide)

Full title: "How do I embed notes in other web pages? (e.g., blog, help center, wiki)"

## Purpose

Amplenote allows users to publish and embed note content across websites, blogs, help centers, and wikis using JavaScript integration. This feature enables distributing information-rich ideas globally in real time.

## Core process

1. First publish the note.
2. Access the "Publish" dialog's second tab for embedding options.
3. Configure embedding settings as needed.

## Configuration options

- **HTML to embed** — code to paste into web pages for loading a near-real-time version of the note.
- **Add Host Domain** (optional) — controls link behavior and stylesheet inclusion.
- **Host Domain** (optional) — specifies the publication domain.
- **Stylesheet** (optional) — controls how styling is interpreted.

## Advanced features

- **Professional styling:** A reference use case covers CSS-styled blogs that mimic Medium's design.
- **Load performance:** Content loads approximately instantly through CDN caching with a 2-hour time-to-live.
- **Sidebar navigation:** You can add a table-of-contents sidebar to embedded content.
- **Batch publishing:** The Webnotes plugin enables publishing multiple notes by tag with automatic index generation.

## Real-world examples

GitClear's help center and the Developer Analytics Encyclopedia demonstrate professional implementations that combine embedding with custom stylesheets.

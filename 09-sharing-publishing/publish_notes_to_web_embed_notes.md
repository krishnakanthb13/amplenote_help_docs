# How do I publish notes to the web?

> [← Help Index](../00-index.md) · Category: [Sharing & Publishing](./index.md) · [Source ↗](https://www.amplenote.com/help/publish_notes_to_web_embed_notes)

Amplenote enables rapid sharing of note content with select users, groups, or the public internet. The process of sharing with the internet is called "publishing" or "embedding."

Publishing embodies the "the case for sharing your work in public" philosophy. As you update a published note, readers see real-time changes, watching your creative process develop from an initial "work in progress" post through continued refinement.

## Publishing process

To publish notes, click the triple-dot note actions menu and select "Publish note." Then click "Create a public note" to access the publishing controls:

- **URL Slug** — a custom URL for special occasions.
- **Access** — controls whether search bots index the page (defaults to non-indexed for privacy).
- **Expires** — sets expiration dates for sensitive documents shared externally, though recipients could copy the URL before expiration.

## Styling and appearance

Related resources cover adding background colors/images and removing Amplenote branding from published content.

## Automatic link translation

Internal note links using the double-brackets syntax automatically convert to public links in published notes, provided the linked notes are also published.

## Multi-URL publishing

You can create multiple publishing tokens for the same note through "Generate another URL," which is useful for sharing with different groups or using custom URLs.

## Managing published notes

Delete published links by expanding the token options and clicking "Delete link." Recopy the publish URL by clicking the publish icon in the note header.

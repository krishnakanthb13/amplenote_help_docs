# Share groups of notes or tags via tag share

> [← Help Index](../00-index.md) · Category: [Sharing & Publishing](./index.md) · [Source ↗](https://www.amplenote.com/help/share_note_group_via_tag)

Full title: "Collaboration: Share notes or tags with individuals, groups, or the web"

## Overview

Amplenote provides three sharing options: individual notes, groups of notes via shared tags, and public web publishing. The first two require Amplenote accounts.

## Sharing individual notes

Two methods exist:

1. Use the `/invite` or `/add` slash commands within a note.
2. Click "Add Collaborators" from the note's triple-dot menu.

You can set permissions as "Edit" (read-write) or "Share" (read-only). After sharing, clicking the share icon displays how many people have access and allows you to adjust permissions.

## Sharing groups via shared tags

This feature enables sharing entire tag collections with collaborators. The process:

1. Hover over a tag's triple dot and select "Share tag."
2. Choose collaborators and set permissions.
3. Recipients see the tag at the `shared/[tag name]` path by default.

As shown in the demo video, regardless of who creates note content, if they apply the shared tag, the note will be available to all collaborators with appropriate permissions.

## Key behaviors

- Shared tags don't propagate hierarchy.
- The original tag sharer controls deletions.
- Recipient-created notes become controlled by the sharer's account.
- Removing a tag removes viewing access but preserves the note in the sharer's account.

## Additional features

- Bulk-add notes to shared tags via multi-note selections.
- View the note creator and sharer in the note details.
- Identify shared notes with visual indicators in Notes View.

# Ample Agent Pro: Quick Start & Usage Guide

> [← Help Index](../00-index.md) · Category: [Account & Subscriptions](./index.md) · [Source ↗](https://www.amplenote.com/help/ample_agent_pro_quick_start_usage)

## 🚀 Focus: Get Work Done with Plug-and-Play Frontier Models

Ample Agent Pro functions as "the glue that connects your projects to the highest-power reasoning available today." The plugin bridges note-taking with frontier AI models from OpenAI, Anthropic, Gemini, and Grok.

The service provides a monthly quota for basic tasks, then allows users to tap into their own API keys for unlimited access to the most powerful agentic models available.

## 🤖 Complimentary Features (within quota)

### Task Agent

Users can invoke "/agent" within a task to activate Task Agent. This feature accepts Rich Footnotes and task context, combines it with success criteria, then asynchronously works on the task via web searches and related notes. The output generates a "result note" linked from the original task.

### Note Agent

Accessed through Note Options, Note Agent enables transformations on notes. Example use cases include:

- Applying tags based on existing hierarchies
- Extracting action items
- Identifying removable words/phrases
- Rewriting for clarity
- Changing tone
- Generating titles
- Finding key points
- Converting to checklists
- Inserting supporting web articles
- Suggesting relevant illustrations

### Goal-Aligned Task Recommendations

After installing the Mission Control Dashboard plugin, Ample Agent Pro parses Quarterly Planning notes to suggest tasks aligned with goals and day of week.

### Batch Task Rescoring

Enter "rescore" in the Open Notes popup to adjust task priority weightings based on current mood and focus areas.

### Thesaurus

Select a word or phrase to receive "10 ideas" for context-aware replacements. Users can switch providers if suggestions prove inadequate.

### Summarize

The summarize feature excels with lengthy web captures or PDFs, or extended help documentation with multiple sections.

### Additional Core Features

- **Complete that thought**: Use `/complete` to finish sentences or paragraphs
- **Revise text**: Describe desired changes to selected content
- **Rhyming suggestions**: Select words to find rhymes
- **Grocery timesaver**: Organize unsorted grocery lists by store sections
- **Task suggester**: Use `/suggest` to synthesize notes into action items
- **Insert related notes (beta)**: Use `/related` to insert links to up to 10 similar notes

## 📡 Extended Features: Provider Synthesis

These features require API keys for OpenAI, Anthropic, Gemini, or Grok.

### Deep Research Agent

Accepts a note or longform prompt, allowing users to "choose **which agents** & **how much reasoning**" to apply to complex questions.

### Generate Image

Use `/image` to generate images from prompts, controlling effort level and dimensions via OpenAI's DALL-E.

### Note Search Agent

Describe desired content to hunt relevant matches within your account. Complex queries on large accounts may require 30-60 seconds.

### Note Chat

Use `/chat` to discuss current note content with an LLM for comprehensive suggestions.

## 🧠 Adding AI Provider Keys

Use the `/provider` slash command to add API keys for Anthropic, OpenAI, Grok, and Gemini. Keys propagate across platforms, and users then select preferred models from available options.

## ⛽ How much quota is included?

"An effectively unlimited number of **non-research** interactions (e.g., 'thesaurus,' 'revise,' 'complete the thought')" are available. Agent-based queries should allow "around 20-50 monthly calls" before requiring personal API keys.

## ♻️ Updating the plugin

Ample Agent Pro receives weekly updates through 2026. Check Account Settings => Plugins for update availability indicated by orange refresh icons or green checkmarks.

## 👋 Canceling Your Subscription

Visit Account Settings => Plugins, select Ample Agent Pro, and click "Manage subscription" to access cancellation options. "We are unable to offer partial-month refunds."

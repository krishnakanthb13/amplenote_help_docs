# Appendix III: Markdown content

> [← Help Index](../00-index.md) · Category: [Plugins](./index.md) · [Source ↗](https://www.amplenote.com/help/developing_amplenote_plugins/appendix_iii)

## Overview

The page describes Amplenote's markdown support for plugin development. According to the documentation, users should "Read all about Amplenote markdown in our dedicated reference page on Plugin API Markdown."

## Key Information

**Markdown Standards:**
The platform follows the GitHub Flavored Markdown Spec as its foundation for markdown formatting.

**Current Limitations:**
As of July 2024, "the markdown passed by plugins to the app is somewhat limited" and will expand over time to support additional Amplenote features.

**Supported Features:**
The documentation mentions that markdown can be used for:
- Applying foreground and background colors to text
- Creating Rich Footnotes
- Building tables
- Other formatting options

See also: [Plugin Markdown Reference](./plugin_api_markdown_reference_parse_markdown.md)

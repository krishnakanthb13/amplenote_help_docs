# What tasks are scheduled to start (due) today & tomorrow?

> [← Help Index](../00-index.md) · Category: [Use Cases](./index.md) · [Source ↗](https://www.amplenote.com/help/find_tasks_start_at_due_today_this_week)

Amplenote provides multiple methods to view tasks scheduled for today and tomorrow. The platform offers both optional setup recommendations and several built-in features for task discovery.

## Recommended setup: Task Domain (Optional, saves time in long-run)

The fastest way to browse upcoming tasks is via the Amplenote Calendar. New accounts automatically receive a "Work" Task Domain displaying tasks within notes tagged as `daily-jots` or `todo`. Establishing a Task Domain that encompasses notes containing your project tasks enables task discovery across multiple interface locations.

![Configuring a "Work" Task Domain in Amplenote](https://images.amplenote.com/71edc31e-40a1-11ef-930d-26e37c279344/4a881541-a527-4b1c-93f7-068cca402dc3.png)

## Jots suggestion

With a Task Domain configured, a link appears in Jots showing your daily scheduled tasks.

![A Jots suggestion link showing your daily scheduled tasks](https://images.amplenote.com/71edc31e-40a1-11ef-930d-26e37c279344/4278915b-759f-4048-b875-c77761029914.png)

## Tasks mode

The Tasks mode offers two primary options for viewing upcoming tasks:

### Sort by scheduled time

Access Tasks mode, click the triple-dot icon, and select "Scheduled time" from the sort options. This displays all tasks matching your tag selection, ordered by start date. Without a tag selection, all tasks appear ordered by proximity to today.

![Sorting tasks by scheduled time in Tasks mode](https://images.amplenote.com/71edc31e-40a1-11ef-930d-26e37c279344/b0235faf-d5c3-4c2c-ac58-23b4738e3da2.png)

### Filter by "Due today" or "Due this week"

Click "Due today" or "Due this week" filters in the left pane to display tasks starting today or this week, including overdue items.

For subset filtering: click "Filter tasks by note reference" for note-specific tasks, or click a tag below these filters, then Shift+click your preferred timeframe filter.

![Filtering tasks by "Due today" or "Due this week"](https://images.amplenote.com/71edc31e-40a1-11ef-930d-26e37c279344/8181a913-cfdb-423f-9226-9d3c4d656c6a.png)

## Calendar mode

With Task Domains configured, the Calendar pane provides visual representation of your schedule. The "4 day view" effectively visualizes near-future task distribution. Task colors correspond to note tag colors. Consult the Calendar documentation for setup details and color customization information.

![Entering Calendar Mode, choosing "4 day view" is a great way to visualize how your energy will be distributed in the near future](https://images.amplenote.com/71edc31e-40a1-11ef-930d-26e37c279344/db75af21-f9ea-489f-9f75-ac3b33077acd.png)

# Building habits (flexible recurrence)

> [← Help Index](../00-index.md) · Category: [Use Cases](./index.md) · [Source ↗](https://www.amplenote.com/help/habit_building_with_flexible_recurrence)

## Overview

Amplenote was designed to help users build habits and pursue long-term goals. The platform's founders emphasize that habit-building and goal-pursuit are interconnected, as they allow present decisions to shape future time allocation. Since time allocation is "the biggest determinant" of lived experience, habit-building tools represent significant leverage for sculpting life outcomes.

## Choose a habit, decide how often to do it

Setting up a new habit in Amplenote involves creating a task and configuring a few key fields. The process is straightforward on desktop platforms.

### Repeat: When task is complete

This setting activates Amplenote's "flexible recurrence" mode, the recommended approach for habits. This mode suits goals where "whenever I do this task, I want to do it again within the next X days."

Flexible recurrence contrasts with standard calendar fixed recurrence, where events occur on set intervals. For habits, exact timing matters less than consistent incremental progress.

### Start at: How often to do this habit?

When using "When task is complete" as the repeat setting, the "Start at" field defines the latest completion deadline. This represents when the next task instance schedules to the calendar if uncompleted by that time.

The company plans by end of 2021 to track consecutive completions of flexible recurring tasks before the Start Time plus duration. Users should check off tasks before the scheduled window ends to enable habit-building statistics.

### Hide until: When to start thinking about doing the habit again?

When marked complete, flexible recurring tasks move to "Completed tasks," and the next instance is created. The "Hide until" setting prevents premature visibility in notes and task lists.

"Hide until" is relative to "Start at"—for example, hiding a monthly task until one week before deadline to reduce cognitive clutter.

## Putting it together: scheduling a new habit on the Calendar

The easiest setup method involves clicking the desired start time in Calendar View, selecting the task, choosing "When task is complete," and specifying frequency.

For example, if you complete a morning workout before 8am, the next instance schedules two days later. Tasks can be dragged to specific times, with subsequent instances updating automatically on the calendar.

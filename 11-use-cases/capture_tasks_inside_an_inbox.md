# How to QUICKLY capture tasks (create an Inbox)

> [← Help Index](../00-index.md) · Category: [Use Cases](./index.md) · [Source ↗](https://www.amplenote.com/help/capture_tasks_inside_an_inbox)

## Overview

In Amplenote, tasks live inside notes rather than in a standalone inbox. While this keeps tasks within their original context, it can slow down rapid task capture. This guide covers methods to quickly capture new thoughts and ideas.

## ⚡ The fastest ways to capture new tasks

Amplenote provides a dedicated help page listing multiple rapid task capture methods across mobile, desktop, and tablet. That canonical resource should be consulted first for the complete list of options.

## ✍️ Capture everything inside Daily Jots

Daily jots serve as a convenient inbox because all task creation paths default to the current daily jot, eliminating the need to choose a destination manually and enabling faster task commitment.

## 🗺️ Quickly capture new tasks, outside & within Amplenote

### 1. Mobile widgets & quick task bar

Mobile clients offer built-in capture tools:
- Home screen widgets enable creating tasks with a single tap
- The "Quick Actions" widget (iOS and Android) includes an "Add a task" button
- A quick task bar at the bottom of the app allows task creation from any view
- iOS users can add tasks via lock screen widget before unlocking their phone

All mobile methods default to the current daily jot as the destination.

### 2. Create your task anywhere and just move it to your inbox

When working in Amplenote, the quickest capture method is to write tasks in the current note, then use the `!move` command to transfer them to your inbox. The `Ctrl-Enter` or `Cmd-Enter` hotkey toggles lines between bullets and tasks. You can type "today" in the note lookup menu to move tasks to the current day's daily jot.

### 3. Web and desktop Quick Open menu

Access the Quick Open menu using `Ctrl-O` or `Cmd-O`. Press `Tab` or use the top-left button to switch to "task lookup mode." Type your task description; if it doesn't exist, an option to create it appears. Press `Enter` to commit the task to the selected note or daily jot. Use `Ctrl-.` and arrow keys to select your daily jot if needed.

### 4. Calendar Mode quick task bar

Since approximately 75% of Amplenote users visit the calendar daily, the bottom-right quick task menu provides the fastest task creation from calendar mode. This tool allows customizing the default destination for new tasks. Alternatively, use the Peek Viewer to open your inbox note in the sidebar without leaving calendar context.

### 5. Capture tasks from external sources

External capture options include:
- The Amplecap browser extension
- The mobile share action
- The mail-to-note mechanism

## More on capture destinations

Capturing to daily jots removes cognitive friction by eliminating destination selection. However, captured tasks scatter across multiple daily jot notes. To view all captured tasks centrally, navigate to Tasks Mode and select the "daily-jots" tag to display all tasks in notes tagged accordingly.

Alternatively, use the Jot Suggestion at the bottom of the current jot to move all open tasks from that jot to another location.

## What happens during "Organize"?

The organize phase involves moving tasks from daily jots to more appropriate locations (e.g., "house chores," "hobby tasks") and prioritizing them. Community resources provide inspiration for task organization approaches, including guides on processing your inbox efficiently and organizing projects.

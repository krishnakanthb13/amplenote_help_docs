# How to QUICKLY capture tasks in Amplenote (create an Inbox)

> [← Help Index](../00-index.md) · Category: [Use Cases](./index.md) · [Source ↗](https://www.amplenote.com/help/capture_tasks_inside_an_inbox)

In Amplenote, tasks live inside notes rather than in a standalone inbox, which keeps them within their original context. This guide covers the fastest ways to capture new thoughts before they get away.

## ⚡ The fastest ways to capture new tasks

### One-tap capture on mobile

The mobile app shows a "➕" icon in the lower-right corner. Tap it, type your task, and Amplenote offers five initial guesses for the destination note. A "Guess note" button in the bottom row auto-files the task for you (requires Agent Pro).

![Ubiquitous one-tap task capture](https://images.amplenote.com/4214511a-dd43-11ee-9a0e-ca8ae82b63ae/3406d810-c06f-45ca-84be-7bfe8b445323.png)

![Quick capture on mobile, featuring 'Guess note' to auto-file tasks](https://images.amplenote.com/4214511a-dd43-11ee-9a0e-ca8ae82b63ae/d1c8af43-362f-4ef3-b3f7-392c48d990d1.jpg)

### Task options: repeat, duration, important

The "More options" button in the lower-right of the task capture form exposes repeat, duration, and important. "Weekday" or "weekend" flexible recurrence are recommended. You can also mark a task urgent/important, set a duration, or set a fixed recurring schedule.

![Task options: repeat, duration, important](https://images.amplenote.com/875d7480-a704-11f1-b6fb-1f66e72a9c4d/a5d0522a-df45-47c7-a576-0c09860a74cb.png)

### Include an image or video

An uploaded image or video on a task is embedded as a Rich Footnote in the task text.

![Include an image or video](https://images.amplenote.com/4214511a-dd43-11ee-9a0e-ca8ae82b63ae/a8275d4c-988b-4f18-8b72-6b9d6e4594d2.jpg)

### 📲 Sharing via "Share sheet"

Use the OS Share Sheet to send content into Amplenote from other apps; the content is placed in a task. Dedicated capture paths also exist for Apple Watch and voice.

![Sharing via the Share Sheet](https://images.amplenote.com/cc7078ee-32ad-11ed-9847-c2af19d2d6e3/5181ffaa-1202-4d61-8a5e-b8c0cb999195.png)

## ✍️ Capture everything inside Daily Jots

Daily jots serve as a convenient inbox because all task creation paths default to the current daily jot, eliminating the need to choose a destination manually and enabling faster task commitment.

![Capturing tasks into the current daily jot](https://images.amplenote.com/4214511a-dd43-11ee-9a0e-ca8ae82b63ae/791e623f-ab7a-4610-8aee-5e57e2d7c7b2.jpg)

## 🗺️ Quickly capture new tasks, outside & within Amplenote

### 1. Mobile widgets & quick task bar

Mobile clients offer built-in capture tools:
- Home screen widgets enable creating tasks with a single tap
- The "Quick Actions" widget (iOS and Android) includes an "Add a task" button
- A quick task bar at the bottom of the app allows task creation from any view
- iOS users can add tasks via lock screen widget before unlocking their phone

All mobile methods default to the current daily jot as the destination.

![The "Quick Actions" widget (iOS and Android). The "Add a task" button lets you jump to the task creation screen with a single tap.](https://images.amplenote.com/44841d32-cffb-11ed-8f5e-76979436bcb1/00d7d3c0-0d6f-45ef-8f1a-2ac487d15500.png)

![Adding a task from the iOS lock screen widget](https://images.amplenote.com/4214511a-dd43-11ee-9a0e-ca8ae82b63ae/57c1091d-1419-4f69-beaf-4531ad6d4c3b.jpg)

### 2. Create your task anywhere and just move it to your inbox

When working in Amplenote, the quickest capture method is to write tasks in the current note, then use the `!move` command to transfer them to your inbox. The `Ctrl-Enter` or `Cmd-Enter` hotkey toggles lines between bullets and tasks. You can type "today" in the note lookup menu to move tasks to the current day's daily jot.

![Capturing a task to the inbox by using the `!move` command. You can also type in "today" instead of "inbox" to move the task to the current daily jot instead.](https://images.amplenote.com/4214511a-dd43-11ee-9a0e-ca8ae82b63ae/fc3035a2-d1a9-4065-84f9-6be9a5feafcd.gif)

### 3. Web and desktop Quick Open menu

Access the Quick Open menu using `Ctrl-O` or `Cmd-O`. Press `Tab` or use the top-left button to switch to "task lookup mode." Type your task description; if it doesn't exist, an option to create it appears. Press `Enter` to commit the task to the selected note or daily jot. Use `Ctrl-.` and arrow keys to select your daily jot if needed.

![Creating a task from the Quick Open menu on web and desktop](https://images.amplenote.com/921f7fe4-fb70-11ea-a4f3-1a263ad550a8/6035a9c8-7a94-41fa-a24e-6f00f91f8da1.gif)

![When creating a new task, you can choose between adding it to the last note that was open or to your Daily Jot.](https://images.amplenote.com/4214511a-dd43-11ee-9a0e-ca8ae82b63ae/967c12fb-889d-4bfa-a658-bd5ba21dd77e.gif)

### 4. Calendar Mode quick task bar

Since approximately 75% of Amplenote users visit the calendar daily, the bottom-right quick task menu provides the fastest task creation from calendar mode. This tool allows customizing the default destination for new tasks. Alternatively, use the Peek Viewer to open your inbox note in the sidebar without leaving calendar context.

![The quick task bar in Calendar Mode](https://images.amplenote.com/c5a402ac-90e1-11eb-bbea-1e34e7aa6740/75a6f89c-342a-4511-b5e3-6c8e16e52b9c.png)

## More on capture destinations

Capturing to daily jots removes cognitive friction by eliminating destination selection. However, captured tasks scatter across multiple daily jot notes. To view all captured tasks centrally, navigate to Tasks Mode and select the "daily-jots" tag to display all tasks in notes tagged accordingly.

Alternatively, use the Jot Suggestion at the bottom of the current jot to move all open tasks from that jot to another location.

![Viewing all tasks captured to daily jots via the daily-jots tag in Tasks Mode](https://images.amplenote.com/4214511a-dd43-11ee-9a0e-ca8ae82b63ae/e973d05e-0d47-4695-be90-696d94e522e8.png)

## What happens during "Organize"?

The organize phase involves moving tasks from daily jots to more appropriate locations (e.g., "house chores," "hobby tasks") and prioritizing them. Community resources provide inspiration for task organization approaches, including guides on processing your inbox efficiently and organizing projects.

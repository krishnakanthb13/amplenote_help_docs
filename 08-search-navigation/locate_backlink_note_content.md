## What are Backlinks?

### Example use case

Backlinks aggregate all past conversations on various topics. Common use cases include collecting mentions around:

- People you're working with
- Ideas to pursue on work projects
- Facts about personal interests
- Classes being taken at school

![Backlinks being used to collect all tasks pertaining to a topic, like "Amplenote Ideas"](https://images.amplenote.com/21768b9a-fb78-11ea-b757-1a263ad550a8/c1c1d89c-9f20-4d65-ad67-d036a74c3987.png)

!["Amplenote Ideas" note collects each mention of the note in the "Backlinks" tab](https://images.amplenote.com/21768b9a-fb78-11ea-b757-1a263ad550a8/74ec7d78-1279-453f-a95f-49c7be301b9e.png)

To create links quickly, use the note linking guide for "@" and double-bracket "[[" notation, or type a note name into the Rich Footnotes URL field.

![Creating a link into a note through the Rich Footnotes popup](https://images.amplenote.com/21768b9a-fb78-11ea-b757-1a263ad550a8/5c5ed06b-d50d-4dab-9ddd-14a885c2e57e.gif)

### What will get shown in the Backlinks tab?

The content displayed depends on where your link occurred:

**Link in a paragraph**: The entire paragraph containing the link appears in the Backlinks tab.

![The Amplenote help page for setting up Shortcuts is linked to from the page for Jots](https://images.amplenote.com/21768b9a-fb78-11ea-b757-1a263ad550a8/c31f29f9-1ee3-4f2e-a2c7-69da8ab94c7b.png)

**Link in a task or bullet item**: When linking from within a hierarchy, "the entire hierarchy is included in the Backlinks tab."

![When a note link occurs in the base bullet, all of the child bullets are included in the Backlink](https://images.amplenote.com/21768b9a-fb78-11ea-b757-1a263ad550a8/938c072e-639b-45db-86a2-03cca497653c.png)

**Link in a heading**: All content displays up until the next heading of equal or greater value, effectively allowing entire notes to appear if the link is within an h1 at the note's beginning.

![Linking to "bread chronicles"](https://images.amplenote.com/21768b9a-fb78-11ea-b757-1a263ad550a8/1ac6b61e-34d4-411d-b69b-782ff8e00fc6.png)

![All content until the next h2 header is shown among the Backlinks](https://images.amplenote.com/21768b9a-fb78-11ea-b757-1a263ad550a8/f2222c2c-1a84-4d12-86b3-49c83e76e677.png)

## Advanced Backlinks

### Renaming Backlinks

When link text differs from the note title (due to note renaming, using Ctrl-K over arbitrary text, or linking to specific headings with #), you can update references. Scroll to the Backlinks tab and click the rename button, then select "Update X references to current title" to change all selected links.

![If this button is missing, that means Amplenote didn't find any references to the current note that differ from the title](https://images.amplenote.com/21768b9a-fb78-11ea-b757-1a263ad550a8/a5d8ea50-ae1f-4017-8896-65c688f0bf77.png)

![In this image, we filtered the references that can be renamed by typing in the `#` character](https://images.amplenote.com/21768b9a-fb78-11ea-b757-1a263ad550a8/9a745b31-d82d-482f-a4fb-47ec115da23e.png)

### Filtering Backlinks

Filter backlinks based on the source note's tags to manage lengthy connection lists. This enables finding "all instances in which you meaningfully interacted" with specific concepts across tagged notes.

![Enter a tag to filter the list of backlinks that are shown](https://images.amplenote.com/e7a0a100-1e02-11eb-a21d-769e40351abc/c284fccc-1730-4d71-9317-b1107233957b.gif)

### Unlinked references

Discover mentions of your note's title that aren't yet linked. In the "Find more references to this note" section, expand to see all notes containing your current note's title. Click the link icon to convert individual references into official backlinks, adding semantic meaning to your notebase.

![Note the "Find more references to this note" now available in "Backlinks"](https://images.amplenote.com/e7a0a100-1e02-11eb-a21d-769e40351abc/5b85c852-4059-4eda-a72e-a5e70771217e.png)

![Notes that reference the current note title, one click to convert them to official backlinks](https://images.amplenote.com/e7a0a100-1e02-11eb-a21d-769e40351abc/967b8297-83ab-401e-b011-7b52d6a83adc.png)

## Completed Task Stats: Combining Productivity & Positive Experiences

### Overview

Amplenote tracks completed tasks through "Victory Value," which measures progress on meaningful work. Unlike Task Score for open tasks, Victory Value rewards completion of important tasks aligned with long-term goals while considering mood and wellbeing alongside productivity metrics.

![The Completed Tasks "Trends" Tab: Go deep into understanding what got done, and how it felt to do it](https://images.amplenote.com/a471f122-82a7-11f0-be91-f1fde84f08ce/1aa3e6e9-89dd-4308-9da8-764fd0394b7b.png)

## ⚙️ Define What Matters Via Victory Value

Victory Value scoring begins at 1 point and increases based on:

- **Important task designation** (Ctrl + I hotkey)
- **Note-level Victory Value multipliers** from tag properties
- **Positive mood ratings** recorded near task completion
- **Task dependencies** and other completion factors

The system emphasizes that "being the most productive person in the world isn't worth much if you're miserable while you do it."

## Fine-Tune Victory Value During Monthly Review

Users should conduct periodic audits by:

1. Navigating to Tasks View and toggling Completed Tasks visibility
2. Clicking numbers next to tasks to adjust Victory Value based on actual value gained
3. Using this review to maximize signal about which task types merit future focus

## 📈 Completed Task Stats: Trends

Access stats via the chart icon in the desktop client's left panel. The Trends tab displays:

- **Victory Value accumulation** over selected time ranges
- **Mood Ratings** alongside productivity metrics
- **Monthly daily breakdown** showing energy distribution across different activity areas
- **Top 3 monthly tasks** for motivation and inspiration

The daily breakdown helps answer questions about time allocation, high-impact weeks, and opportunities seized or missed.

## 🏋️ Completed Task Stats: Recurring Streaks (Habit Building)

The Task Streaks tab tracks follow-through on recurring tasks. Streaks remain active when tasks are marked complete on or before their scheduled start date—not necessarily on completion day.

**Key considerations:**

- Mark tasks complete at their scheduled time, even if finished earlier
- If marking late, reschedule subsequent tasks to maintain cadence
- Leverage flexible recurrence options distinguishing weekday (work) versus weekend (personal) tasks

**Primary use case:** Building new habits while staying accountable to quarterly planning intentions.

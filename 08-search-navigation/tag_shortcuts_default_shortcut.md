## Organizing with Tags

Amplenote employs tags to help categorize and prioritize notes, enabling users to organize, search, filter, and share notes efficiently.

## On Youtube: All About Tagging

Three video resources are available:

- Basics of tagging, filtering by tags and nested tags

## Adding Tags to Notes

Process for tagging:

1. Click "Add a tag" link in the note header
2. Enter the word or phrase for categorization
3. Press Enter or Return to save
4. Click the # icon next to a tag to change its color

Multiple tags can be applied to a single note. Tag suggestions appear as you type to prevent duplicate hierarchies.

## Tag Naming Rules to Prevent Duplicate Hierarchies

Amplenote implements automatic rules to minimize redundant tag structures:

**Lowercase conversion:** All tag hierarchy names convert to lowercase automatically (e.g., `Blog/Draft` becomes `blog/draft`).

**Spacing and punctuation replacement:** All spaces and punctuation convert to hyphens (e.g., `Tech Blog/Drafts` becomes `tech-blog/drafts`).

The system also auto-suggests existing tag names while entering to encourage reuse over recreation.

## How Do Nested/Hierarchical Tags Work?

Nested tags (hierarchical tags) like `hobby-projects/golf-tournament` or `todo/dev/client-a` help manage multiple project-specific tasks. Multiple nested tags can apply to any note.

### Two Common Types of Nested Tags

**Knowledge Management Collections and Project Knowledge Notes:**
Examples include tags for evergreen reference topics:

- `gitclear/blogs`
- `recipe/thai`
- `personal/dev/devops`
- `people/influencers/reddit`
- `amplenote/help/organizing-tags`

These may contain ephemeral tasks relevant only to research contexts.

**Project Tasks:**
Tag hierarchies destined to become Tag Shortcuts in Task View or Task Domains:

- `todo/gitclear/dev`
- `daily-jots/may-2021`
- `blog/to-write`
- `recipes/ingredients-to-buy`

**When a Note Contains Both Knowledge and Tasks:**
A single note can receive multiple tags (e.g., `recipes/indian`, `todo/grocery`, `personal/recipes/favorites`).

### Managing Tasks Across Multiple Projects

Apply tags like `todo/project-a` and `todo/project-b` to notes containing relevant tasks. Access them through Tasks View mode or the Amplenote Calendar with Task Domains for scheduling.

![Control which notes are shown via tag in the Calendar task list](https://images.amplenote.com/8f50f93a-fae1-11ea-95c1-f200a12bf340/6ee8d947-8a3c-41a6-add6-17b219869ce6.gif)

## Browsing Notes by Tag

Notes can be browsed through tag hierarchies in the sidebar. Quick Open references notes matching hierarchies. Nested tags serve as the primary means to navigate between productivity contexts in tasks mode.

### Multi-Tag Selection

Select combinations of tags using Shift+click on tag names (Shift+click again to exclude). This filters notes tagged with multiple tags simultaneously.

Example use case: viewing all work-related tasks that are also collaborative notes (tagged with `shared-with-me`).

The `in:` selector with comma-separated tags achieves similar filtering: `in: amplenote/help-pages, auto-archived`

![Selecting multiple tags to filter notes by more than one tag at once](https://images.amplenote.com/8f50f93a-fae1-11ea-95c1-f200a12bf340/794441a5-adcf-4e23-9687-cab51ca8b8b7.png)

## Tag Shortcuts and the Default Shortcut

Tag Shortcuts affix important tags in the leftmost pane for quick access to tagged content. A dedicated help page covers creating, renaming Tag Shortcuts, and defining a "Default Shortcut" (a tag or note opened first when entering a mode).

## Creating a New Note with Tag Hierarchy

Tag hierarchies can be specified when creating notes using the `@` notation. Example: `@recipes/pizza/BBQ Hawaiian Pizza` automatically applies the tag hierarchy `recipes/pizza` to the new note.

![Creating a new note with a tag hierarchy using the @ notation](https://images.amplenote.com/8f50f93a-fae1-11ea-95c1-f200a12bf340/8ecefc3b-c2cb-4fe7-82f0-40be36b88e49.png)

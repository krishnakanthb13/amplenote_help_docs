# All about searching, lookup and filtering for notes and tasks

> [← Help Index](../00-index.md) · Category: [Search, Lookup & Navigation](./index.md) · [Source ↗](https://www.amplenote.com/help/all_about_search_lookup_filtering)

## Searching inside a note (find in note)

### Web and PWA: built-in browser search

Modern browsers provide built-in search functionality (typically `Ctrl-F` or `Cmd-F`) that works well for locating text within long notes in the web client.

### Mobile and native desktop clients

Mobile apps and native desktop clients (Windows/macOS/Linux) offer a "Search note..." feature accessible through: triple dot menu → "More options…" → "Search note..."

This enhanced version searches Rich Footnotes in addition to regular note content.

![Open triple dot for a note, then 'More Options...' -> 'Search Note'](https://images.amplenote.com/6505a3de-cd28-11ee-8ec2-66615dfa637a/bd9f7401-fe29-42e2-ba1b-ecbec197fcf6.png)

## Searching for notes

Amplenote provides two primary search methods:

### Quick Open (recommended for everyday use)

Quick Open is accessed via `CMD-O` (macOS) or `Ctrl-O` (Linux/Windows). It searches note titles and supports multiple filtering options. The feature displays recently visited notes and modes when first opened, before typing.

[Full documentation available](./organizing_notes_quick_search.md)

![Quick Open can look up notes by title, it supports multiple filtering options and also user to jump between view modes (e.g., jots, notes, tasks, calendar)](https://images.amplenote.com/692a1aa2-b81e-11eb-99b8-eaa3c46a2c1d/a2632d98-c634-483c-a197-ec00dc7bf525.gif)

![Quick Open menu](https://images.amplenote.com/692a1aa2-b81e-11eb-99b8-eaa3c46a2c1d/80bb70f8-a1b4-4b1f-9f60-530886cc80dd.png)

### Full text search

Full text search examines complete note contents, including OCR-recognized text from images. Accessed via the "Search notes" input field in navigation, it searches auto-archived notes and uses fuzzy matching (which may produce noisier results than Quick Open).

**Mobile access:** Tap the magnifying glass, then select "Full search"

![Tap the magnifying glass, then choose 'Full search'](https://images.amplenote.com/692a1aa2-b81e-11eb-99b8-eaa3c46a2c1d/d04c147b-8494-4c71-9ba4-bf331e72327b.gif)

#### Excluding note content from search results

A toggle allows searching based solely on note titles rather than matching against full content.

![Excluding note content from search results](https://images.amplenote.com/c0cee21c-24a2-11ef-8ea9-9e00649d95f8/88043638-1c4b-4164-b395-6bc9e7445a14.png)

#### Saved searches in Notes Mode

Tag, group, and keyword combinations can be saved to shortcuts for quick access later.

#### Searching from Graph Mode

Quick Open and full text search are available in Graph Mode with an options menu toggle to switch between them.

![Searching from Graph Mode](https://images.amplenote.com/c0cee21c-24a2-11ef-8ea9-9e00649d95f8/d3147d4e-ab8f-4a86-af34-aa2f2d2f2978.jpg)

### Filtering notes

Multiple filtering options exist for both search methods. [See filtering documentation](./search_filter_tags_groups.md)

![Filtering notes](https://images.amplenote.com/4cf4e692-e58a-11ec-a6de-f2e2bc5c6b4b/eb97bb7c-b126-440e-b286-d0188d1e3047.png)

### iOS Spotlight search

iOS users can swipe down from the home screen to search notes by title using Spotlight integration.

![iOS Spotlight search for notes](https://images.amplenote.com/c0cee21c-24a2-11ef-8ea9-9e00649d95f8/230343db-d639-462f-9a95-611fef1b439a.png)

## Searching for tasks

Two methods exist for task searching:

- Look up tasks by description using Quick Open
- Filter by tags and note references (backlinks/projects)

![Filtering tasks by Note References](https://images.amplenote.com/62ccdd04-76da-11ec-b1d8-1eca04f4fc71/b23491ac-7f4a-4013-b69c-80166240044e.gif)

### Saved task searches

Task filters applied in Tasks Mode and Calendar Mode can be saved to shortcuts for easy access.

## Searching for backlinks/note references

The Backlinks panel at the bottom of notes displays all linking notes. Filtering options are available when the list grows lengthy. See the [backlinked note references filtering documentation](./locate_backlink_note_content.md).

![Enter a tag to filter the list of backlinks that are shown](https://images.amplenote.com/e7a0a100-1e02-11eb-a21d-769e40351abc/c284fccc-1730-4d71-9317-b1107233957b.gif)

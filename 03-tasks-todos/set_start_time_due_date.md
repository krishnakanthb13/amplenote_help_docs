# Set a task Start Time (Due Date) using natural language

> [← Help Index](../00-index.md) · Category: [Tasks & Todo Lists](./index.md) · [Source ↗](https://www.amplenote.com/help/set_start_time_due_date)

## Overview

Amplenote provides multiple methods to assign a Due Date/Start Time to tasks. Setting a Start Time increases the task's value on its scheduled date and displays it in the Calendar if the note is included in the current Task Domain.

## Methods for Setting Start Times

### Via Task Icons

The quickest approach uses Quick Actions visible when hovering over a task. Users can also access the "Start time" field through Task Details options.

### Via Task Details

When setting a start time in Task Details, users may employ either a date picker or natural language input. The system supports date calculations as documented in the help resources.

### Via Task Commands

Users can utilize task commands to set Start Times, specifically the "Start (formerly Due)" command from the keyboard-driven menu.

### Via Natural Language Recognition

Tasks can have Start Times assigned directly from the description box using date and time formats. When the system detects date-like text, it prompts for confirmation. Users should "Press `Enter` when the Start Time prompt appears to apply it to the current task." Those who don't wish to apply a detected date can simply continue typing to dismiss the prompt.

## Key Features

- Start Times dictate when tasks should receive attention
- Connected calendar systems (Google/Outlook) schedule tasks at the specified time
- Tasks receive 10 bonus points on their due date for visibility
- Reminders trigger at the designated time
- Natural Language Processing currently does not support recurrence rules

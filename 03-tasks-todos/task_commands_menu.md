# Keyboard-driven ! Task Commands Menu

> [← Help Index](../00-index.md) · Category: [Tasks & Todo Lists](./index.md) · [Source ↗](https://www.amplenote.com/help/task_commands_menu)

## Using the Keyboard-driven ! Task Commands Menu

Amplenote provides convenient actions when the `!` key is pressed at the beginning of a task or mid-task after a space. Some options are also available in bullet points.

![Entering "!" after a space in a task to open the Task Commands Menu](https://images.amplenote.com/fc49046e-1315-11eb-930c-0acc36b7fd62/fe7c1c72-3f82-4892-a738-38f8a29f7247.png)

**Currently 14 options are available** in the Task Commands Menu.

Most actions are also accessible through Task Details, but the Task Commands menu expedites access to these features through keyboard shortcuts.

---

## Move and duplicate tasks

### Copy
Copy a task from its current note into a new note. Useful for maintaining a main task list alongside a daily task list via Jots. Tasks remain on the main list if not completed that day.

### Move
Remove a task from the current note and place it at the top of a different note. After selecting "Move," an input box displays available note names.

![Input box with note names after selecting the Move option](https://images.amplenote.com/fc49046e-1315-11eb-930c-0acc36b7fd62/ed1c1062-30ef-45fc-ac83-2231c5c8c39e.png)

### Copy/move to specific section
When specifying a destination note, type a `#` hashtag to search for the specific section or heading where the task should be sent.

![Using a hashtag to search for a specific section or heading](https://images.amplenote.com/dd0d06ba-854c-11ef-8a22-62fb339586e5/890ed4af-af70-485a-8208-7c89adce4551.png)

## Complete or dismiss tasks

### Complete
Marks a task as complete. Also available via keyboard shortcuts.

### Cross-out
Cross out a task without marking it complete. Available via keyboard shortcuts.

### Dismiss
Hide a task temporarily. Available via keyboard shortcuts.

### Delete
Permanently remove a task. See documentation for task deletion details.

---

## Set start times, durations and recurrence

### Start (formerly Due)
**💡 Update August 2022**: Natural language can now describe dates directly in the task description without using `!start`. The Start field accepts date labels from Task Details.

![Setting a Due Date / Start Date via Task Command](https://images.amplenote.com/fc49046e-1315-11eb-930c-0acc36b7fd62/10f5fe46-b05e-4a30-bafa-d5d80f415254.png)

### Duration
Configure how much time a task occupies when dragged onto the calendar. Essential for time-blocking, especially combined with Start and Every commands.

![After typing `!duration` you can specify how many minutes your task will last for.](https://images.amplenote.com/fc49046e-1315-11eb-930c-0acc36b7fd62/1f6ca0b6-715c-4c7f-94a1-fdbfad32130e.png)

### Hide
Hide a task until a later date or time.

### Every
Set how many days after task completion it should restart. Choose recurrence frequency from available options.

![After choosing 'Every,' you'll get a choice about how often you want the task to repeat](https://images.amplenote.com/fc49046e-1315-11eb-930c-0acc36b7fd62/8cd4b929-80ca-450d-8a1c-ddbc85027051.png)

## Control the Score of a task

### Max Score
Set the task score equal to the highest-value task in the current note.

### Reset Score
Remove accumulated task score from inactive tasks.

### Important & Urgent
Mark tasks with priority levels. Available via keyboard shortcuts.

---

## Bullet commands

Bullet commands include:

- Cross-out the current bullet
- Convert a bullet to a task
- Duplicate a bullet
- Delete the current bullet

# Create a Task (To-Do List)

> [← Help Index](../00-index.md) · Category: [Tasks & Todo Lists](./index.md) · [Source ↗](https://www.amplenote.com/help/tasks_and_todos_create_list)

## Creating tasks & to-do lists, and configuring task options

Tasks are integral features in Amplenote, residing within notes while remaining easily accessible separately. This guide covers task creation and configuration options.

## Different ways to add new tasks

### Create tasks from within note or a jot

The primary method involves two approaches:

1. **Type `[]` (brackets with space)** followed by your task text, then check the box to mark complete
2. **Click the check icon** in the formatting bar on desktop or mobile

Tasks appear in Tasks View Mode under whatever tags you've assigned to the note.

![Creating a new task by typing brackets, followed by a space. Then check it to mark as complete](https://images.amplenote.com/cce04e4c-fad0-11ea-95c1-f200a12bf340/0a9325a9-0b09-4de5-97a5-de3009b27922.gif)

### Create a task from mobile Quick Task Bar

Reference the dedicated help page on the iOS & Android Quick Task Bar for mobile task creation.

### Create a task from the Quick Open menu

See the Quick Open navigation help page for instructions on quickly creating new tasks.

### Create a task from email

Using the mail-to-note feature, you can forward emails to your to-do list by creating a contact with your note's email address.

### Create a task from within a mobile app

**Home screen widgets:** Check the widgets help page for iOS and Android options.

**Share Sheet:** Use the Share Sheet feature to send text, links, images, and PDFs from mobile.

**iOS voice input:** Record voice notes using Siri Shortcuts for speech-to-text capture.

### Creating a subtask

Use Tab to indent child tasks or Shift+Tab to outdent them. Example structure:

- 🎁 Send Santa an updated present list
  - Grow 1" by tomorrow
  - Watch the paint dry

### Create a task via system-wide hotkey

Install the Amplecap browser extension (Chrome or Firefox) to define an Omnicapture hotkey for task capture outside Amplenote. A future native desktop app update will introduce configurable system-wide hotkeys.

### Set a "Start Time" (aka "Due Date")

A dedicated page explains how to set start times and due dates for tasks.

### Set a Reminder

In Task Details, check the notification option to receive alerts at the task's due time. Configure notification preferences in Settings > Notifications for push, browser, or email alerts.

### Is it Urgent, Important, Both or Neither?

Based on the Eisenhower Method (Covey Quadrants), classify tasks:

**Urgent tasks:** Bad consequences occur within days if incomplete.

**Important tasks:** Tasks align with your long-term or short-term goals.

General principle: Minimize urgent tasks and maximize important ones.

![Setting whether a task is urgent or important](https://images.amplenote.com/cce04e4c-fad0-11ea-95c1-f200a12bf340/f6e4730b-5f8e-4133-8268-7fd66fb6ce77.png)

Set urgency and importance using task commands or the Task Details panel.

### Set the Duration

Specify estimated task duration from four options:

- Tasks under 90 minutes are recommended for breakdown
- 15- and 30-minute tasks often feel more actionable
- Task Score prioritizes shorter-duration tasks
- Shorter tasks accumulate score faster and reduce list clutter quickly

### Edit the Task Score

Click the Task Score number to enter a new value. Alternative methods include:

- Reset score via task commands
- Increase score to maximum via task commands
- Batch-edit scores within a note

![Editing the Task Score](https://images.amplenote.com/cce04e4c-fad0-11ea-95c1-f200a12bf340/22869c94-3a6d-4c10-935d-7e6867369c8d.png)

## Making tasks go away 🗑️

### ✅ Completing tasks

Three completion methods:

1. Click the checkbox
2. Use keyboard shortcut for marking complete
3. Use task command menu

Completed tasks move to the `Completed` tab, displaying your productivity score.

**Want inline tasks?** Configure strikethrough for completed tasks instead.

### ⏳ Rewriting history by moving completed tasks

In the `Completed` tab, use drag-and-drop to reassign a task's completion date to another day.

![In the `Completed` tab of a note, use drag-and-drop to move a task's completion date to another day.](https://images.amplenote.com/cce04e4c-fad0-11ea-95c1-f200a12bf340/2d2503bb-02c2-4261-b225-09dcb6476f76.gif)

### ✏️ Dismissing tasks

Dismiss tasks for half accumulated score when they're partially complete, handled by others, or no longer necessary. Dismissing recurring tasks preserves upcoming occurrences.

Reference the associated keyboard shortcut documentation for details.

![Dismissing a task](https://images.amplenote.com/cce04e4c-fad0-11ea-95c1-f200a12bf340/2d734b3d-8b53-4e0d-8d9d-104c030d08c8.png)

### ☑️ Crossing out tasks

See the dedicated help page on strikethrough options for completed tasks.

### 🗑️ Deleting Tasks

Remove tasks entirely by clicking the line and pressing Delete or Backspace. Alternative methods:

- Expand task details and select Delete
- Use the associated task command

![Deleting a task](https://images.amplenote.com/a87fe9b8-03d3-11e9-8493-fed38e33333f/3193b6ee-7a98-46cf-a05b-aa743107da02)

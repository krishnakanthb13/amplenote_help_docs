## Completed tasks: What's getting done at a glance

Users interested in life optimization and GTD methodology often want to track how many tasks they complete and what types of tasks they're finishing over specific time periods. Amplenote provides multiple methods for viewing completed tasks.

## Complete Task Stats

Amplenote offers several options to review completed tasks.

### Recommended option: Completed Task Stats section ✨

As of 2025, Amplenote features "a dedicated section of the app for Completed Task Stats" to provide insights into time allocation and happiness correlations.

Users should consult the full documentation on the dedicated Completed Tasks Stats help page for comprehensive information.

The following options represent task review methods that predate the Completed Task Stats feature.

### Option: View Completed Tasks on Calendar

When tasks are marked complete, they appear on the calendar at the time of completion. Within Settings => Task Domains, users can control whether completed tasks display on external calendars or only within Amplenote.

The calendar view works best for reviewing weekly task completion. With tag coloring enabled, users gain visual insight into their focus areas during the past week.

### Option: Completed task list in Tasks pane

The Tasks pane includes a toggle between "Open" and "Completed" tasks. Selecting completed tasks displays a filterable, daily breakdown of finished work.

This view serves as an ideal location for periodically adjusting Victory Value scores for tasks with strong long-term ROI. The Completed Stats Help Page discusses a method for reviewing completed tasks and assigning Victory Value.

### Option: Completed task progress per-note

Every note displays task completion data over time. The Completed tasks tab shows the past six weeks of completed Task Score by day. Below that, users see yearly Task Score completion broken down weekly.

These graphs effectively track productivity trends when tasks originate from a single note.

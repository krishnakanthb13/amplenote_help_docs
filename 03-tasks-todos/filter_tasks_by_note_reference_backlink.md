# Filtering tasks: tags and note references (backlinks/projects)

> [← Help Index](../00-index.md) · Category: [Tasks & Todo Lists](./index.md) · [Source ↗](https://www.amplenote.com/help/filter_tasks_by_note_reference_backlink)

## Overview

Amplenote allows you to filter tasks using two primary methods: tags and note references. As the documentation puts it, "One of the most handy ways of filtering your tasks is by the tag of the note they are part of / the note that they link to as an Inline Tag."

When you link a task to a specific note, that task becomes visible when filtering by any of that note's tags. This is especially useful for managing work that spans multiple projects or daily journals.

![Filtering tasks by the tag of the note they are part of or link to as an Inline Tag](https://images.amplenote.com/8dbdd952-f9c7-11ed-9bd0-aa1e76b1d5f5/f63d9dbc-0815-4668-9969-aa8edc9b38da.png)

## Filtering in Tasks Mode

The Reference Filtering menu appears above the formatting bar in Tasks Mode. To use it:

- **Click** to add a note filter
- Adding multiple notes displays only tasks referencing **both** notes
- **Shift-Click** to exclude tasks referencing that note

![Use the new Filter Tasks by Note Reference button to start narrowing down your list of to-dos.](https://images.amplenote.com/62ccdd04-76da-11ec-b1d8-1eca04f4fc71/b23491ac-7f4a-4013-b69c-80166240044e.gif)

### Saving Filters

You can preserve your filter selections by clicking the star icon next to the selected task tag title for future use.

## Calendar Mode Filtering

In Calendar Mode, the filter icon opens the Note Reference Filter menu with similar controls. However, note that "The list of notes to filter **on** is **not** determined by the current Task Domain."

![Filtering tasks by note reference in Calendar Mode](https://images.amplenote.com/62ccdd04-76da-11ec-b1d8-1eca04f4fc71/dc6ae12a-cb5a-418b-b972-a6493c87b6b6.gif)

## Advanced Techniques

![Useful tips for filtering tasks by tags and note references](https://images.amplenote.com/62ccdd04-76da-11ec-b1d8-1eca04f4fc71/99131eef-bf92-4cb7-937d-503e48019849.png)

**Combining Filters**: You can apply both traditional tag filters and reference filters simultaneously. For example, combine a `work` tag filter with a `@next` reference filter to see only work-related next tasks.

**Excluding References**: Using Shift-Click removes tasks associated with specific notes.

![Excluding note references from the task filter](https://images.amplenote.com/62ccdd04-76da-11ec-b1d8-1eca04f4fc71/2848000e-f507-4d45-846a-f1dd614373e8.gif)

**Time-Saving Tips**: Use tag shortcuts for frequently accessed task lists, and click "Tasks" again to clear active tag filters.

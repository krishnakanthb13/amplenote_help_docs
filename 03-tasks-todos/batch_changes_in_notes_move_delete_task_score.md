# Batch moving & updating tasks, batch changing Task Score

> [← Help Index](../00-index.md) · Category: [Tasks & Todo Lists](./index.md) · [Source ↗](https://www.amplenote.com/help/batch_changes_in_notes_move_delete_task_score)

## Batch Move Tasks to a New Note

Two straightforward options exist for moving tasks between notes in the Notes Pane.

### Batch-Move Child Tasks

This method works in both Notes Pane and Jots. The process involves:

1. Select all tasks beneath the first one by holding shift and pressing "up" or "down"
2. Press tab
3. All tasks now share a single parent

You can move task parent hierarchies using the Task Command `!move`. Creating a new parent task specifically for organizing related task groups is also possible.

### Batch-Move Drag-and-Drop Tasks

"It's also possible to use your cursor to drag-select a group of tasks, and drag them to a new note" in the notes list. This places dropped tasks alongside existing tasks in the destination note.

## Batch Delete Tasks

Two deletion approaches:

- Select all tasks in the note (Ctrl-A or Cmd-A on desktop; triple tap on mobile), then press backspace
- Hold shift and drag to select a task range, then press backspace

## Batch Adjust Task Score

For notes containing multiple tasks, such as inbox or project notes:

1. Click the triple dot "Note Options" menu
2. Select "View all details" at the bottom
3. In the "Note Details" sidebar, click "Manage tasks" next to "Open Tasks"
4. Adjust scores by percentage or specific number increment/decrement

This feature proves useful when project priorities shift, allowing rapid bulk adjustments to task scores.

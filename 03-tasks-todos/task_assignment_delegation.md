# Assign/Delegate Tasks

> [← Help Index](../00-index.md) · Category: [Tasks & Todo Lists](./index.md) · [Source ↗](https://www.amplenote.com/help/task_assignment_delegation)

## Create a to-do note for collaboration

Amplenote uses an "Assigned Tasks Note" as a collaborative task-sharing paradigm. The setup involves two steps:

1. Create a note to receive tasks from collaborators (for example, "Bill's tasks from Liam")
2. Share the newly created note with one or more collaborators

Once established, collaborators can send you tasks that won't appear in their own Task Domains or Tasks View Mode unless they choose to view them.

More details are available on the dedicated Assigned Tasks Note help page.

## Assign a task to a collaborator

The quickest method is using the `!move` Task Command.

## See tasks assigned to collaborators in Tasks View mode

Control task visibility through the triple dot menu in Tasks View mode:

- **Group tasks by note creator**: Select this option to organize tasks, particularly useful when collaborators maintain shared to-do notes
- **Show tasks from notes created by others**: By default, Task View mode excludes tasks in notes shared with you, but this toggle allows you to display them

## Seeing events assigned to others in Calendar View mode

Like Tasks View mode, Calendar View mode hides tasks in notes created by collaborators by default. To display all such tasks, click the sync indicator in Calendar View mode to adjust visibility settings.

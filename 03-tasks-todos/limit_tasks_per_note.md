# Setting a maximum limit of open tasks per note

> [← Help Index](../00-index.md) · Category: [Tasks & Todo Lists](./index.md) · [Source ↗](https://www.amplenote.com/help/limit_tasks_per_note)

## Overview

Amplenote addresses task list overload by allowing users to set a maximum limit on the number of tasks in a specific note, preventing lists from becoming unmanageable.

## Steps to Set a Task Limit

1. Open a note in Notes view
2. Click the three dots in the top right corner
3. Select "More options"
4. Click on "Manage tasks"
5. Enter your desired number in the "Target Maximum Open Tasks" field

## Visual Feedback

Once you've configured a maximum, a new indicator appears at the top of your note. This icon displays your current progress toward the limit and "will change to red if it reaches or passes the maximum."

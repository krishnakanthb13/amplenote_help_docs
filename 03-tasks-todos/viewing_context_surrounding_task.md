# View a task's surrounding context from Tasks or Calendar view

> [← Help Index](../00-index.md) · Category: [Tasks & Todo Lists](./index.md) · [Source ↗](https://www.amplenote.com/help/viewing_context_surrounding_task)

## Overview

Users often need to recall the context of tasks they've created. For instance, tasks generated from meeting notes require reference to the original discussion to be executed effectively.

## Two Methods for Viewing Task Context

### Method 1: Include a Backlink Within the Task

The recommended approach involves embedding a backlink using Amplenote's "Note Linking creation syntax." Users can:

- Utilize the `[[` syntax followed by `#` to access all note sections
- Select the relevant section to include
- Reference available demos and video tutorials demonstrating transcluded content creation in tasks

### Method 2: Jump Back to the Note

An alternative approach involves using the navigation link located at the bottom of Task Details in both Tasks View and Calendar View modes. This link directs users back to the original note.

To access Task Details, users can:
- Use the designated hotkey
- Click the expander on the right edge of any task

The interface includes a hover feature displaying the link back to the source note.

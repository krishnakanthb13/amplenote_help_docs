# The iOS & Android Quick Task Bar: Creating Tasks and To-Do Lists on Mobile

## How to use the mobile Quick Task Bar

The Quick Task Button appears in the bottom right corner whenever you open the mobile app. Tap it to open the Quick Task Bar and keyboard, then type your task description.

As you begin typing, a menu displays above the field indicating which note will receive the task. Once finished, tap "add" and your task appears at the top of your to-do list.

**Tip:** Tapping the blue or grey note icon in the Quick to-do area opens a new note for writing.

## Choosing a destination for your new task

By default, new tasks on mobile are added to the current day's Jot. You can change the destination by clicking the Destination Note's name and selecting or searching for your preferred note.

## Advanced: Adding tasks to the top or the bottom of a note

Tap the "Options" button while creating a task to choose whether it appears at the top or bottom of your selected note.

## Adding a Start Date/Due Date for Tasks using the Quick Task Bar

Two primary methods exist:
- Using the Date & Time Picker
- Using Natural Language Processing in the task description

### Creating tasks without a Start Date

By default, tasks created in the Quick Task Bar have no Start Date. Simply type the task and add it.

### Adding a Quick Start Date

Click "Select a start time (optional)" and choose from preset dates.

### Choosing a Custom Start Date

From the same menu, select "Choose Day and time..." and use Fuzzy Time options from the top of the menu.

### Setting the Exact Date and Time

Select the "Custom Time" option to set precise date and time values.

## Adding Start Dates using Natural Language Processing (NLP) in the Quick Task Bar

When you write something resembling a time or date in the Quick Task Bar, Amplenote offers an option to apply that time/date to your task automatically.

## Adding images and videos using the Quick Task Bar

Use the "Image/video" button in the Quick Task Bar to quickly attach images or videos from your mobile device.

**Tip:** Check the iOS/Android Share Sheet documentation for another method to add images to notes.

## Using Task Commands inside the Quick Task Bar

Task Commands work in the Quick Task Bar. Enter an exclamation mark `!` (with a space before it) to see available options.

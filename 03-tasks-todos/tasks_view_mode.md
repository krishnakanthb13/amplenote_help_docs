# Tasks Mode Overview, and visible due/starting time

> [← Help Index](../00-index.md) · Category: [Tasks & Todo Lists](./index.md) · [Source ↗](https://www.amplenote.com/help/tasks_view_mode)

## Article Summary

Amplenote's Task View provides a unified interface for browsing all tasks across notes. The feature allows users to organize their to-do items through grouping, sorting, and filtering options.

## Key Features

**Accessing Task View**: Located in the leftmost navigation pane or accessible via Quick Open by typing "Tasks"

**Task Organization Options**:
- Group tasks by Scheduled Date (Agenda view), Note, or Creator
- Sort tasks by priority, alphabetically, or by other criteria
- Filter by tags, note references, or shortcuts

**Notable Functions**:
- Tasks display in paginated groups of 100 for performance optimization
- "Scheduled Date" grouping shows when tasks begin on the calendar
- Default shortcuts include "Due This Week" and "High Value" (Task Score above 10)

## Finding Task Details

To identify which note a task originated from, users can expand the "Task Details" section within the Task View interface.

The platform distinguishes between "Start Time" (when a task appears on calendar) and traditional "Due" dates, reflecting its calendar-based architecture rather than pure task management design.

# Checkboxes (lightweight tasks that don't show up in Tasks mode)

> [← Help Index](../00-index.md) · Category: [Tasks & Todo Lists](./index.md) · [Source ↗](https://www.amplenote.com/help/using_checklists)

## Checkboxes vs Tasks (checklists vs to-do lists)

The document distinguishes between "Tasks" and "Checklists," suggesting that tasks represent "real-life, one-time objectives that have measurable impact" while checklists function as smaller, more abstract items within a list of steps needed to complete a chore.

Example task:

- ✍️ Write the upcoming blog post

Associated checklist items:

- ✅ Finish first draft
- ✅ Add links and images
- ✅ Do editing pass
- ✅ Do proof-reading
- ✅ Publish and send emails

Checklists are notably reusable across similar projects, making them valuable templates.

## Four Options to Realize Simple Checklists in Amplenote

### Option 1: Use Tasks, Marked Complete via "Cross-out"

Users wanting checklists that remain inline after completion can configure tasks accordingly. The `Ctrl-Shift-Space` hotkey crosses out tasks while keeping them visible. Tasks only display in Tasks or Calendar mode when created in tagged notes included in your Task Domain.

### Option 2: Use Bullet List (or Numbered List) Items

Bullet or numbered list items can be crossed off using `Ctrl-Space`. Clicking the bullet itself provides options for crossing it out or scheduling it as an event.

### Option 3: Install the Checklists Plugin

The Checklists plugin by David Trapp offers interactive checklist functionality available through the plugin directory.

### Option 4: Tag Your Note `checklists` (and Lock It If It's a Template)

Combine templates and notes tagged "checklists" to create tasks that exclude from Task or Calendar view.

## Recommendations Based on Use Cases

### I Am Often Employing Reusable Checklists

Use note templates (regular notes typically locked and rarely edited). Duplicate templates when needed using `@=` syntax. The key advantage: "tasks from locked notes are hidden from Tasks and Calendar Mode," showing only working copies.

Complete tasks using "Cross out" or `Ctrl-Shift-Space` hotkey to keep them inline. Alternatively, use bullet points instead of tasks.

### I Am Creating Checklists in Specific Notes

1. Create checklists as normal task lists
2. Tag checklist notes with `checklists` or similar identifier
3. In Tasks Mode, exclude individual checklist notes or deselect the `checklists` tag
4. In Calendar Mode, exclude individual notes or omit `checklists` tag from Task Domains

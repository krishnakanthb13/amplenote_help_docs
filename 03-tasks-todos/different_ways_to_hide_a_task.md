# Hide (snooze) a task until later

> [← Help Index](../00-index.md) · Category: [Tasks & Todo Lists](./index.md) · [Source ↗](https://www.amplenote.com/help/different_ways_to_hide_a_task)

## Many options to hide (snooze) a task until later

Concealing tasks is one of the most frequent actions users perform on their to-do lists. The platform suggests that if you've hidden a task three times, you might want to consider dismissing it instead. Dismissing provides half the credit of completing a task for upcoming to-do statistics, making it strategically valuable.

The philosophy emphasizes "strategic procrastination" as central to productivity. Tasks should remain on regularly-visited lists only if completion seems feasible within your planning horizon (typically a couple weeks).

## 🐰 In Notes, Tasks or Calendar View modes: if blocked by another task, use the block task link to automatically hide until the blocker is complete

Amplenote enables task dependencies where Task B can be automatically hidden until Task A completes. Users can connect blocking and blocked tasks through the interface, with documentation available for "task links."

## 🐰 In Notes, Tasks or Calendar View modes: Use `!hide` to hide a task for a set number of days

The quickest method involves typing `!hi` and pressing enter. This keyboard shortcut provides fast task concealment without mouse interaction.

## 🐰 In Jots View mode: Move the task to a future day

Moving tasks to future dates offers another rapid concealment method. Users can employ natural language like `{tomorrow}`, `3 days from now`, `2 weeks from now`, or `1 year from now` to reschedule tasks.

## 🐰 In Calendar View mode: De-select the note or tag for items you don't want to see

Deselecting notes removes their associated tasks from display. Holding shift while clicking focuses tasks from a single note. The `!hide` command also functions here.

## 🐴 Another Option: Hover over Quick Actions area in task

Quick Actions menus appear when hovering over tasks, offering convenient concealment options for human-friendly timeframes.

## 🐢 Another Option: Open Task Details

The Task Details window allows setting "Hide Until" times, particularly useful for configuring flexible recurring task rules. Users can input relative times or modify dates directly.

## 🤔 Where are my hidden tasks?

Hidden tasks, including future recurring task occurrences, appear in two locations:

- The `Hidden` tab within each note
- Tasks view, after enabling hidden tasks visibility

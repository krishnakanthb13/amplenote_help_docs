# Nested tasks and subtasks

> [← Help Index](../00-index.md) · Category: [Tasks & Todo Lists](./index.md) · [Source ↗](https://www.amplenote.com/help/nested_tasks_subtasks_when_to_create_how_to_use)

## Using Nested Tasks and Subtasks

Nested tasks, also called "subtasks," indicate a hierarchical relationship between tasks. Parent tasks typically contain subtasks that enumerate steps to accomplish the parent task or dependencies required for completion.

In this structure, a parent task cannot be considered complete until all child tasks are marked as completed.

## Subtask Options

The following features are available when viewing subtasks in Notes view or Jots View mode.

### Creating Subtasks

To create a subtask, first create a standard task using `[]` followed by a space. Then, with your cursor positioned at the beginning of the line, press `tab` to indent it as a subtask. The cursor must be at the first position for indentation to work properly.

After creating the first subtask, pressing Enter automatically creates another subtask at the same depth.

![Using the Tab key to indent a task into a subtask](https://images.amplenote.com/08ec76b2-e8e3-11eb-ac70-42c8adfdc167/cc20cce5-b277-4e7c-8e9d-9a98678d0d4e.gif)

On mobile devices, use the highlighted toolbar icons to create or remove subtasks.

![Mobile toolbar icons for creating or removing subtasks](https://images.amplenote.com/08ec76b2-e8e3-11eb-ac70-42c8adfdc167/b752fd0f-6049-47e7-a134-7be0754e7506.jpg)

### Reordering Subtasks

Standard hotkeys can be used to reorder subtasks. On macOS, use the Command key; on PC, use Ctrl.

![Reordering subtasks using the macOS hotkeys. On PC, the Command key corresponds to Ctrl](https://images.amplenote.com/08ec76b2-e8e3-11eb-ac70-42c8adfdc167/fd7c82b3-09fe-4843-9d7a-0bef9c2e41c8.gif)

### Expanding and Collapsing Subtasks

Expand or collapse subtasks using the `ctrl-,` hotkey when your cursor is in the parent task, or click the expand/collapse arrow positioned to the left of any task with subtasks.

![Tasks can be expanded or collapsed by clicking the arrow at left, or using the keyboard shortcut ctrl-,](https://images.amplenote.com/08ec76b2-e8e3-11eb-ac70-42c8adfdc167/9760b0de-d751-4fef-9b03-0a2e78793674.gif)

### Dragging Subtasks

When a parent task is dragged, all of its subtasks travel with it.

![When a parent task is dragged, its subtasks are dragged down the list with it](https://images.amplenote.com/08ec76b2-e8e3-11eb-ac70-42c8adfdc167/15cce6e0-cc41-425c-b147-797edc5f8ea3.gif)

### Completing Subtasks Within a Group

Subtasks are completed the same way as normal tasks: by clicking the checkbox or using the `ctrl-space` hotkey.

### Completing All Subtasks at Once

When a parent task is marked complete, all of its subtasks are automatically marked as complete. This saves time when subtasks are too minor to check off individually.

![When a parent task is completed, all subtasks are marked as complete](https://images.amplenote.com/08ec76b2-e8e3-11eb-ac70-42c8adfdc167/680feb4b-51c2-4d98-9207-51389cd75f3e.gif)

### Hiding All Subtasks at Once

Use the `!hide` task command within a parent task to move the parent and all child tasks to the "Hidden" tab. The task hierarchy remains intact when the tasks reappear after the specified interval.

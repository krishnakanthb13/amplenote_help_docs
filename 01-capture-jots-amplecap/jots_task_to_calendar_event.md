# From Jot task to scheduled event on calendar

> [← Help Index](../00-index.md) · Category: [Capture: Jots & Amplecap](./index.md) · [Source ↗](https://www.amplenote.com/help/jots_task_to_calendar_event)

## Overview

Amplenote's workflow enables users to transform ideas into scheduled tasks efficiently. The core process involves "create a task in a Jot and put it on your calendar," connecting the initial ideation phase to execution tracking.

## Step One: Set Up a Task Domain That Includes Your Jots Tag

To begin, configure Task Domains through Account Settings → Task Calendar. If necessary, click "Enable Task Domains" to activate this feature.

Once available, you'll see a list of existing Task Domains. Add the `daily-jots` tag (or your configured default shortcut) to the appropriate domain—such as "Work"—so tasks within notes bearing this tag appear in the calendar sidebar.

![List of Task Domains, where you can connect Jots to Calendar](https://images.amplenote.com/99a83da2-9ebb-11eb-a50e-aa43de7fc280/30c08a51-beb3-41af-99a9-99947a8e1d51.png)

![Adding the Daily Jots tag to the 'Work' Task Domain](https://images.amplenote.com/99a83da2-9ebb-11eb-a50e-aa43de7fc280/06522d74-0977-4bcb-b4c0-4324423d72a8.gif)

**Pro tip:** Consider which other notes or tag hierarchies contain tasks you'd like to schedule. You might also configure separate domains for "Personal" projects or miscellaneous tasks. Learn more about Task Domains for additional configuration options.

## Step Two: Give the Task a Start Time

Tasks in your Jots notes now appear in the calendar sidebar and can be scheduled. Set a task's start time using two methods:

**Exact scheduling:** Use the Task Commands Menu with `!start` to specify a precise date and time.

![Choosing a calendar time with the `!start` Task Command](https://images.amplenote.com/99a83da2-9ebb-11eb-a50e-aa43de7fc280/7f82e8f5-c0a2-49ea-a8fd-6c3e00434f7f.gif)

**Fuzzy scheduling:** Let the calendar automatically select an available time within a range you specify (like "tomorrow afternoon"). This approach prevents scheduling conflicts by automatically shifting tasks to open time slots.

![Use fuzzy scheduling to have the calendar pick an exact Start Time for you within a range](https://images.amplenote.com/99a83da2-9ebb-11eb-a50e-aa43de7fc280/77b4851f-7817-4020-8206-3de3a57053a4.gif)

## Step Three: View Your Scheduled Task

That's the complete process. Your task now appears in Calendar View mode at the designated time. If you've connected external calendars, the scheduled task automatically publishes to those platforms as well.

![Calendar View mode now shows the task at the scheduled time](https://images.amplenote.com/99a83da2-9ebb-11eb-a50e-aa43de7fc280/30766f4d-f0df-4f0c-a5b2-515af9f0e65a.png)

# What are Jots suggestions and how to configure them?

> [← Help Index](../00-index.md) · Category: [Capture: Jots & Amplecap](./index.md) · [Source ↗](https://www.amplenote.com/help/jots_suggestions)

## What are Jots Suggestions?

Jots suggestions provide contextually relevant options for users who employ Jots View as their daily dashboard. The feature presents several types of helpful actions automatically.

## Types of Suggestions

**Move previous day's tasks**

This feature automatically moves all uncompleted to-do items from the prior jot to the current day's jot. The system includes hidden tasks from the previous day as well.

**Link to updated shared notes**

When collaborating, this suggestion alerts you to changes in shared notes you didn't author yourself, eliminating the need to manually search for collaborative content.

**Link to tasks scheduled for today**

This appears when you have tasks scheduled for today that belong to Task Domains. Clicking "Visit Calendar" navigates to your most recently opened Domain in Calendar Mode.

**Link to recent notes with open tasks**

If a note contains numerous tasks and you haven't opened it today, this suggestion appears at the bottom of your Jot.

## Enabling and Disabling Suggestions

Access the Jot options menu in Jots Mode to configure which suggestion types display or disable them entirely. An option to "Apply these settings to all Jots views" allows you to copy your configuration across all tags used for jots.

## Hiding and Snoozing Suggestions

After addressing suggestions, dismiss them for the day using the "Hide until tomorrow" button. You can also snooze suggestions for extended periods or disable them permanently through the dropdown menu.

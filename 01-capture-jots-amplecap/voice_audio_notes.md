# Recording Voice Notes, Speech-to-Text, Audio Notes, or Voice Typing

## Overview

As of November 2024, Amplenote does not include native voice input functionality. However, the platform recommends leveraging operating system-native features or specialized plugins, as "every OS supports it natively, and it's also possible to use plugins for still-more refined speech-to-text functionality."

## Available Options by Platform

### Voice Notes Plugin (OpenAI Whisper)

This plugin allows users to speak into a microphone for transcription via OpenAI's service. It requires your own OpenAI API key and delivers high-precision transcription results.

### macOS Dictation

The F5 key initiates dictation mode on modern macOS systems. According to the article, Amplenote's CEO regularly uses this feature for "multi-paragraph notes" with solid contextual accuracy.

**Limitation:** Creating new lines and revising past words presents some challenges as of Q4 2024, though keyboard use for light edits doesn't disable dictation.

### iOS Dictation

Users can activate dictation by tapping the microphone button on the keyboard when the cursor is positioned in a note. This version offers somewhat expanded functionality compared to the macOS equivalent.

![Tapping the microphone button on the iOS keyboard to dictate into a note](https://images.amplenote.com/31f3beb0-a0e8-11ef-b7be-e30655da85d3/82b540d6-eb44-453f-9e25-62493bfe5c4f.jpg)

### iOS Siri Shortcut

The "Capture to Amplenote" shortcut enables voice-activated task capture through Siri, allowing quick additions to your daily jot.

### Windows Voice Typing

Initiate voice typing using either Windows logo key + H (hardware keyboard) or the microphone key next to the spacebar (touch keyboard).

### Android Speech-to-Text

Google's Gboard keyboard includes microphone functionality that works across most text-input areas within apps, accessible via the microphone icon.

### Linux

Amplenote acknowledges multiple potential configurations depending on distribution, welcoming user recommendations at support@amplenote.com.

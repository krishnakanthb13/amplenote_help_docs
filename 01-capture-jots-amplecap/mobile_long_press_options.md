# Mobile long-press options

> [← Help Index](../00-index.md) · Category: [Capture: Jots & Amplecap](./index.md) · [Source ↗](https://www.amplenote.com/help/mobile_long_press_options)

## Overview

Amplenote users can access quick actions on mobile devices by long-pressing the app icon from the home screen or app explorer.

## How to Access

"You can access it by long-pressing the Amplenote app icon for one second."

## Available Functions

The long-press menu provides three primary options:

**New Note** - Creates a blank note within the application.

**Search** - Launches the search interface to locate specific notes or tasks.

**Quick Add** - Opens the Quick Add window for rapid note creation.

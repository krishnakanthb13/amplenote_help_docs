# Using OCR (optical character recognition) to extract image contents to text

## Image OCR features

Amplenote automatically indexes images uploaded to notes via OCR when you're online. As text is extracted from images, it becomes searchable and can be inserted into notes for editing. The OCR process occurs when images are uploaded to the backend, then the extracted text merges back into your note.

You don't need to manually paste extracted text for search indexing—"that happens automatically." However, pasting text can be useful when you want to edit the extracted content.

## OCR extraction use cases

**Written meeting notes**: Amplenote's OCR handles handwritten text reliably, transforming jotted notes into editable format.

**Meal recipes**: Users can extract specific sections like ingredients for printing or referencing elsewhere.

**Editing code**: The OCR engine accurately translates block text into editable code, with punctuation differences being the main limitation.

**Business cards**: Photographs of business cards become editable, enabling contact information capture.

**Handwritten journaling**: OCR makes past journal entries searchable for later reference.

## Conditions for successful OCR processing

### System limitations

- OCR requires internet connectivity and only functions when online. Images uploaded offline will be indexed once the note is accessed while connected.
- Images exceeding 10,000 pixels may have clipped words due to low resolution at the OCR provider. Images under 5,000 pixels tall perform optimally.

### System-specific limitations & debugging

Browser configuration variations can prevent OCR indexing. If an uploaded image lacks the OCR icon after approximately 30 seconds while online, contact support@amplenote.com with:

![The OCR icon shown on an indexed image](https://images.amplenote.com/71e4e1e6-5e9a-11eb-b2f6-a668f5837565/1e4d9a44-b687-4640-8f79-1605619279af.png)

- Browser and platform details
- The problematic image
- Detailed reproduction steps from the 30 seconds following insertion
- Optional video documentation

Minimizing note changes immediately after image insertion improves OCR success likelihood.

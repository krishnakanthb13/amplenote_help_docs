# Amplecap Usage Examples

> [← Help Index](../00-index.md) · Category: [Capture: Jots & Amplecap](./index.md) · [Source ↗](https://www.amplenote.com/help/cool_ways_to_use_amplecap)

## Overview

Amplenote's Amplecap browser extension enables users to capture web content in multiple ways. This article details "cool ways" people use this feature, with five main use cases presented.

## Primary Use Cases

**Quick Task Capture**: Users can add notes and reminders using the Omnicapture feature without leaving their browser. This is ideal when you want to "capture an idea while browsing the web" or avoid interrupting activities like streaming.

**Visual Context**: The screenshot selection tool lets users capture relevant page sections and paste them into Rich Footnotes, useful since "humans are visual creatures."

**Content Highlighting**: The Highlights capture mode allows manual selection of key phrases from articles, with editable excerpts that preserve surrounding context for better understanding.

**Visual Inspiration**: Screenshot selections can be saved directly to note bodies, supporting creative projects like "house building or redecorating" and "web page designing."

**Reading Lists**: Using Bookmark mode with to-do formatting creates manageable reading/watchlists. This approach works well "when you have a hard time managing the many sources of content you like to consume."

## Key Features

- Hotkey access (`Ctrl-Shift-A`) for rapid capturing
- Multiple destination options (new notes, existing notes, clipboard)
- Annotation text fields for task descriptions
- Source preservation for later reference
- Tag assignment during capture

# Global task/event capture shortcut hotkey on desktop

> [← Help Index](../00-index.md) · Category: [Capture: Jots & Amplecap](./index.md) · [Source ↗](https://www.amplenote.com/help/global_task_todo_capture_via_hotkey_on_desktop_plus_global_note_open_key)

## Picking a global task capture shortcut (hotkey)

To enable this feature, open the Amplenote desktop application and navigate to "Settings" from the main "Amplenote Desktop" menu at the top of your window. You can also access settings using `Cmd ,` on macOS or `Ctrl ,` on Windows.

Once in the Settings menu, the first option available is "Global task capture shortcut." Select a key combination you'll remember when you want to quickly capture a new task.

Additionally, you can configure a "Global quick open shortcut" (the global note open/lookup key) to access your note list lookup directly from anywhere.

## Capturing a task via global popup

When you press your chosen global task capture hotkey—regardless of which application you're currently using—a popup input box appears for capturing your idea or task.

This input box supports the full range of Amplenote's editing capabilities:
- Rich text formatting
- Rich Footnotes (images, videos, and other media)
- Slash commands (such as marking tasks as "Important" or setting deadlines)

You can insert images or videos by selecting text and pasting media directly into the input field.

## Finishing capture

After describing your task, save it using `Cmd-Enter` on macOS or `Ctrl-Enter` on Windows.

The bottom of the popup displays your most recently accessed notes numbered for quick selection. Press `Ctrl` plus the number next to a note to send your task there. Alternatively, press `Tab` to navigate to the note selector, then `Enter` to choose your destination note.

# Fastest way to add a task from phone?

> [← Help Index](../00-index.md) · Category: [Capture: Jots & Amplecap](./index.md) · [Source ↗](https://www.amplenote.com/help/fastest_way_to_add_a_task_quick_todo)

## Overview

Amplenote treats tasks as "first-class citizens" where all tasks reside within notes but can be viewed separately. This guide covers task creation and configuration options.

## Different Ways to Add New Tasks

### Create Tasks from Within a Note or Jot

**Method 1: Type Brackets** — Type `[]` (open bracket, closed bracket, space) followed by your task text.

**Method 2: Use Formatting Bar** — Click the check icon in the formatting bar to create a new task on desktop or mobile.

Tasks appear in Tasks View Mode with assigned tags.

### Create a Task from Mobile Quick Task Bar

Dedicated help available for iOS & Android Quick Task Bar functionality for mobile task creation.

### Create a Task from Quick Open Menu

Quick Open navigation enables rapid task creation; see dedicated help page for details.

### Create a Task from Email

Use the mail-to-note feature by creating a contact with your note's email address in Gmail or your preferred email app to forward emails as tasks.

### Create a Task from Within a Mobile App

**Home Screen Widgets** — Separate page available covering iOS and Android widget functionality.

**Share Sheet** — iOS/Android Share Sheet enables sending text, links, images, and PDFs to tasks.

**iOS Voice Input** — Siri Shortcuts support voice-to-text task capture.

### Create a Task via System-Wide Hotkey

Install the Amplecap browser extension (Chrome or Firefox) to define an Omnicapture hotkey for task capture outside Amplenote. A future native desktop app update will introduce configurable system-wide hotkeys.

### Creating Subtasks

Use Tab to indent child tasks or Shift+Tab to outdent. Nested tasks are supported with hierarchical organization.

## Adding Details to Tasks

### Rich Footnotes

Tasks can include rich footnotes containing:
- Images
- Videos
- Text
- Links (including existing or newly created notes)
- Tweets
- YouTube videos
- Google Sheets
- Bullet lists
- Combinations of above content types

## Recurring Tasks

Full details available on dedicated help page for recurring tasks and due dates.

## Task Details Panel

Access via expand icon on task bar or hotkey.

### Set a "Start Time" (Due Date)

Dedicated page explains due date and start time configuration.

### Set a Reminder

Enable notifications in Task Details; configure notification type (push, browser, or email) in Settings > Notifications.

### Urgent vs. Important

Based on the Eisenhower Method:

- **Urgent tasks**: Bad consequences within a couple of days.
- **Important tasks**: Align with long-term or short-term goals.

Recommendation emphasizes minimizing urgent tasks and maximizing important ones.

### Set Duration

Choose from four duration options:
- Tasks 90+ minutes benefit from subdivision
- 15-30 minute tasks are easier to act upon
- Task Score prioritizes shorter duration tasks
- Shorter tasks accumulate score faster

### Edit Task Score

Click the score number to enter a new value. Alternative methods include keyboard commands and batch editing.

## Manage Tasks Panel

Per-note options including:
- Review open task statistics
- Configure cross-out behavior on completion
- Batch change Task Scores
- Set maximum open tasks per note

## Snoozing Tasks

Multiple methods available for hiding tasks until later; dedicated help page available.

## Making Tasks Disappear

### Completing Tasks

Three completion options:
1. Click checkbox
2. Use keyboard shortcut
3. Use task command

Completed tasks move to note's Completed tab with productivity graph. **Stay Inline Option**: Tasks can remain visible with strikethrough instead.

### Moving Completed Tasks

In Completed tab, use drag-and-drop to change task completion date.

### Dismissing Tasks

Dismiss for half accumulated score when: task is half done; someone else completed it; circumstances made it unnecessary. Dismissing recurring tasks preserves upcoming occurrences.

### Crossing Out Tasks

Dedicated help page covers strikethrough on completion configuration.

### Deleting Tasks

Remove entirely via:
- Delete/Backspace key while editing
- Delete option in expanded Task Details
- Task command

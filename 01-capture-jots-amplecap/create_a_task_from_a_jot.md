# Create a task from a jot

> [← Help Index](../00-index.md) · Category: [Capture: Jots & Amplecap](./index.md) · [Source ↗](https://www.amplenote.com/help/create_a_task_from_a_jot)

## Article Overview

This guide covers task creation and management in Amplenote, emphasizing that "tasks are first-class citizens" within the platform.

## Different Ways to Add New Tasks

### Create tasks from within note or a jot

Two primary methods exist:

1. **Type brackets syntax**: Enter `[] ` (open bracket, closed bracket, space) followed by task text
2. **Use formatting bar**: Click the check icon in the toolbar to generate a new task

Tasks automatically appear in Tasks View Mode and inherit any tags assigned to their parent note or jot.

![Tapping the checkbox icon will create a new task on either desktop or mobile](https://images.amplenote.com/cce04e4c-fad0-11ea-95c1-f200a12bf340/d0b34abb-20e8-4e8a-ab60-bb028b87d75b.gif)

### Create tasks from mobile Quick Task Bar

A dedicated mobile feature enables rapid task capture on iOS and Android devices.

### Create tasks via Quick Open menu

The Quick Open navigation provides streamlined task creation shortcuts.

### Create tasks from email

Using the mail-to-note feature, users can forward emails directly to task lists by creating a contact with their note's email address.

### Create tasks within mobile apps

Three mechanisms support mobile task capture:

- **Home screen widgets** for at-a-glance task addition
- **Share Sheet integration** for sending text, links, images, and PDFs
- **iOS Siri Shortcuts** enabling voice-based task input

### Create subtasks

Use Tab to indent child tasks or Shift-Tab to outdent them, enabling nested task hierarchies.

### Create tasks via system-wide hotkey

Installing the Amplecap browser extension (Chrome or Firefox) enables Omnicapture functionality for capturing tasks outside Amplenote. A native desktop app update in 2024 will introduce configurable system-wide hotkeys.

![Creating a task via a system-wide hotkey with Amplecap](https://images.amplenote.com/cce04e4c-fad0-11ea-95c1-f200a12bf340/4c5d6ae3-ec27-4e5e-9bef-67e640c04d30.png)

## Configuring Task Options

### Set a "Start Time" (Due Date)

A dedicated help page describes the complete process for scheduling task due dates.

### Set a Reminder

Users can enable notifications at task due times, configurable through Settings > Notifications for push, browser, or email delivery.

### Urgency and Importance Classification

Based on the Eisenhower Method, tasks are categorized as:

- **Urgent tasks**: Consequences ensue if not completed within days
- **Important tasks**: Tasks aligning with long-term or short-term goals

The platform emphasizes minimizing urgent tasks while maximizing important ones. These can be set via task commands menu.

![Classifying a task as Urgent, Important, both, or neither](https://images.amplenote.com/cce04e4c-fad0-11ea-95c1-f200a12bf340/f6e4730b-5f8e-4133-8268-7fd66fb6ce77.png)

### Set the Duration

Choose from four options (15 minutes, 30 minutes, 90 minutes, or longer). Recommendations include:
- Breaking down 90+ minute tasks into smaller ones
- Prioritizing 15-30 minute tasks for easier action
- Task Score prioritizes shorter duration tasks

Duration can be set through task commands.

### Edit Task Score

Click the Task Score number to enter a new value. Alternative methods include:
- Resetting via task commands menu
- Increasing to maximum via commands
- Batch-editing through note management panel

![Editing the Task Score by clicking the score number](https://images.amplenote.com/cce04e4c-fad0-11ea-95c1-f200a12bf340/22869c94-3a6d-4c10-935d-7e6867369c8d.png)

## Task Completion and Removal

### Completing tasks

Three methods mark tasks complete:
1. Click the checkbox
2. Use keyboard shortcut
3. Use task commands menu

Completed tasks move to a "Completed" tab displaying productivity metrics.

### Crossing out tasks

Tasks can be configured to display strikethrough formatting upon completion while remaining inline.

### Rewriting completion history

The Completed tab allows drag-and-drop reassignment of task completion dates to different days.

![In the Completed tab of a note, use drag-and-drop to move a task's completion date to another day](https://images.amplenote.com/cce04e4c-fad0-11ea-95c1-f200a12bf340/2d2503bb-02c2-4261-b225-09dcb6476f76.gif)

### Dismissing tasks

Tasks can be dismissed for half their accumulated score when partially done, delegated, or no longer necessary. Dismissing recurring tasks preserves upcoming occurrences.

![Dismissing a task](https://images.amplenote.com/cce04e4c-fad0-11ea-95c1-f200a12bf340/2d734b3d-8b53-4e0d-8d9d-104c030d08c8.png)

### Deleting tasks

Remove tasks using Delete or Backspace keys, or access deletion through expanded task details menu.

![Deleting a task](https://images.amplenote.com/a87fe9b8-03d3-11e9-8493-fed38e33333f/3193b6ee-7a98-46cf-a05b-aa743107da02)

# Forward emails (Gmail, Outlook, etc) to a note inbox of your choosing

> [← Help Index](../00-index.md) · Category: [Capture: Jots & Amplecap](./index.md) · [Source ↗](https://www.amplenote.com/help/mail-to-note)

## Mail-to-note usage and options

Mail-to-note is a capability that allows users to "send images or content to a note of their choosing from any platform on which they can send an email." The feature comes enabled by default and also supports PDF attachment forwarding.

## Getting your dedicated mail-to-note address

To obtain an email address for a specific note:

1. Click the triple-dot icon in the upper right corner of any note on the web
2. Select "More options"
3. Click "Copy mail-to-note address"

This generates an address in the format: `[Email token]~[Note ID]@amplenote.email`

## Mail-to-note options

The service offers several address variations:

| Email address | Behavior |
|---|---|
| `[Email token]~[Note ID]@amplenote.email` | Adds email as a task in that particular note |
| `[Email token]@amplenote.email` | Creates a new note titled after the email subject |
| `[Email token]~today@amplenote.email` | Adds email as a task in today's daily jot |
| `[Email token]~tomorrow@amplenote.email` | Adds email as a task in tomorrow's daily jot |

## Tagging a newly created note with mail-to-note

When using the new note option, you can tag the created note by editing the email subject before forwarding. For example: `Insurance offers for 2025 #my-tag-here` creates a note titled "Insurance offers for 2025" tagged as `my-tag-here`.

## Creating a Contact (Gmail)

For regular task forwarding, Gmail users can create a contact:

1. Click the 9-dot menu near the top of Gmail
2. Scroll to "Contacts" (the last option listed)
3. Create a new contact with your note's name for quick future access

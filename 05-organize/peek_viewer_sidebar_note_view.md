# Peek Viewer: Sidebar for multi-note viewing

> [← Help Index](../00-index.md) · Category: [Organize Everything](./index.md) · [Source ↗](https://www.amplenote.com/help/peek_viewer_sidebar_note_view)

## Overview

Peek Viewer is a feature available to desktop users with Pro subscriptions or above, enabling the opening of unlimited notes in a right sidebar. This functionality proves especially useful when authoring notes that reference other content.

![Peek Viewer used for multi-note viewing in the right sidebar](https://images.amplenote.com/ffbf729e-0397-11ed-a1b4-7eb08a2c5cd0/cedd33cc-6011-4326-881a-04e217578538.gif)

## Use cases

- **Daily planning**: Create task notes by browsing and dragging tasks from ongoing project notes.
- **Writing projects**: Reference previously created notes summarizing source material when composing papers, essays, or books.
- **Quick access**: Keep bookmark notes open for repeated visits to frequently needed web pages and actions.
- **Collaboration**: Open shared notes in the sidebar to delegate work without leaving your primary note.
- **Work reporting**: View work logs alongside report composition by opening relevant notes side-by-side.

## Opening notes in Peek Viewer

The Peek Viewer is accessible in Jots, Notes, Tasks, or Calendar modes on sufficiently wide displays. Activate it using **Cmd-J** (macOS) or **Ctrl-J** (Windows/Linux).

### Access methods

- **Quick Open with modifier key**: Hold Cmd (macOS) or Ctrl (Windows/Linux) when selecting a note from Quick Open.
- **Manual sidebar opening**: Click the sidebar icon adjacent to the "New note" button, then drag notes from the list.
- **Section extraction**: Press Esc while the cursor is inside a heading to select it, then drag into Peek Viewer.
- **Link opening**: Use Cmd-Click or Ctrl-Click on note references within your main note.
- **New note creation**: Cmd-Click or Ctrl-Click the "New note" button to create and open notes directly in the sidebar.
- **Close others**: Hold Shift and click the x icon next to a note's name to close all other open notes.

## Media content support

Peek Viewer supports opening various media types via Cmd-Click (macOS) or Ctrl-Click (Windows/Linux):

- YouTube videos
- Tweets
- Google Sheets
- PDFs
- Note previews

![Open a YouTube video or tweet using `Ctrl-Click` on Windows/Linux or `Cmd-Click` for macOS](https://images.amplenote.com/7ffd297a-14fc-11ef-9586-c6370cefecaf/627f87b6-93e5-46f3-8680-fe15a4a45ce5.gif)

## Note management

Notes opened in Peek Viewer can be renamed and have tags modified through the triple-dot menu next to each note's name, which also provides access to other note options.

![Renaming notes and adding tags via the note options menu in Peek Viewer](https://images.amplenote.com/7ffd297a-14fc-11ef-9586-c6370cefecaf/3b729de3-c45a-4948-bc9d-e82baed3431e.png)

## Limitations and future development

There is no hard limit on the number of simultaneously open notes. Future versions planned for late 2022 or early 2023 include Peek Viewer support for additional modes and batch-opening capabilities using Shortcuts.

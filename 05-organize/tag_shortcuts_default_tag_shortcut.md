# Shortcuts and Pinned Notes

> [← Help Index](../00-index.md) · Category: [Organize Everything](./index.md) · [Source ↗](https://www.amplenote.com/help/tag_shortcuts_default_tag_shortcut)

## Overview

In Amplenote you can create "Shortcuts" which allow you to quickly access a note or a search query by pinning them to the left-hand-side sidebar.

## Note Shortcuts

Note Shortcuts enable you to pin individual notes to the Notes View sidebar for easy access. The first three shortcuts are available by default. To create one, visit the triple-dot menu within a note and select "Add to Shortcuts."

## Search Shortcuts

### Tag Shortcuts

Tag Shortcuts filter notes by one or more tags and appear below the four view modes. To create one:

1. Hover over a tag in the left sidebar.
2. Click its triple-dot menu.
3. Select "Add to Shortcuts."

**Adding multi-tag selections to Shortcuts:**

1. Select desired tags using multi-tag selection.
2. Click the Star ⭐ symbol next to the tag list at the top.

You can combine normal tags and Tag Shortcuts using Shift-Click to narrow results by notes tagged with all selected tags. This also works with preset shortcuts like "Due This Week" and "High Value."

### Saved searches in Notes mode

Once satisfied with a search query, save it using the triple-dot button in the search bar.

### Saved searches in Tasks mode

Click the star icon next to "Tasks" to save any applied filters, including Note Reference filters.

### Saved searches in Calendar mode

Calendar Mode also supports saved filters.

## The Default Shortcut

Select any shortcut as your "Default Shortcut" to automatically open it when entering a mode. This persists across devices and can differ per mode. Click a shortcut's star icon to set it as default.

"Tag Shortcuts and the Default Shortcut are a high leverage target if you're trying to nudge yourself to focus on a particular area of your life."

## Managing Shortcuts

### Removing a shortcut

1. Select the shortcut from the sidebar.
2. Click the star icon next to its name at the top.

Alternatively, use the triple-dot menu next to each sidebar shortcut.

### Renaming a shortcut

Use the triple-dot menu to rename any search shortcut with custom names, including emoji support.

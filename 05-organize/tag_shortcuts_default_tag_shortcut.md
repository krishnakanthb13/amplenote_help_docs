# Shortcuts and Pinned Notes

> [← Help Index](../00-index.md) · Category: [Organize Everything](./index.md) · [Source ↗](https://www.amplenote.com/help/tag_shortcuts_default_tag_shortcut)

## Overview

In Amplenote you can create "Shortcuts" which allow you to quickly access a note or a search query by pinning them to the left-hand-side sidebar.

![Shortcuts and Pinned Notes in the left sidebar](https://images.amplenote.com/1b7197a6-3e2e-11ef-badf-26e37c279344/c8a8f215-4ff4-4d85-b03e-46f5c7c73e31.png)

## Note Shortcuts

Note Shortcuts enable you to pin individual notes to the Notes View sidebar for easy access. The first three shortcuts are available by default. To create one, visit the triple-dot menu within a note and select "Add to Shortcuts."

![Pinned Note Shortcuts in the Notes View sidebar](https://images.amplenote.com/4e9f07b6-51ab-11ec-81a4-4a5a484c3616/1e8ee5b9-af4b-4dda-a11e-50b1728a10d7.jpg)

## Search Shortcuts

### Tag Shortcuts

Tag Shortcuts filter notes by one or more tags and appear below the four view modes. To create one:

1. Hover over a tag in the left sidebar.
2. Click its triple-dot menu.
3. Select "Add to Shortcuts."

![A Tag Shortcut pinned below the four view modes](https://images.amplenote.com/8f50f93a-fae1-11ea-95c1-f200a12bf340/046d9318-789f-4018-ba52-34c811c94fc0.png)

![Adding a new Tag Shortcut](https://images.amplenote.com/8f50f93a-fae1-11ea-95c1-f200a12bf340/d40f269e-af3e-4c70-92b4-ded361c6a37b.gif)

**Adding multi-tag selections to Shortcuts:**

1. Select desired tags using multi-tag selection.
2. Click the Star ⭐ symbol next to the tag list at the top.

![Adding a multi-tag selection to Shortcuts via the Star symbol](https://images.amplenote.com/8f50f93a-fae1-11ea-95c1-f200a12bf340/5c62ec46-a9e5-4451-ac61-914c7ce9b419.png)

You can combine normal tags and Tag Shortcuts using Shift-Click to narrow results by notes tagged with all selected tags. This also works with preset shortcuts like "Due This Week" and "High Value."

![Shift-Click to select a Tag Shortcut and narrow results](https://images.amplenote.com/8f50f93a-fae1-11ea-95c1-f200a12bf340/a41b1ae3-8c41-40a7-9c23-94a32fa549ab.png)

### Saved searches in Notes mode

Once satisfied with a search query, save it using the triple-dot button in the search bar.

![Saving a search query in Notes mode](https://images.amplenote.com/1b7197a6-3e2e-11ef-badf-26e37c279344/8e286c3b-7dd2-4d65-a724-f07a30d47e7c.png)

![A saved search in the Notes mode sidebar](https://images.amplenote.com/1b7197a6-3e2e-11ef-badf-26e37c279344/fdb67569-2582-4d81-a3e4-72944ef7ecd4.png)

### Saved searches in Tasks mode

Click the star icon next to "Tasks" to save any applied filters, including Note Reference filters.

![Saving applied filters in Tasks mode](https://images.amplenote.com/1b7197a6-3e2e-11ef-badf-26e37c279344/cf515fed-029f-4e9c-93eb-52b338246500.png)

### Saved searches in Calendar mode

Calendar Mode also supports saved filters.

## The Default Shortcut

Select any shortcut as your "Default Shortcut" to automatically open it when entering a mode. This persists across devices and can differ per mode. Click a shortcut's star icon to set it as default.

![Setting a shortcut as the Default Shortcut](https://images.amplenote.com/1b7197a6-3e2e-11ef-badf-26e37c279344/541c4c15-d4f1-4d0e-aac1-2ddc480a3832.png)

"Tag Shortcuts and the Default Shortcut are a high leverage target if you're trying to nudge yourself to focus on a particular area of your life."

![Changing the Default Shortcut to `amplenote`](https://images.amplenote.com/8f50f93a-fae1-11ea-95c1-f200a12bf340/eb43c9ec-98b6-4c88-af4d-516c9d09c395.gif)

## Managing Shortcuts

### Removing a shortcut

1. Select the shortcut from the sidebar.
2. Click the star icon next to its name at the top.

Alternatively, use the triple-dot menu next to each sidebar shortcut.

![Removing a shortcut via the star icon](https://images.amplenote.com/8f50f93a-fae1-11ea-95c1-f200a12bf340/1d283bae-13ec-4f7f-9cdc-2eb2e1ad5ed1.png)

![Removing a shortcut from the sidebar triple-dot menu](https://images.amplenote.com/1b7197a6-3e2e-11ef-badf-26e37c279344/18804778-a568-448e-bf35-4222940943e7.png)

### Renaming a shortcut

Use the triple-dot menu to rename any search shortcut with custom names, including emoji support.

![Renaming a shortcut from the triple-dot menu](https://images.amplenote.com/1b7197a6-3e2e-11ef-badf-26e37c279344/b9fbca5c-7cc1-4fdb-ba5d-de50da7a9ad2.png)

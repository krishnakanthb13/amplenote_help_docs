# Organizing, sorting, and viewing task lists

> [← Help Index](../00-index.md) · Category: [Organize Everything](./index.md) · [Source ↗](https://www.amplenote.com/help/organizing_sorting_viewing_task_lists)

## Task View overview and how to show visible due/starting time

Amplenote's Task View, also called the "Unified Task List" or "Tasks pane," displays all tasks across notes in one centralized location. Access it through the left navigation pane or Quick Open by typing "Tasks."

![Task View, the Unified Task List that shows tasks across all notes](https://images.amplenote.com/6da70c7a-fc35-11ea-a1e0-160c44ce3352/cfa3f052-7cd5-402a-b8fc-94eb5fe17439.png)

### Task View primer

Tasks originating from individual notes appear in Task View, where the source note becomes irrelevant unless you filter the task list. The system paginates tasks into groups of 100 for optimal performance.

### Group, sort and control display

By default, Task View shows all tasks across all notes. You can organize tasks through several options:

![Task View offers options to group/sort your tasks (+ control inline task info to substantiate the group), and several options to reduce tasks by filtering](https://images.amplenote.com/6da70c7a-fc35-11ea-a1e0-160c44ce3352/a0f223a9-22c3-4931-831e-6e8647f079e8.png)

**Group Tasks By:**

- **Scheduled Date (Agenda View)**: Clusters tasks by their start date. This is Amplenote's equivalent to "due" dates in other apps. In calendar-based systems, "start time" reflects when a task should appear on the calendar.
- **Other grouping options**: Tasks can be grouped by source note or by the creator of their source note.

![Change Task View grouping from "None" to "Scheduled date." Notice the per-task inline data changes.](https://images.amplenote.com/6da70c7a-fc35-11ea-a1e0-160c44ce3352/f0fd0741-d896-4565-ae56-ea236e1f21d0.gif)

![Grouping tasks by Scheduled Date on mobile](https://images.amplenote.com/6da70c7a-fc35-11ea-a1e0-160c44ce3352/85d5ca49-4ccb-4cc6-9dd4-cbaa0a3e9dbb.jpg)

![Other grouping options for Task View](https://images.amplenote.com/6da70c7a-fc35-11ea-a1e0-160c44ce3352/3f04d796-84df-4407-9da1-e4ac64d29f45.png)

**Seeing task due times**: To view when tasks are scheduled without expanding them, select "Scheduled Date" as the grouping option.

**Group by Note — Sort Notes By**: When grouping by notes, a "Sort notes by" selector controls how notes (and their tasks) are positioned.

!["Sort notes by" becomes active when "Group tasks by" is "Notes"](https://images.amplenote.com/6da70c7a-fc35-11ea-a1e0-160c44ce3352/4d2d05e7-6885-4033-adc1-e59bd8716e2a.png)

**Sort Tasks By**: After choosing a grouping method, control how tasks are prioritized within groups. For example, when grouped by scheduled date, hundreds of unscheduled tasks can be sorted by criteria like importance or creation date.

![Choosing "Sort tasks by" controls precedence of tasks as shown within their group](https://images.amplenote.com/6da70c7a-fc35-11ea-a1e0-160c44ce3352/1aab683f-18cd-42d5-8295-430e9d0d6dd8.png)

### Filter tasks: by tag, note, inline tag, and more

- **Filter by Tag or Shortcut**: Browse tasks by their tag hierarchy to create new shortcuts for frequently accessed task categories.
- **Filter by Note Reference**: Learn about filtering by note reference on its dedicated help page.
- **Default Task Filters**: Two built-in shortcuts are available:
  - "Due This Week": Shows tasks scheduled for the current week
  - "High Value": Displays tasks with a Task Score above 10

![Filtering tasks by tag or shortcut](https://images.amplenote.com/6da70c7a-fc35-11ea-a1e0-160c44ce3352/4f360363-2b48-47f5-bca2-01a87adf77c5.gif)

### Using Task View

**Finding source notes**: To discover which note a task originated from, expand the Task Details using the expand/contract icon or a dedicated hotkey.

![Find which note a task came from by clicking its Task Details via the expand/contract icon](https://images.amplenote.com/6da70c7a-fc35-11ea-a1e0-160c44ce3352/468c9d0f-800d-4994-811d-f76efe1e5eb6.gif)

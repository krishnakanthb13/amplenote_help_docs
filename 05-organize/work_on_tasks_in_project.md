# Managing tasks across multiple projects with nested tags

> [← Help Index](../00-index.md) · Category: [Organize Everything](./index.md) · [Source ↗](https://www.amplenote.com/help/work_on_tasks_in_project)

## Organizing with tags

Amplenote uses tags to help categorize and prioritize notes. With tags, you can easily organize and search your notes by tag, quickly return to important items, or filter on notes you'd like to share with others.

## Adding tags to notes

1. Click the "Add a tag" link in the note header and enter the word or phrase you wish to use.
2. Hit the Enter or Return key to save the tag.
3. You can add multiple tags to a single note.
4. Click on the `#` icon next to the tag to change the tag color for at-a-glance organization.

Applicable tag suggestions appear as you enter your hierarchy to prevent duplicate hierarchies.

## Tag naming rules to prevent duplicate hierarchies

One of the most frustrating problems for note-taking users is redundant tag/folder hierarchies. Amplenote has built-in rules to minimize this:

- **Tag hierarchy names are always lower-cased.** If you type `Blog/Draft`, it converts to `blog/draft` automatically.
- **All spacing and punctuation is replaced by "-".** For example, `Tech Blog/Drafts` or `Tech_Blog/Drafts` both convert to `tech-blog/drafts`.

Amplenote also **auto-suggests existing tag names** as you're entering a tag, to maximize reuse versus recreation of your organization hierarchy.

## How do nested/hierarchical tags work? How can I manage multiple projects with them?

Nested tags (also called hierarchical tags) like `hobby-projects/golf-tournament` or `todo/dev/client-a` are a reliable way to manage many project-specific tasks. One or more nested tags can be applied to any note, and all tasks within a note can be found via any of the note's nested tags.

If you plan to use Amplenote for multiple projects, it's recommended to review suggestions for choosing hierarchy/nested tag names.

## Two common types of nested tags

### Knowledge Management collections and Project Knowledge notes

These are notes collected around evergreen topics for future reference. Examples include:

- `gitclear/blogs`
- `recipe/thai`
- `personal/dev/devops`
- `people/influencers/reddit`
- `personal/blog/my-favorite-hobby-to-blog-about`
- `personal/nice-things-said`
- `amplenote/competition`
- `amplenote/help/organizing-tags`
- `movie/reviews/comedy`
- `seattle/coworking-offices`

These notes may or may not contain tasks, and any tasks present are typically ephemeral — useful only in the context of when the research was being done.

### Project Tasks

Tag hierarchies destined to become Tag Shortcuts within the Task View hierarchy or Task Domains. Examples:

- `todo/gitclear/dev`
- `daily-jots/may-2021`
- `todo/personal/hobby`
- `todo/personal/chore`
- `blog/to-write`
- `todo/personal/family`
- `recipes/ingredients-to-buy`

**Why separate these structures?** A Knowledge Management system can contain notes with ephemeral to-dos (like researching Roman architecture and noting cities to look up). You probably don't want those tasks showing up when scheduling your week.

### When a note is knowledge and tasks

Often a note contains both knowledge to remember and tasks to follow up on. Amplenote allows you to tag any note with multiple tags. For example, a note compiling the best Indian cooking recipes could be tagged with `recipes/indian`, `todo/grocery`, and `personal/recipes/favorites`.

## Managing tasks across multiple projects with nested tags

After identifying notes containing tasks you want to work on, choose a tag to apply to them. For example, tag notes with `todo/project-a` and `todo/project-b`. Then in Tasks View mode, you'll have a list of all tasks for `project-a` extracted from notes with that tag.

Alternatively, use the Amplenote Calendar with Task Domains to group nested tags indicating work tasks in a "Work" Task Domain. When ready to schedule your day, hold shift and click to select the particular project tag from the list of possibilities. This makes it convenient to get tags pertaining only to a specific project and see applicable tasks to drag onto your calendar (which syncs to Google or Outlook calendars, if desired).

## Browsing notes by tag

You can browse through your note hierarchy to see all notes with a certain tag using the sidebar, or reference notes matching your hierarchy by using Quick Open. This displays note titles matching the query and provides a holistic filter to view all notes with the nested tag alongside each other. In tasks mode, nested tags are the primary means to move from one productivity context to another.

## Multi-tag selection

In some scenarios, it's useful to list all notes tagged with a **combination of tags**. To achieve this, `Shift`-click on every tag name you want to include (and `Shift`-click again to exclude).

Filtering by multiple tags might prove especially useful when browsing tasks — for instance, viewing all work-related tasks that are also part of collaborative notes (tagged with `shared-with-me`).

Filtering notes by combinations of tags can also be achieved using the `in:` selector and a comma-separated list of tags in the search bar. For example: `in: amplenote/help-pages, auto-archived`.

![Multi-tag selection by Shift-clicking tag names](https://images.amplenote.com/8f50f93a-fae1-11ea-95c1-f200a12bf340/794441a5-adcf-4e23-9687-cab51ca8b8b7.png)

## Tag Shortcuts and the Default Shortcut

Tag Shortcuts allow you to affix a particularly important tag within your leftmost-pane. When you click that tag, you immediately return to a view showing all note content with that tag.

The dedicated help page on Tag Shortcuts and the Default Shortcut discusses how to create and rename Tag Shortcuts, as well as how to define a "Default Shortcut" (a tag or note that always opens first when entering a mode).

## Creating a new note with tag hierarchy

When creating a new note, you can specify a tag hierarchy by prefacing the note title with its hierarchy. For example, `@recipes/pizza/BBQ Hawaiian Pizza` will display with the appropriate hierarchical structure.

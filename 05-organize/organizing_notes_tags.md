# How do tags work in Amplenote?

> [← Help Index](../00-index.md) · Category: [Organize Everything](./index.md) · [Source ↗](https://www.amplenote.com/help/organizing_notes_tags)

## Organizing with tags

Amplenote uses tags to help categorize and prioritize notes. With tags, you can easily organize, search your notes by tag, quickly return to important items, or filter on notes you'd like to share with others.

## On YouTube: All About Tagging

Videos are available covering:

- Basics of tagging, filtering by tags and nested tags
- Searching using tags and tag shortcuts
- Inspiration for choosing tag hierarchies, color coding tasks and productivity reports

## Adding tags to notes

- Click the "Add a tag" link in the note header and enter the word or phrase you wish to use.
- Hit the Enter or Return key to save the tag.
- You can add multiple tags to a single note.
- Click on the `#` icon next to the tag to change the tag color for at-a-glance organization.
- Applicable tag suggestions will be shown as you enter your hierarchy.

## Deleting tags from notes

To remove a tag from a note, click the triple-dot to the right of the tag name, then select "Remove tag."

![Removing a tag from a note](https://images.amplenote.com/8f50f93a-fae1-11ea-95c1-f200a12bf340/2b55a09d-b73a-43a3-91fa-62fb7daf9fb9.png)

## Tag naming rules to prevent duplicate hierarchies

Amplenote implements automatic tag standardization:

- **Tag hierarchy names are always lower-cased**: `Blog/Draft` becomes `blog/draft`.
- **All spacing and punctuation is replaced by "-"**: `Tech Blog/Drafts` becomes `tech-blog/drafts`.
- The system **auto-suggests existing tag names** as you type to maximize reuse.

## How do nested/hierarchical tags work?

Nested tags like `hobby-projects/golf-tournament` or `todo/dev/client-a` are a reliable way to juggle many project-specific tasks. One or more nested tags can be applied to any note.

### Two common types of nested tags

- **Knowledge Management collections and Project Knowledge notes**: Notes around evergreen topics you'll reference later (examples: `gitclear/blogs`, `recipe/thai`, `personal/dev/devops`). These may contain ephemeral tasks only useful during research.
- **Project Tasks**: Tag hierarchies destined to become Tag Shortcuts within Task View hierarchy or Task Domains (examples: `todo/gitclear/dev`, `daily-jots/may-2021`, `blog/to-write`).
- **When a note is knowledge and tasks**: A single note can have multiple tags if it contains both knowledge and actionable items.

### Managing tasks across multiple projects with nested tags

Tag notes with `todo/project-a` and `todo/project-b`. In Tasks View mode, you'll have a list of all tasks for each project. When using the Amplenote Calendar with Task Domains, shift-click to select particular project tags.

![Control which notes are shown via tag in the Calendar task list](https://images.amplenote.com/8f50f93a-fae1-11ea-95c1-f200a12bf340/6ee8d947-8a3c-41a6-add6-17b219869ce6.gif)

## Browsing notes by tag

- Browse through your note hierarchy to see all notes with a certain tag using the sidebar.
- Use Quick Open to reference notes matching your hierarchy.
- This allows viewing note titles matching your query and filtering all notes with a nested tag.

![Browsing notes by tag in the sidebar hierarchy](https://images.amplenote.com/8f50f93a-fae1-11ea-95c1-f200a12bf340/8087e8d3-29e9-4d72-b7af-aa9ff0dffaf7.png)

### Multi-tag selection

Shift-click on every tag name you want to include (and Shift-click again to exclude) to list notes tagged with a combination of tags. Filtering by multiple tags is useful for browsing tasks, or use the `in:` selector with comma-separated tags in the search bar.

![Multi-tag selection by Shift-clicking tag names](https://images.amplenote.com/8f50f93a-fae1-11ea-95c1-f200a12bf340/794441a5-adcf-4e23-9687-cab51ca8b8b7.png)

## Tag Shortcuts and the Default Shortcut

Tag Shortcuts affix important tags within your leftmost-pane for quick access to all note content with that tag. The Default Shortcut is a tag or note that always opens first when entering a mode.

## Creating a new note with tag hierarchy

Specify a tag hierarchy when creating a new note by prefacing the note title with its hierarchy. For example, `@recipes/pizza/BBQ Hawaiian Pizza` creates a note with that tag structure.

![Creating a new note with a tag hierarchy by prefacing the note title](https://images.amplenote.com/8f50f93a-fae1-11ea-95c1-f200a12bf340/8ecefc3b-c2cb-4fe7-82f0-40be36b88e49.png)

# Tag settings: coloring, moving, renaming

> [← Help Index](../00-index.md) · Category: [Organize Everything](./index.md) · [Source ↗](https://www.amplenote.com/help/tag_renaming_reorganizing)

## Overview

Tag hierarchies inevitably need refreshing as organizing systems evolve. Amplenote provides multiple options for managing tags, including renaming, merging, and configuring per-tag settings.

## Tag options

Access tag options by clicking the "triple dot" icon next to any tag. On mobile, tap the triple dot next to a tag in a note, or tap the note count in the left pane.

### Tag coloring

You can assign colors to tags through the Tag Settings menu. This affects:

- How the tag displays in the sidebar and in notes
- How tasks with that tag appear on the calendar

The primary use case is "setting up calendar coloring of tasks."

### Victory Value multiplier

Victory Value is graphed in the Completed Task Stats section. For tags containing tasks aligned with current quarterly goals, "we recommend setting the Victory Value multiplier to 2 or higher."

### Target maximum open tasks

Set a per-tag limit for open tasks. When exceeded, you'll see an indicator in Jots View or Tasks View showing proximity to your goal limit.

### Prevent auto-archive in tag

Toggle in the "Notes" section to prevent auto-archiving of notes within a specific tag. This option is "generally not necessary."

## Moving a tag hierarchy

Relocate tags through drag-and-drop. All notes with that tag automatically update when moved.

## Renaming a tag

Hover over a tag, select "Tag Settings," and enter a new name. All notes with that tag update with the new name. Note: renaming a parent tag updates "the path of all descendant tags" accordingly.

## Deleting a tag

Delete tags through the Tag Settings menu. Deleting a tag removes it from notes but doesn't delete the notes themselves.

## Deleting all notes with a certain tag

The tag options menu allows deleting all notes associated with a tag. **Use caution — this operation cannot be undone.**

## Merging a tag

Merge tags by dragging one onto another. All notes update to reflect the merge. Merging a parent tag also merges "the path of those tags" with descendants.

## Multi-note selection for complex tag queries

For complex operations across multiple notes, use the multi-note selection feature with bulk actions.

# Moving & organizing tasks in Notes & Jots

> [← Help Index](../00-index.md) · Category: [Organize Everything](./index.md) · [Source ↗](https://www.amplenote.com/help/moving_tasks_across_between_notes)

This help article explains methods for reordering tasks within notes and transferring them between projects.

## Key organization methods

- **Automatic sorting by priority**: Use the sort icon in the formatting toolbar to arrange tasks based on assigned point values, automatically prioritizing them accordingly.
- **Manual reordering**: Tasks can be repositioned using the drag handle beside checkboxes. Keyboard shortcuts are recommended instead: "Shift-Mod-Up or Shift-Mod-Down will push a task up or down the list."
- **Subtask creation**: Create hierarchical task structures by pressing Enter for a new task, then Tab to indent it as a subtask — mirroring bullet-point functionality.

## Moving between notes

Two primary approaches exist:

1. The `!move` task command (referenced in the task commands menu)
2. Drag-and-drop functionality directly to notes in the sidebar

![Moving tasks between notes](https://images.amplenote.com/6da70c7a-fc35-11ea-a1e0-160c44ce3352/c5ed5c42-d2bd-4521-8a5d-61638d44088b.gif)

## Additional features

There are batch adjustment capabilities for modifying multiple task scores simultaneously within a single note, with details available on a dedicated help page.

> **Note**: Task reorganization in Tasks or Calendar views follows different rules, using algorithmic sorting based on user-selected grouping or sorting preferences.

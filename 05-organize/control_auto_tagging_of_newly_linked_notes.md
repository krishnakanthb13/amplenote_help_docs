# Control auto-tagging of newly linked notes

> [← Help Index](../00-index.md) · Category: [Organize Everything](./index.md) · [Source ↗](https://www.amplenote.com/help/control_auto_tagging_of_newly_linked_notes)

## Overview

Amplenote manages auto-tagging through several mechanisms when creating linked notes.

## Auto-tagging behavior

**Selected tags are applied to new notes** when:

- Using the `@` note linking syntax
- Extracting text to a new note

**Tags from the current note propagate** when:

- Using the `Ctrl-Shift-[` phrase-linking hotkey
- Prefixing a note link with the `&` character

## Preventing auto-tagging

To disable automatic tag application to newly created notes, add a `~` character following the `@` syntax.

![Adding a tilde `~` after the `@` syntax to prevent automatic tag application](https://images.amplenote.com/23f25aae-fad1-11ea-a5bc-f200a12bf340/591032ee-d0ed-48cd-93d4-5a88e02373cf.gif)

Alternatively, in Jots mode, deselect tags by clicking the Jots button again.

## Auto-tagging from the source note

Prepending an `&` character to a link applies all tags from your current note to the linked note — whether newly created or existing. This proves particularly useful when taking notes on specific projects, as it enables "mass applying" of relevant tags.

![Prepending the `&` character to apply the current note's tags to a linked note](https://images.amplenote.com/94a36246-bf49-11ec-9da7-2eacb931c5dc/0a6c4954-bc7f-4e2e-8d90-127b80563c9e.png)

# Backlinking (bidirectional linking)

> [← Help Index](../00-index.md) · Category: [Organize Everything](./index.md) · [Source ↗](https://www.amplenote.com/help/backlinking_bidirectional_linking)

## Overview

Backlinking in Amplenote provides a convenient way to connect your notes (and thus, ideas) together into a network of knowledge.

## What are backlinks?

### Common use cases

Typical applications of backlinking include:

- People being worked with
- Ideas to pursue on work projects
- Facts about areas of personal interest
- Classes being taken at school

### Creating links

You can create backlinks through two primary methods:

1. **Note linking syntax** — using `[[` notation and `@` mentions
2. **Rich Footnotes URL field** — typing note names directly

## What gets shown in the Backlinks tab

The content displayed depends on where the link sits:

- **Link in a paragraph:** The containing paragraph appears in the Backlinks tab.
- **Link in a task or bullet item:** The entire hierarchy, including child bullets, is included.
- **Link in a heading:** All content displays up until the next head of equal or greater value.

## Advanced features

### Renaming backlinks

You can update link text to match current note titles through a button in the Backlinks tab. This is particularly useful when note titles change after linking.

### Filtering backlinks

Filtering enables you to effectively find all instances in which you meaningfully interacted with a subject (for example, "Huckleberry about an Amplenote project") by narrowing results using source note tags.

### Unlinked references

This feature identifies note title mentions that aren't yet formatted as links, allowing one-click conversion to official backlinks.

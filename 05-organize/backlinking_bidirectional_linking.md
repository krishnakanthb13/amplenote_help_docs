# Backlinking (bidirectional linking)

> [← Help Index](../00-index.md) · Category: [Organize Everything](./index.md) · [Source ↗](https://www.amplenote.com/help/backlinking_bidirectional_linking)

## Overview

Backlinking in Amplenote provides a convenient way to connect your notes (and thus, ideas) together into a network of knowledge.

## What are backlinks?

### Common use cases

Typical applications of backlinking include:

- People being worked with
- Ideas to pursue on work projects
- Facts about areas of personal interest
- Classes being taken at school

![Backlinks being used to collect all tasks pertaining to a topic, like "Amplenote Ideas"](https://images.amplenote.com/21768b9a-fb78-11ea-b757-1a263ad550a8/c1c1d89c-9f20-4d65-ad67-d036a74c3987.png)

![The "Amplenote Ideas" note collects each mention of the note in the "Backlinks" tab](https://images.amplenote.com/21768b9a-fb78-11ea-b757-1a263ad550a8/74ec7d78-1279-453f-a95f-49c7be301b9e.png)

### Creating links

You can create backlinks through two primary methods:

1. **Note linking syntax** — using `[[` notation and `@` mentions
2. **Rich Footnotes URL field** — typing note names directly

![Creating a link into a note through the Rich Footnotes popup](https://images.amplenote.com/21768b9a-fb78-11ea-b757-1a263ad550a8/5c5ed06b-d50d-4dab-9ddd-14a885c2e57e.gif)

## What gets shown in the Backlinks tab

The content displayed depends on where the link sits:

- **Link in a paragraph:** The containing paragraph appears in the Backlinks tab.
- **Link in a task or bullet item:** The entire hierarchy, including child bullets, is included.
- **Link in a heading:** All content displays up until the next head of equal or greater value.

## Advanced features

### Renaming backlinks

You can update link text to match current note titles through a button in the Backlinks tab. This is particularly useful when note titles change after linking.

![Button for updating reference text](https://images.amplenote.com/21768b9a-fb78-11ea-b757-1a263ad550a8/a5d8ea50-ae1f-4017-8896-65c688f0bf77.png)

![References filtered by typing the `#` character in the search bar](https://images.amplenote.com/21768b9a-fb78-11ea-b757-1a263ad550a8/9a745b31-d82d-482f-a4fb-47ec115da23e.png)

### Filtering backlinks

Filtering enables you to effectively find all instances in which you meaningfully interacted with a subject (for example, "Huckleberry about an Amplenote project") by narrowing results using source note tags.

![Enter a tag to filter the list of backlinks that are shown](https://images.amplenote.com/e7a0a100-1e02-11eb-a21d-769e40351abc/c284fccc-1730-4d71-9317-b1107233957b.gif)

### Unlinked references

This feature identifies note title mentions that aren't yet formatted as links, allowing one-click conversion to official backlinks.

![Note the "Find more references to this note" now available in "Backlinks"](https://images.amplenote.com/e7a0a100-1e02-11eb-a21d-769e40351abc/5b85c852-4059-4eda-a72e-a5e70771217e.png)

![Notes that reference the current note title, one click to convert them to official backlinks](https://images.amplenote.com/e7a0a100-1e02-11eb-a21d-769e40351abc/967b8297-83ab-401e-b011-7b52d6a83adc.png)

# Organizing notes into folders using hierarchical tags

> [← Help Index](../00-index.md) · Category: [Organize Everything](./index.md) · [Source ↗](https://www.amplenote.com/help/folders_vs_tags)

## Overview

Amplenote addresses folder organization requests from users migrating from Evernote and OneNote by offering hierarchical tags that provide folder-like functionality with additional benefits.

## Key features of tags in Amplenote

- **Deep hierarchies for projects and contexts**: Create nested tags like `work/project-a/research` and browse them in the left sidebar or access them through Quick Open navigation.
- **Multiple tags per note**: Notes can belong to several hierarchies simultaneously, useful for notes that combine research with tasks. A single note could have both a research tag and a `todo/project-a` tag.
- **Flexible management**: Tags can be renamed, deleted, moved, and merged — accommodating evolving organizational needs without creating permanent structure constraints.
- **Collaboration options**: Tags can be shared with individuals, groups, or the public, allowing collaborators on specific note collections.

## Setting up tag structure

You can create empty tags before adding notes using the plus sign icon next to "Tags." However, the guide recommends applying tags only as needed rather than pre-building comprehensive hierarchies, since circumstances change and advance planning often becomes outdated.

## Tags vs. folders

Amplenote positions tags as an enhancement over traditional folders because they allow "multiple 'folders' per note" while maintaining optional single-tag usage for those preferring traditional organization.
